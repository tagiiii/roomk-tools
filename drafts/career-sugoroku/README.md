## ゲームの流れ

```
スタート（6さい）
 → 小学生（6〜12さい）
 → 中学生（13〜15さい）… 近道（3マス）／寄り道（5マス・体験マスが多い）
 → 15さいの節目: 学びの道（高校）か、しごとの道（ここで職業を選ぶ）
 → 16〜18さい
 → 18さいの節目: 学びの道（大学・専門学校）か、しごとの道（職業を選ぶ・続ける）
 → 19〜22さい
 → 22さいの節目: 職業がない人は選ぶ（ある人は続けても変えてもいい）
 → おとな（23〜35さい）… 近道／寄り道（成長マスとなかまマスがある）
 → ゴール（35さい）
```

- 1回の番: サイコロを押す → 進む → 止まったマスのカード → 「つぎへ」。押すのはサイコロと、選ぶところだけ
- 節目（15・18・22さい）は、サイコロの目が残っていても必ず止まる
- マス
  - 体験マス（6色＝6つの適性）: 止まると、その色の適性 +1
  - なかまマス: だれかをさそって一緒に体験。2人とも +1。休んでいる人をさそうと、その人の休みがなくなる
  - イベント: カードをめくる（いいこと・1回休み・もどる・進む・もう1回・みんなで決める・みんなでサイコロ）
  - しごとマス: 通るたびに、今の職業の★の数だけポイント（同じマスは1回だけ）
  - 成長マス: 今の職業に合う適性のうち、いちばん少ないもの +1
  - 転職チャンス: 職業を変えてもいい（今のままでもいい）
  - ミニゲームマス: 全員でミニゲーム（下の「ミニゲーム」）
- 学びの道から節目に着くと: 18さいは好きな適性 +1 と 1ポイント、22さいは好きな適性 +2
- ★: 職業に合う3つの適性の合計で決まる（0〜2で★1、3〜5で★2、6〜8で★3、9以上で★4）。★は今の適性でいつも計算し直す（あとから育つ）。どの職業でも選べる
- ゴールの順のボーナス: 1番目 +5、2番目 +3、3番目 +2、4番目から +1
- 全員がゴールしたら結果。ポイントの合計が多い順（同点は同じ順位）。時間が来たら、メニューの「ここで終えて結果を見る」で終われる（まだの人は、ゴールに近い順に続きの順位のボーナス）
- ゴールした人は応援役になり、まだの人のサイコロに +1 できる（1回の番に1人）

## 作戦（戦略でポイントを増やす）

- サイコロ: はじめの画面で「2つ振って、進む目を選ぶ（作戦あり・既定）」か「1つだけ振る（運まかせ）」を選ぶ
- 2つのときは、振ったあとに「どっちの目で進む？」のカードが出る。それぞれの止まる先（体験マスの色・イベント・分かれ道・節目・途中で通るしごとマスなど）をカードの文と盤面の①②で見比べて選ぶ。カードは駒と反対側に寄せて出し、盤面の目印を隠さない
- しごとマスにぴったり止まると、そのマスのポイントをもう1回（2倍）。2つの目から「急いで進むか、ポイントをねらうか」を選ぶ理由になる
- ぴったりのボーナスを入れたら、ねらってゆっくり進むほうが得になり、1番にゴールする意味が薄れた（4人で「1番にゴールした人が1位」が48%→30%）。オーナーの方針3（醍醐味は1番にゴール）に合わせて、ゴールの順のボーナスを 5・3・2・1 から 8・5・3・2・1・1 に上げた（45%にもどる）
- 測った効き目（4人・各2000〜3000ゲーム。職業と適性とサイコロを考えて選ぶ人と、ランダムに選ぶ人を半々にした）: 考えて選ぶ人が平均5.9点多く、1位の割合は50%対6%。サイコロの選び方だけ（職業と適性はどちらも考える）で平均1.0点・1位33%対24%の差。いちばん効くのは職業と適性の選び方で、それを選びやすくするために「★が上がる職業」の表示としごと図鑑を入れた

## ミニゲーム

ミニゲームマスに止まると、全員で遊ぶ。3つを順番に（山札のように）出す。1台の画面なので、みんなが口・チャット・手で出したものを、メンターが1人ずつ押して入れ、結果はアプリが決める。

| ミニゲーム | 遊び方 | ごほうび |
|---|---|---|
| 大きい？小さい？ | 画面の数（2〜5）より、つぎのサイコロが大きいか小さいかを全員で予想 | 当たった人 +1ポイント。同じ数なら全員 +1ポイント |
| じゃんけん | みんなでコンピューターとじゃんけん（チャットに書くか、手で出す） | 勝った人 +1ポイント |
| 合計ピッタリ | 相談しないで、せーので1〜3を出す。合計が目標と同じならピッタリ | ピッタリなら全員 +1ポイント |

- 勝ち負けは運か協力で決まるものだけにした（うまい子がいつも勝つ形にしない）
- 「大きい？小さい？」「じゃんけん」は、答えを入れなかった人がいても進める（今回は参加なし）。「合計ピッタリ」は全員の数が要る
- 合計ピッタリの目標は、全員1・全員3の端を除いた範囲（人数が n なら n+1〜3n−1）。1人のときは出さない
- ゴールした人・休みの人も参加する
- 答えを隠しておくゲーム（ジェスチャーでお題を当てる など）は、1台の画面だと全員に見えてしまうので入れていない

## 画面

- いつも出すのは、盤面・コマ・「○○さんの番」・サイコロだけ
- 出来事は盤面の上のカードで大きく出す。選ぶものには①②③の番号（進行役は数字キーでも選べる。Enter で主なボタン）
- 適性・職業・ポイントは、プレイヤーの名前を押すと開く「手帳」で見る。途中の順位は出さない（コマの位置でレースは見える）
- 適性を選ぶカードでは、各適性の下に「★が上がる職業」（上がる職業がなければ「合う職業」）を出す。今の職業に合う適性には「今の職業に合う・★2→★3」のしるし（2026-09-29 オーナーの試遊で「職業別の適性がわからず選びづらい」→追加）
- しごと図鑑: 全24職業の合う適性3つと、その人のいまの★・合計を★の多い順に出す。適性でしぼれる。上のバー（番の人の★）・適性を選ぶカード・手帳（その人の★）から開く
- できごと（記録）・あそびかた・メニュー（表示の切り替え・遊んでいる時間・途中で終える・最初にもどる）は上のボタンから
- 状態はこのタブの `sessionStorage` にだけ残す（再読み込みしても「つづきから」で戻れる。タブを閉じると消える）

## つり合いのシミュレーション（`tests/sim.cjs`・各2000〜3000ゲーム）

コンピューターの選び方は「道はランダム・寄り道は半々・職業は★がいちばん多いもの・サイコロ2つは止まる先の価値と速さで選ぶ・ミニゲームの答えはランダム」。人の選び方とは違うので、目安として見る。

| 人数・サイコロ | 1人あたりの手番 | 1番にゴールした人が1位 | 道ごとの1位の割合（しし／し学／学し／学学） | 平均点（同） |
|---|---|---|---|---|
| 2人・2つ | 12.3 | 61% | 50%／57%／57%／53%（ひとしければ50%） | 24.9／25.4／25.8／25.7 |
| 4人・2つ | 12.2 | 45% | 28%／—／—／29%（ひとしければ25%） | 23.4／—／—／23.6 |
| 6人・2つ | 12.1 | 39% | 19%／—／—／17%（ひとしければ17%） | 22.7／—／—／22.6 |
| 4人・1つ | 12.2 | 50% | 24%／30%／29%／30% | 22.7／23.5／23.5／23.6 |

「し学」は15さいでしごと・18さいで学びの道。道ごとの平均点の差は約1点以内（しごと→しごとがやや低め）、寄り道と近道の差は0.6点以内。ミニゲームは4人で1ゲーム平均2〜3回（サイコロ2つだとミニゲームマスをよけることもあるので少し減る）。
経緯: 最初はしごと→しごとが圧勝 → しごとマスの数・★の段階・学びのボーナスで均した → ミニゲームでイベントマスが減り学びのボーナスが相対的に強まった → ぴったり2倍でレースが弱まり、ゴールのボーナスを上げた。

## ガイドラインとの関係

- 学校名: 前の版の決定10（進路の学校名は意図的な例外）を引き継ぐ。今回は盤面の骨組みになるため、はじめの画面とメニューで「年齢だけ」の表示に切り替えられるようにした
- ステージの出来事は、学校に通っていなくても経験できること（遊び・習いごと・家・地域・趣味・アルバイトなど）にした。運動会・修学旅行・部活・テストのような、通っていることが前提の出来事は入れていない
- 道の間に優劣をつけない（長さは同じ。平均点の差は約1点以内）
- 職業は診断や推薦ではない。ゲームの中でたまった適性で★が決まり、その中から本人が選ぶ（どれでも選べる）
- ポイント制は、オーナーの方針5による意図的な選択（apps/ に移すときに、アプリの AGENTS.md へ理由を書く）
- 結婚・子どものイベントは、まだ入れていない（入れるときは前の版の決定11の条件: 本人が選ぶ・オフにできる）

## 試遊で見てほしいところ

- 1回の長さ（メニューの「遊んでいる時間」で測れる）。4人で30分前後の見込み
- 操作のわかりやすさ（押すのはサイコロと、選ぶところだけ）。カードの文字が画面共有で読めるか
- 会話が自然に起きたか（分かれ道の相談・なかまマス・みんなで決める・みんなでサイコロ・応援・ミニゲーム）
- ミニゲームの入れ方（メンターが1人ずつ押す手間・回数・どれが盛り上がったか）
- サイコロ2つから選ぶ遊び方で、考える楽しさが出たか・1回の番が長くなりすぎないか・ぴったりをねらう場面が生まれたか。「1つだけ振る」と比べてどうか
- 1番にゴールする楽しさと、ポイントでの逆転のバランス
- 学校名のステージの受け止め（年齢だけの表示に切り替えたくなる場面があったか）
- しごとの道で15さいに職業を選ぶのが早すぎないか
- ★の意味（合う適性の合計）が伝わるか。適性を選ぶときの「★が上がる職業」としごと図鑑で選びやすくなったか
