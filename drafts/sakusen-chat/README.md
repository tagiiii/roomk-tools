# 作戦会議チャット（試作）

状態: `drafts/` の試作（drafts は GitHub Pages に配信されないので未公開）。2026-10-13 作成。
**2026-10-13 本体化済み**: オーナーの指示で `apps/sakusen-chat/` に本体を作った（3人まで・名前あり・別の端末どうしでつながる）。現在の仕様の正本は `apps/sakusen-chat/AGENTS.md`。このフォルダは試作の記録。
作戦会議（1対1の面談）で、マイクOFF・カメラOFFの子どもと文字と画像で話すためのチャット。
話題ごとに会話が分かれ、いくつもの話題を同時に進められる。

**この試作は通信しない。** 同じブラウザでひらいた2つのウィンドウの間だけでつながる（BroadcastChannel）。
別の端末どうしではつながらない。画面の流れと話すテンポを確かめるためのもの。
フォントとアイコンだけは、公開中のアプリと同じく Google Fonts から読み込む。

## 開き方

リポジトリのルートで次を実行する。

```bash
python3 -m http.server 8090
```

1. `http://localhost:8090/drafts/sakusen-chat/` を開き、「部屋をひらく」を押す（メンター側）
2. 「リンクをコピー」を押し、同じブラウザの別のウィンドウでそのリンクを開いて「入る」を押す（子ども側）
3. 2つのウィンドウを横に並べて使う

画面を更新したのに古い動きのままなら、`index.html` の `?v=` の値を上げる。

| 話題 | 話題ごとに会話が分かれる。メンターも子どもも話題をふやせる |

| ジブンチェック | 「今日の調子はどのへん？」の5段階をボタンで出し、押すと回答が会話に入る |
| 未読 | 話題ごとの数・ブラウザのタブ名の件数・新着の音（切りかえ可）。「入力中…」は出す。「既読」は出さない |

## 答えがなかったので仮に置いたこと

オーナーの確認が要る。試して違えば変える。

- **文字を書くのは両方**。メンターが声で話す場合も、そのまま使える
- **端末は PC でもスマホでも使える形**にした。幅 600px 以下では、話題の一覧と会話を切りかえて出す
- **画像は両方が送れる**。写真もスクリーンショットも可。送る前にブラウザの中で長い辺 1280px の JPEG に小さくする（このとき位置情報などの付属データも落ちる）
- **チェックインは空の話題だけを用意**する。問いはメンターがその場で書く
- **名前は聞かない**。2人だけなので、自分は右・相手は左の吹き出しで分かる
- **ジブンチェックはメンターも答えられる**。「今日は答えない」を5段階と同じ並びに置いた

## 依頼になかったが入れたもの

- **自分のメッセージを「消す」**（相手の画面からも消える）。まちがえて送った画像を取り消せるように
- **書きかけは話題ごとに残る**。別の話題に切りかえても、書きかけの文字と選んだ画像は元の話題に残る
- **話題に ①②③ の番号**。声で「3番の話題に答えてね」と言えるように
- **「ここから新しいメッセージ」の線**。未読のある話題をひらいたとき、どこから読めばよいか分かるように
- **入るのは2人まで**。3人目がリンクを開いても入れない
- **メンターがウィンドウを閉じようとすると確認が出る**（閉じると会話が消えるため）

## 画面

- はじめの画面: リンクなしで開いたとき。「部屋をひらく」だけ
- 参加の画面: リンクから開いたとき。「入る」だけ
- チャットの画面: 左に話題の一覧、右に選んだ話題の会話。メンターだけに「リンクをコピー」「終わる」が出る
- おわりの画面: 会話と画像が消えたことを伝える

未読の数え方: その話題を開いていて、ウィンドウが手前にある間に届いたものは未読にしない。
別の話題を見ている間・ウィンドウが後ろにある間（Zoom を手前にしている間など）に届いたものは未読になる。

## 試作の限界

- 同じブラウザの2つのウィンドウの間でしかつながらない
- 会話はメンターのウィンドウのメモリにだけある。メンターが再読み込みすると部屋は閉じ、会話は消える
- 子どもが再読み込みしたときは、もう一度「入る」を押すと同じ会話に戻る（未読の数は 0 から）
- はじめの画面の「部屋をひらく」は誰でも押せる（下の「本体にするときに決めること」1）

## 本体にするときに決めること

`apps/` への移植と公開はオーナーの判断。そのときに決める点:

1. **部屋をひらける人をどう限るか**。今は、リンクなしでページを開けば誰でも部屋をひらける。子どもが自分で部屋をひらいて
   別の人と使うことを止めるには、メンター用の合言葉を置くか、ルールで部屋をひらける人を限る必要がある
2. **読める人を2人に限るルール**（`database.rules.json`。変更禁止パスなので、オーナーの個別判断で行う）
3. **メンターが再読み込みしても会話が続くようにするか**（本体ではサーバーに置くので可能）
4. **メンターが「終わる」を押さずに閉じたときの消し方**（一定時間で消す など）
5. **画像の大きさと枚数の上限**（無料枠の中に収める。1枚は小さくした後で数百KBの見込み）
6. 名前（表示名・フォルダ名）。「作戦会議チャット」「sakusen-chat」は仮
