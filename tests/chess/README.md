# チェスの E2E

隔離した Firebase エミュレーターと Playwright で、ホスト・対戦する2人・観戦・みんなにみせる画面を別々のブラウザとして動かして確かめる。
**本番の Firebase には接続しない**（共通の `rtdb-utils.js` をエミュレーター向けに差し替えた写しを使い、本番あての通信が出たら失敗にする）。作りは将棋の E2E（`tests/shogi/`）と同じ。

| ファイル | 内容 |
|---|---|
| `engine.test.cjs` | 盤のルール（perft で手の数を既知の値と照合・メイト・ステイルメイト・キャスリング・アンパッサン・成る・ピン・指せない理由・引き分け3種・表記・取った駒・CPU・でたらめ対局）。エミュレーター不要。`node tests/chess/engine.test.cjs` |
| `e2e1.cjs` | 作成・参加・席・みんなにみせる画面・補助（名前・点・駒の説明・おすすめの手）・指せない理由・同期・盤の向き・メイト・結果・もう一回（白黒の入れかえ）・1手もどす・投了・成る・キャスリング・補助を変える・待合室へ・端末なしの参加者・幅 375px・退出・ルームを閉じる |
| `e2e2.cjs` | 対局中に入った人は観戦・古い選択が消える・ホストの切断と戻り・席の人の切断とホストが代わりに指す・席の名前は別の人に使えない・再読み込み（参加者・ホスト）・相手の番の投了（ルールを読み込ませて流す） |
| `e2e3.cjs` | 1台の画面（名前・キーボード・チェック・指せない理由・盤の向き・1手もどす・読み込み直し・投了・もう一回・成る・CPU と対戦・時間切れ・幅 375px）と、ルームの席の CPU・ルームの時間切れ。時間切れを待つので30秒ほど |
| `e2e4.cjs` | ルールの板（2026-11-19。タブ・駒の図・持ち時間と CPU に合わせた中身・広い画面は右・375px は下から出て盤が板の上に入る・開いたまま指せる・Esc と × で閉じる・トップで閉じる・待合室でも見られる・みんなにみせる画面には出さない） |
| `lib.cjs` | 共通の部品（配信用サーバー・本番あて通信の検出・画面の操作） |
| `sync-site.sh` | `apps/shared` と `apps/chess` を作業フォルダに写し、エミュレーター向けに差し替える。ルールとエミュレーターの設定も写す |
| `firebase.json` | エミュレーターのポート（auth 9531・database 9532・hub 4531・logging 4631）。配信は 6531（`E2E_PORT` で変えると、その1〜3を並べて流せる） |

## 実行

```bash
export CH_WORK=/tmp/chess-e2e
export PLAYWRIGHT=（playwright のフォルダ）

# 1. 写しを作る（アプリを直すたびにやり直す）
bash tests/chess/sync-site.sh

# 2. エミュレーターを起動する（別の端末で。Java が要る）
(cd "$CH_WORK" && npx --yes firebase-tools@15.29.0 emulators:start --only auth,database --project demo-roomk-ch)

# 3. 流す（その2は切断の検知を待つので1〜2分かかる）
node tests/chess/e2e1.cjs
node tests/chess/e2e2.cjs
node tests/chess/e2e3.cjs
node tests/chess/e2e4.cjs
```

- 成る・キャスリングの局面は、記録をエミュレーターに直接入れ、最後の1手だけ画面で指す
- ポートを別のセッションが使っていたら、相手は止めずに、`firebase.json`・`sync-site.sh`・`lib.cjs` のポートをそろえて変える
- 終わったらエミュレーターを止め、ポートが空いたことを確かめる
- 2026-11-18 の結果: ルール 54件・その1 53項目・その2 33項目・その3 48項目、すべて合格
