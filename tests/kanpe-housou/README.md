# カンペ放送局の E2E

隔離した Firebase エミュレーターと Playwright で、ホスト・参加者・みんなにみせる画面を別々のブラウザとして動かして確かめる。
**本番の Firebase には接続しない**（共通の `rtdb-utils.js` をエミュレーター向けに差し替えた写しを使い、本番あての通信が出たら失敗にする）。

| ファイル | 内容 |
|---|---|
| `engine.test.cjs` | ルールと原稿の形（空らんの数・割りあて・番組60本×7行の形・ヒントとおまかせの言葉・番組選び・判定（過半数・同じ数は読みきりにしない）と点・読む順番と書くだけ）。エミュレーター不要。`node tests/kanpe-housou/engine.test.cjs` |
| `e2e1.cjs` | ホストも遊ぶ5人: 作成・参加・同じ名前・数字だけの名前・みんなにみせる画面・書く（ほかの人が出して描きなおしても言葉と入力の位置が残る・日本語の変換中は描きなおさない・書きなおし・からっぽは出せない・おまかせ）・読む前の言葉がほかの画面に入っていない・読む（1行ずつ・新しい行だけ動く）・判定（読む人とみんなにみせる画面にはボタンなし・いっせいに出す・だれが何を出したかは出ない）・結果（読みきった／笑っちゃった・判定の数は出さない・だれが書いた）・点・届いた言葉をたしかめる／おまかせに替える・待たずに読む・おまかせだけの回は点なし・おしまい・きょうの放送・もう一回・幅 375px・待合室へ・退出・ルームを閉じる |
| `e2e2.cjs` | 進行だけのホスト＋参加者2人＋端末なし1人: 端末なしの人を足す（印はホストだけ・同じ名前は不可）・設定（2周・順位）・書くだけ（自分の行だけ・ホストはみんなの行・みんな書くだけだとはじめられない）・書くだけの人は読む番をとばす（2周目も）・読み込み直し・端末なしの人の代わりに書く／読む／判定する・同じ数は読みきりにしない・まだの人を待たずに判定を開く・読む人の切断とホストの代わりの「つぎへ」・もどると続きから・途中から入った人は見ているだけ・ホストが切れたときのオーバーレイ・順位 |
| `lib.cjs` | 共通の部品（配信用サーバー・本番あて通信の検出・画面の操作） |
| `sync-site.sh` | `apps/shared` と `apps/kanpe-housou` を作業フォルダに写し、エミュレーター向けに差し替える |
| `firebase.json` | エミュレーターのポート（auth 9721・database 9722・hub 4721・logging 4821）。配信は 6721 |

## 実行

作業フォルダ（リポジトリの外）を決めて、次の順に行う。Java（エミュレーターに必要）・Playwright の場所は環境に合わせる。

```bash
export KH_WORK=/tmp/kanpe-housou-e2e
export PLAYWRIGHT=（playwright のフォルダ）

# 1. 写しを作る（アプリを直すたびにやり直す）
bash tests/kanpe-housou/sync-site.sh

# 2. エミュレーターを起動する（別の端末で。設定とルールは作業フォルダに置く）
cp tests/kanpe-housou/firebase.json database.rules.json "$KH_WORK"/
(cd "$KH_WORK" && npx --yes firebase-tools@15.29.0 emulators:start --only auth,database --project demo-roomk-kh)

# 3. 1本ずつ流す（その2は切断の検知を待つので、長いと2〜3分かかる）
node tests/kanpe-housou/e2e1.cjs
node tests/kanpe-housou/e2e2.cjs
```

- ポートを別のセッションが使っていたら、相手は止めずに、`firebase.json`・`sync-site.sh`・`lib.cjs` のポートをそろえて変える
- 終わったらエミュレーターを止め、ポートが空いたことを確かめる
