# ひらめき大喜利の E2E

隔離した Firebase エミュレーターと Playwright で、ホスト・参加者・みんなにみせる画面を別々のブラウザとして動かして確かめる。
**本番の Firebase には接続しない**（共通の `rtdb-utils.js` をエミュレーター向けに差し替えた写しを使い、本番あての通信が出たら失敗にする）。

時間で進むこと（押せる時間の終わり・時間で区切る）は、エミュレーターのルームの時刻（`game/cur/endsAt`・`game/roundEndsAt`）を REST で書きかえて早める。アプリにテスト用の切りかえは入れていない。

| ファイル | 内容 |
|---|---|
| `e2e1.cjs` | 作成・参加（同じ名前・ホストと同じ名前）・待合室（ホストのすること・ルール・参加のしかた・はじめられる人数）・みんなにみせる画面（待合室のボタンから・書きこまない）・設定・お題の候補（①②③・ほかの候補・前のお題は出ない）・答え（確認待ち・名前は出ない・本人は押せない）・一本（名前つき・一本で区切る・結果）・押せる時間の終わり（名前なし・「あなた」）・2つまで・かくす（確認待ち・いま出ている答え）・ホストの答えは確認なし・参加のしかたの切りかえ・進行だけのホストは数えない・おしまい（1本以上の人だけ・お題ごと）・もう一回あそぶ・時間で区切る（一本でも締め切らない・時間で締め切る・確認待ちがあると結果へ進まない）・幅 375px（ホストの枠の位置）・ルームを閉じる・利用回数 |
| `e2e2.cjs` | 端末のない参加者（足す欄はたたんである・同じ名前・外す・参加できない名前・投票する人に数える・代わりに書く・代わりに押す・本人の答えには押せない・結果の画面で足す・一本の数）・再読み込み（参加のしかたも戻る）・途中参加・退出で数えなおして一本・抜けても名前は残る・同じ人は入りなおせる・ほかの人は入れない・ホストの切断（オーバーレイ・時間が進まない・戻ると続く） |
| `lib.cjs` | 共通の部品（配信用サーバー・本番あて通信の検出・音の部品の検出・画面の操作） |
| `sync-site.sh` | `apps/shared` と `apps/hirameki-oogiri` を作業フォルダに写し、エミュレーター向けに差し替える |
| `firebase.json` | エミュレーターのポート（auth 9681・database 9682・hub 4795・logging 4895） |

## 実行

作業フォルダ（リポジトリの外）を決めて、次の順に行う。Java（エミュレーターに必要）・Playwright の場所は環境に合わせる。

```bash
export OG_WORK=/tmp/hirameki-oogiri-e2e
export PLAYWRIGHT=（playwright のフォルダ）

# 1. 写しを作る（アプリを直すたびにやり直す）
bash tests/hirameki-oogiri/sync-site.sh

# 2. エミュレーターを起動する（別の端末で。設定とルールは作業フォルダに置く）
cp tests/hirameki-oogiri/firebase.json database.rules.json "$OG_WORK"/
(cd "$OG_WORK" && npx --yes firebase-tools@15.29.0 emulators:start --only auth,database --project demo-roomk-og)

# 3. 1本ずつ流す（その2は、ホストの切断の検知を待つので1〜2分かかる）
node tests/hirameki-oogiri/e2e1.cjs
node tests/hirameki-oogiri/e2e2.cjs
```

- ポートを別のセッションが使っていたら、相手は止めずに、`firebase.json`・`sync-site.sh`・`lib.cjs` のポートをそろえて変える
- 終わったらエミュレーターを止め、ポートが空いたことを確かめる
