# しるしでヒントの E2E

隔離した Firebase エミュレーターと Playwright で、ホスト・参加者・みんなにみせる画面を別々のブラウザとして動かして確かめる。
**本番の Firebase には接続しない**（共通の `rtdb-utils.js` をエミュレーター向けに差し替えた写しを使い、本番あての通信が出たら失敗にする）。

| ファイル | 内容 |
|---|---|
| `e2e1.cjs` | 作成・参加・同じ名前・みんなにみせる画面・1問の流れ（候補・しるし・答え合わせ・点・はずれ −1点・結果の表示）・次の人・パス・一巡の順位・もう一巡・出せないしるし・おしまい・もう一回あそぶ・ホストも遊ぶ（3人・待たずに締まる・伝えた人の点は1回）・幅 375px・アイコンの表示・ルームを閉じる |
| `e2e2.cjs` | 端末なしの参加者（足す・外す・同じ名前・ホストは進行だけ・代わりに押す・代わりに伝える）・再読み込み・退出で待たずに答え合わせ・途中参加は不可・同じ名前で入りなおし・伝える人の切断（ブラウザを閉じる）と交代・ホストの切断と復帰・レビューの指摘の確認（再読み込みの一瞬に答えへ進まない・当てていない人が抜けたら答えへ・6つ目のあとの案内） |
| `e2e3.cjs` | しるしごとに選ぶ時間（待合室の設定・参加者にも見える・開始時に固定・残り時間の表示・再読み込みしても続き・5秒から色・時間切れの答え合わせ（選ばない人は減らない）・全員選べば待たない・なしなら出さない・幅 375px） |
| `lib.cjs` | 共通の部品（配信用サーバー・本番あて通信の検出・画面の操作） |
| `sync-site.sh` | `apps/shared` と `apps/shirushi-hint` を作業フォルダに写し、エミュレーター向けに差し替える |
| `firebase.json` | エミュレーターのポート（auth 9581・database 9582・hub 4581・logging 4681） |

## 実行

作業フォルダ（リポジトリの外）を決めて、次の順に行う。Java（エミュレーターに必要）・Playwright の場所は環境に合わせる。

```bash
export SH_WORK=/tmp/shirushi-hint-e2e
export PLAYWRIGHT=（playwright のフォルダ）

# 1. 写しを作る（アプリを直すたびにやり直す）
bash tests/shirushi-hint/sync-site.sh

# 2. エミュレーターを起動する（別の端末で。設定とルールは作業フォルダに置く）
cp tests/shirushi-hint/firebase.json database.rules.json "$SH_WORK"/
(cd "$SH_WORK" && npx --yes firebase-tools@15.29.0 emulators:start --only auth,database --project demo-roomk-sh)

# 3. 1本ずつ流す（その2は、切断の検知を待つので1〜2分かかる）
node tests/shirushi-hint/e2e1.cjs
node tests/shirushi-hint/e2e2.cjs
node tests/shirushi-hint/e2e3.cjs
```

- ポートを別のセッションが使っていたら、相手は止めずに、`firebase.json`・`sync-site.sh`・`lib.cjs` のポートをそろえて変える
- お題は毎回くじで出る。特定のお題を試すときは、テストの中でエミュレーターの `game/q/cands` を書きかえる（その1の「出せないしるし」）
- 終わったらエミュレーターを止め、ポートが空いたことを確かめる
- 2026-10-19 の結果: その1 85項目・その2 69項目、すべて合格（その2 の V は、レビューの指摘を直したことの確認）
- 2026-10-19（しるしごとに選ぶ時間を足したあと）: その1 85項目・その2 69項目・その3 30項目、すべて合格。その3 は時間切れを実際に待つので30秒ほどかかる
