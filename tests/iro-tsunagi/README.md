# いろつなぎのテスト

ひとりで遊ぶツールなので、Firebase のエミュレーターは要らない。

| ファイル | 内容 |
|---|---|
| `engine.test.cjs` | ルール（4つで消える・れんさ・置いた組がばらばらに落ちる・かべぎわ／床で回す・1列のすき間は flip のときだけ入れかえ・色の袋・全部消えた・出る所がふさがる・影・1000手のためし置き）。`node tests/iro-tsunagi/engine.test.cjs` |
| `e2e1.cjs` | 画面（タイトル・はじめるを数える・出る所・左右の押しっぱなし・W A S D・下の押しっぱなしが同じ速さ・とめる・あそびかたでとまる・おわる・同じ seed と手順で Node と同じ盤／点／れんさ・一言が盤の左の外・盤がいっぱいでからにする・時間・おしまい・もう一回・効果音（切のうちは読まない・入で7つ読む・端末に残る）・375px で収まり右下の丸ボタンに重ならない・操作ボタン・コンソールのエラー・外への通信がない） |

## 実行

```bash
PLAYWRIGHT=（playwright のフォルダ） node tests/iro-tsunagi/e2e1.cjs
```

- `apps/` をテストの中で `127.0.0.1:6931` に配信する（`E2E_PORT` で変えられる）。外への通信はすべて止め、`stats.js` は数えるだけの写しに差し替える（本番に数えない）
- 画面の写真がほしいときは `IT_OUT=（フォルダ）` を付ける
- 画面の状態は `?test=1` のときだけ `window.__iro` から読む。`?seed=` で玉の順番を決める
