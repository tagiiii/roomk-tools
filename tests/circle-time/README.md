# サークルタイムの E2E

隔離した Firebase エミュレーターと Playwright で、進行役・参加者2人・みんなにみせる画面を別々のブラウザとして動かす。
**本番の Firebase にも気象庁にも接続しない**（共通の `rtdb-utils.js` をエミュレーター向けに差し替えた写しを使い、気象庁の応答はテストの中で差し替える。本番あての通信が出たら失敗にする）。

| ファイル | 内容 |
|---|---|
| `e2e1.cjs` | 入口・午前のルーム（天気13都市・何の日・プログラム）・リンクからの参加・みんなにみせる画面（大人の点線）・心（伏せる→答えた人の名前→せーので見せる→パス→しめきる）・端末なしの人と自分の分を代わりに入れる・チャット用の文・一覧から移る・飛ばす・前へ次へ・天気の「きみのところは？」・何の日（伏せる→見せる→答えと由来）・文を直す・その場で聞く・プログラムのリンク・並べかえ・退出・外す・幅375px |
| `e2e2.cjs` | 午後のルーム（お題・話したい・つぎのお題・ふりかえりの数字とひとこと）・参加者と進行役の読み込み直し・進行役の切断と復帰・外された参加者・ルームを閉じる・天気が取れないとき |
| `e2e3.cjs` | 今日は何の日の毎朝のデータ（自動で入る・1つだけ本当・別の候補・3つとも本当・カードごとの由来・出し方を覚える）・まだ用意されていない日・本当が2つの日・つかいかた（みんなにみせる画面では「？」を出さない） |
| `e2e4.cjs` | 準備は自動（たたんだ欄・準備のようす・午前午後は時刻で）・プログラム（ファイルから・時刻ごと・コマ目・場所・この日だけ・サムネイル・申し込み制の印は出さない・午後は明日）・日本地図の天気・自由タイム（準備で決めたニュースから・つぎのニュース・進行役が変える・なし）・移動の案内 |
| `e2e5.cjs` | 準備で決めたみんなでゲームの「ルームを作る」で、そのゲームのタブが開き、本物のクイズパックでルームを作ると、参加リンク（?room=）とルームコードが自動でみんなの端末・みんなの画面に出る |
| `daily-check.mjs` | 毎朝のデータの検査（Wikipedia を読む。エミュレーター不要） |
| `news-check.mjs` | 自由タイムのニュースの検査（形・長さ・リンク・選ばない話題の言葉。エミュレーター不要） |
| `lib.cjs` | 共通の部品（配信・本番あて通信の検出・気象庁と毎朝のデータの差し替え・操作） |
| `sync-site.sh` | `apps/shared`・`apps/talk-card`・`apps/quiz`・`apps/kotoba-mikke`・`apps/index.html`・`apps/circle-time` を作業フォルダに写し、エミュレーター向けに差し替える |
| `firebase.json` | エミュレーターのポート（auth 9931・database 9932・hub 4931・logging 5031。配信は 6931） |

## 実行

```bash
export CT_WORK=/tmp/circle-time-e2e
export PLAYWRIGHT=（playwright のフォルダ）
bash tests/circle-time/sync-site.sh
cp tests/circle-time/firebase.json database.rules.json "$CT_WORK"/
(cd "$CT_WORK" && npx --yes firebase-tools@15.29.0 emulators:start --only auth,database --project demo-roomk-ct)
node tests/circle-time/e2e1.cjs
node tests/circle-time/e2e2.cjs
node tests/circle-time/e2e3.cjs
node tests/circle-time/e2e4.cjs
node tests/circle-time/e2e5.cjs
```

- 画面の写真は `$CT_WORK/out/` に出る
- 2026-11-09 本体化のときの結果: その1 100項目・その2 55項目・その3 35項目・その4 54項目・その5 12項目、すべて合格（Playwright 1.64・システムの Chrome・firebase-tools 15.29.0・Temurin 21 JRE）
- 2026-11-10 きょうやることを先に決める変更のときの結果: その1 100項目・その2 53項目・その3 35項目・その4 49項目・その5 12項目、すべて合格（同じ環境。自由タイムの話したいの印を外したあと）
- 2026-11-10 ニュースに写真（Wikimedia Commons）を足したときの結果: その1 100・その2 53・その3 35・その4 51・その5 12、すべて合格
- 2026-11-10 使いやすさの見直し（参加者の一覧を1人1行・大きいボタンで「せーので見せる → 答えを見せる → 次へ」・時刻）のときの結果: その1 106・その2 53・その3 35・その4 51・その5 12、すべて合格。`nextMain` は、伏せて集める画面では画面が変わるまで大きいボタンを押す

## 手で触って確かめる（本番に書かない）

1. 上の「実行」の 1・2（写しを作り、エミュレーターを起動する）
2. `.claude/launch.json` の `circle-time-emu`（作業フォルダの `site` を 6941 で配信する。手元だけの設定）でブラウザペインを開き、`http://localhost:6941/apps/circle-time/` へ
3. 開いた画面で `window.__EMU__` の projectId が `demo-roomk-ct` であることを確かめる
4. 終わったらエミュレーターと配信を止める
