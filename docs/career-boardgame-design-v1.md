# みらいルート：職業・終盤の選択・参加と進行の試作案

更新日：2026-09-27

状態：会話で検討中の企画メモ。職業の組み合わせ、配点、時間、確率は試作用の提案であり、実装・公開用の確定仕様ではない。アプリや公開コンテンツへの反映はしていない。

実装担当への入口は [全体の流れ・画面一覧・引き継ぎ](career-boardgame-handoff.md)。本書はルールと数値の詳細を扱う。

## 目的と想定

適性と職業のカードを集めるすごろく。最後に保持する職業から1つを選び、適性との組み合わせでゲーム得点を競う。未来への興味と、必要な行動を逆算する体験を両方入れる。

- ホスト1人＋参加者1〜7人。ホストは「進行のみ／自分も参加」を開始時に選ぶ。プレイヤー総数は1〜8人。
- ゲームに参加せず、最初から見学だけする人も入室できる。見学者はプレイヤー定員・手番・時間チップ・得点の対象に含めない。
- 開始時に人数、ホストの役割、手番上限、選択時間、ライフイベントの有無を選ぶ。追加案では進路イベントと暮らしのイベントを別々に設定する。
- 1回のスキップ、一時的な見学、途中復帰、今回の参加終了を扱う。獲得済みのカードを没収しない。
- 45分以内を設計目標とする。所要時間は未実測。
- 選択・イベント・振り返りはすべて選択式。自由記述や理由説明を進行条件にしない。
- 適性カードは今回のゲーム内の持ち札。ランダムな配布や判定から、本人の実際の適性・成長を診断しない。
- 職業ごとの数値はゲーム用の組み合わせ。現実の就業条件や必要な資質を網羅したものではない。
- 内省の回答や成長評価の保存・採点・比較・自動推薦は追加しない。ゲーム得点と区別する。

## 引き継ぐゲームの骨格

1. 最初に、一覧から理想の職業を1枚選ぶ。「まだ決めない」も選べる。
2. 異なる種類の適性カードをランダムに3枚受け取る。
3. ランダムな職業候補3枚から1枚を選び、当面の目標にする。
4. サイコロで進み、分岐とマスで行動を選ぶ。
5. 適性の成長・新しい適性の発見・職業の追加・コラボ・ライフイベントを経験する。進学・就職を扱う進路イベントも追加候補にする。
6. 職業・適性カードを保持しながら、目標を見直せる。
7. 最後に職業を1つ選び、手札で通常得点を計算する。終盤の逆転ルールは下記の比較案で検討する。

理想の職業も保持する職業の1枚に含める案。「まだ決めない」の場合は、ゲーム用の職業をランダムに1枚受け取り、本人の理想としては扱わない。どちらの場合も初期の職業カードは2枚になる。理想だからという特別加点は付けない。初期の理想を途中で差し替えられるかは未確定。

職業は参加者同士で重複してよい。誰かが選んでも他の参加者の候補から消えない。各プレイヤーの追加候補では、自分が既に持つ職業を除く。残りが3種類未満なら、その種類だけを提示する。

## 適性カード

| 種類 | カードに添える説明 |
|---|---|
| アイデア | 新しいことや、おもしろいことを思いつく |
| 気づく力 | よく見たり聞いたりして、違いや特徴を見つける |
| ものづくり | 考えたことを作品や形にする |
| コミュニケーション | 自分の考えを伝えたり、相手の話を聞いたりする |
| 協力する力 | 役割を分けたり、助け合ったりして一緒に進める |
| 工夫する力 | もっとやりやすくなる方法を考えて試す |

試作では各種類3枚まで。同じ適性の4枚目以降は増やさず、3個の枠で量を見せる。職業の達成や変更で適性カードを消費しない。

初期・追加の候補は基本3枚ずつ提示する。理想の職業を選ぶ一覧では「別の候補を見る」を使えるようにし、24枚を一度に読み比べなくても進められるようにする。手札から最適な職業を自動推薦する仕組みは設けない。

### 通常得点の計算

- 2点の適性：持っている枚数 × 2点（最大3枚、6点）
- 1点の適性2種類：それぞれの枚数 × 1点（各最大3枚、計6点）
- 上記3種類を1枚以上ずつ持つ：組み合わせボーナス3点
- 最大15点。同点は同順位。
- 選ばなかった職業の得点や、対象外の適性の点数は合算しない。
- カードに示す枠と点を見て計算できる形にし、暗算を進行条件にしない。

式：2 × 中心の枚数 ＋ 関連Aの枚数 ＋ 関連Bの枚数 ＋ 3種類がそろったときの3点。

従来の「5枠を埋めて完成」の案から、最後に1職業だけ選ぶ前提で配点を組み直した。1種類を伸ばす行動も、欠けた種類を発見する行動も得点につながる。

### 成長と新しい発見の選び分け

「ものづくり2枚・工夫する力1枚」を持ってエンジニアを選ぶと、現時点では4点。

- 工夫する力を1枚追加：6点（+2点）。
- 新しく協力する力を1枚追加：8点（カード+1点、3種類のボーナス+3点）。

この手札では新しい適性の発見に価値がある。3種類がそろった後は、2点の適性を伸ばす作戦も有効になる。

## 途中で敗北が確定しにくい終盤の設計

進行中は順位表と「1位との差」を出さず、自分の手札・目標・残り時間を中心に表示する。画面共有では手札から点数を推測できるため、この表示方針だけで敗北確定を防げるとは扱わない。

通常得点15点の相手がいるとき、残りの行動で13点までしか届かない人は、点数を隠しても逆転できない。カードの取り直しや最後の小さな加点だけで、どの状態からも逆転できるとは限らない。逆転の強さについてユーザーに選択を尋ねており、現時点ではAを具体的な試作提案として置き、Bも比較する。

### A：最後に全員が同点1位を狙える案

最終職業を選び、通常得点を計算した後に、全員が「仕上げチャレンジ」を1回行える。成功した人の最終得点は15点。失敗した場合は通常得点を維持する。すでに15点の人はそのままでよい。

| 選んだ職業の通常得点 | サイコロで成功する出目 | 成功確率 |
|---|---|---:|
| 0〜5点 | 6 | 1/6 |
| 6〜10点 | 5・6 | 2/6 |
| 11〜14点 | 4・5・6 | 3/6 |
| 15点 | 追加判定不要 | そのまま15点 |

- 高い通常得点ほど、失敗したときの得点も成功率も高くなる。通常得点の準備に意味を残す。
- 時間チップを消費せず、全員1回。同じ職業でも人ごとに判定する。
- 生活カードや既存の適性による補正をこのサイコロには加えない。振り直しや複数回挑戦は認めない。
- 同点1位を認める。全員の選択と判定を処理してから、まとめて結果を出す。
- 参加者が選ばなければ挑戦を飛ばせる。時間切れで自動的にサイコロを振らない。
- その回の登録プレイヤーが一時的な見学から戻り、最後の職業を選んだ場合は同じ条件で参加できる。見学専用で入室した人は、この回のチャレンジや得点集計の対象にしない。
- ゲーム上の仕上げに成功する演出であり、その職業に就けるか、本人の適性があるかの判定にはしない。

通常得点0〜14点のすべてについて、まだこのサイコロを振っていなければ15点に到達する目が最低1つある。したがって「他の人が15点だから、もう同点1位にも届かない」という状態を避けられる。単独優勝や、必ず勝てることを保証するルールではない。

運の影響が強く、低い通常得点から大きく追いつく場合や、複数人が同点1位になる場合がある。手札を育てた手応えが薄くならないか、終盤だけ復帰した人への受け止め方も含めて試遊で確認する。確率を本人に隠して操作したり、負けそうな人だけ出目を書き換えたりはしない。

### B：育成と職業選択で追いつく案

比較案として通常得点の計算を維持し、次の救済を用意する。

- イベントのサイコロ判定でカードを1枚も獲得できなかったときだけ「再挑戦チップ」を1枚得る。本人のスキップや時間切れでは得ない。
- 最後に再挑戦チップ最大2枚を、それぞれ好きな適性1枚に替えられる。適性の上限3枚は守る。
- 全員に最後の職業候補3枚から1枚を追加する機会を用意し、保持した職業から最後の1枚を選ぶ。
- 新しい適性や職業との組み合わせで得点を伸ばす。大きなサイコロ加点は付けない。

この案は育成の積み重ねを残しやすい一方、点差と残り資源によっては途中で同点1位に届かなくなる。厳密に「最後まで敗北が確定しない」を優先する場合はAが適合する。AとBの両方を初回から重ねて実施しない。

## ホストの役割と人数

- 進行のみ：ホストはカードや得点を持たず、参加者1〜7人で遊ぶ。
- 自分も参加：ホストも同じ初期カード、時間チップ、選択、判定、得点ルールで遊ぶ。参加者1〜7人にホストを加え、2〜8人のゲームになる。
- 人数別の手番数と時間見積もりは、ホストを含めた実際のプレイヤー総数で計算する。
- ホストが自分の手番をスキップ・見学にしても、進行操作は使える。参加しない人のカードを勝手に選び直す操作は設けない。

### ゲームに参加しない見学者

同じルームコードの入室画面で「ゲームに参加する／見学する」を選べるようにする。見学者は開始前・進行中・結果表示中のいずれでも入退室でき、途中入室時は現在の盤面とイベントから見られる。過去の操作を再生し終わるまで待たせない。

| 項目 | 見学者の扱い |
|---|---|
| 表示するもの | 公開盤面、現在の手番、現在のイベントと公開選択肢、確定したサイコロ結果、公開済みのカード獲得、全員に公開した最終結果 |
| 表示しないもの | 途中順位・点差、未公開の選択や結果、ホストの進行操作・管理用情報 |
| 操作 | 自分の画面での説明やカード詳細の確認、退室。サイコロ・行動選択・カード獲得・進行変更は行えない |
| 人数 | プレイヤー数と別に「見学○人」と表示。ホストは見学者一覧を確認できる |
| 手番・時間 | 順番を作らず、時間チップも配らない。人数別の手番数や時間見積もりを変更しない |
| イベント・結果 | コラボの招待先、ライフイベントの対象、最終職業選択、逆転チャレンジ、順位の対象にしない |
| 入退室・切断 | ゲームのタイマー、進行、全員の選択待ち、終了判定に影響させない |

見学画面の情報は公開中のゲーム画面に合わせる。見学者だけが先に最終得点や非公開情報を見られる仕組みにしない。本人の内省や振り返りの回答を見学画面へ追加表示する機能は設けない。

見学者が何人いても、プレイヤーが1人なら1人モードを使う。見学者だけではゲームを開始せず、プレイヤー全員が終了・見学に切り替えたときに見学者の入力を待たない。

### 最初からの見学と、プレイヤーの一時的な見学

- 見学専用：この回の手札・残り時間・席を持たない。
- プレイヤーの一時的な見学：もともとの手札・席・残り時間を保持し、下記の復帰ルールを使う。
- 開始前なら、本人の希望に応じてホストが見学者をプレイヤーに切り替えられる。定員を確認し、人数別の推奨設定を更新してから開始する。
- 進行中の新規見学者がプレイしたくなった場合、初回仕様では次のゲームから参加する。途中で新しい手札や追加手番を作る処理は加えない。
- 既存プレイヤーが見学してから戻る場合は新規参加として扱わず、元の手札と残り時間で復帰する。

見学者の接続上限はプレイヤー定員と別に扱い、想定端末と同期方式を決めてから負荷確認で設定する。無制限に接続できるとは扱わない。応援ボタンやチャットなど、見学者からの追加操作は今回の基本仕様には含めない。

### プレイヤーが1人のとき

ホストが進行のみで参加者1人の場合、ホストは架空の「仕事仲間」の役も担う。コラボマスでは参加者が役割を選び、自分の判定だけを行う。相棒のカード・得点・サイコロ判定は追加しない。

処理は通常手番内なので時間1枚に含める。成長、発見、職業の追加、ライフイベント、最後の職業選択は同じルールを使う。最後はゲーム得点を表示し、架空の対戦相手や順位を作らない。ほかの人が見学・終了に切り替えて1人になった場合も同じ形で続けられる。

## 人数・手番・所要時間

### 開始時の設定

- ホストの役割：進行のみ／自分も参加。
- 参加者数：1〜7人。実際のプレイヤー総数も併記する。
- 見学者数は別表示とし、プレイヤー数には加算しない。
- 手番上限：4・5・6・8・10回。全プレイヤーに同じ枚数の時間チップを配る。
- 選択時間：制限なし／30秒／45秒／60秒。初期案は30秒＋希望時に15秒の延長1回。
- 暮らしのイベント：あり／なし。
- 進路イベント：あり／なしを追加する案。回数・表示タイミングは下記「進学・就職を扱う進路イベント」で検討する。

設定する回数は各人が使える時間の総量であり、通常手番の上限。コラボの招待を受けると、その分だけ残りの通常手番は減る。表示例は「使える時間：6回分」。初期値を人数から提示し、ホストが変更できる。設定の異なる回の点数は比較しない。

### 人数別の初期値

最終職業の選択と終盤の処理のために、以前の見積もりより集計枠を2分増やす。仮の計算式は「19分＋プレイヤー総数×時間チップ枚数×0.75分」。

| プレイヤー総数（参加するホストを含む） | 1人の時間チップ | 全員分の消費機会の上限 | 1枚45秒・その他19分の見積もり |
|---|---:|---:|---:|
| 1人 | 8枚 | 8回 | 約25分 |
| 2人 | 8枚 | 16回 | 約31分 |
| 3人 | 8枚 | 24回 | 約37分 |
| 4人 | 6枚 | 24回 | 約37分 |
| 5人 | 6枚 | 30回 | 約42分 |
| 6人 | 5枚 | 30回 | 約42分 |
| 7人 | 4枚 | 28回 | 約40分 |
| 8人 | 4枚 | 32回 | 約43分 |

7人で5枚の場合は約45分15秒、8人で5枚なら約49分。機能が増えた現段階では7〜8人は4枚から試す。カードや説明を簡潔にして5枚で遊べるか、45分の実測で確認する。4回では職業や適性の変化が少なすぎないかも試遊対象にする。

通常手番は1枚。誘われてコラボに参加する場合も1枚。主催者はその通常手番で支払った1枚に含み、追加では支払わない。2人のコラボは合計2枚を消費するため、上の計算では90秒分に相当する。

| 内容 | 45分枠の目安 |
|---|---:|
| 説明・選択とサイコロの実演 | 5分 |
| 理想の選択・初期配布・当面の目標選択 | 5分 |
| すごろく本編 | 最大26分 |
| 最終職業の選択・終盤の処理・得点計算 | 5分 |
| 選択式の振り返り | 2分 |
| 予備 | 2分 |
| 合計 | 45分 |

45秒は読み上げ、選択、移動、判定、カード処理の平均時間の仮定。選択タイマーが30秒でも、1手番全体が30秒になるわけではない。全員が毎回延長する場合、ホスト自身も遊ぶ場合、ライフイベントを説明する場合などは、この見積もりを超え得る。実測なしに45分以内を保証しない。

### 時間チップと早めの終了

- 通常手番の開始時に1枚消費する。手番内でスキップや時間切れになっても二重には消費しない。
- 招待されたコラボは、内容とコストを見て「参加する／今回は見送る」を選ぶ。参加したときだけ1枚消費する。
- 判定でカードを獲得できなかった場合も使用した時間は戻らない。
- 時間がなくなった人の通常手番とコラボ参加は終了。最終職業の選択と終盤の処理は全員一緒に行う。
- ホストは本編中に「次の1周で終了」を宣言できる。宣言時点の順番に沿って、残り時間のあるプレイヤーに通常手番を1回ずつ用意し、その後に全員で終盤へ進む。スキップした手番を後から追加しない。
- 時間チップの追加、カードの再配布、進行の巻き戻しを、途中復帰の自動処理として行わない。

## スキップ・見学・復帰

この節の「見学」は、その回の登録プレイヤーが一時的に休む操作。見学専用の入室者には手番も時間チップ消費も発生しない。

| 操作・状態 | 進行とカードの扱い |
|---|---|
| 今回の手番をスキップ | 時間1枚を使って次の人へ。獲得済みのカードを保持。次の自分の順番には戻る |
| しばらく見学 | 順番が来たら自動でスキップし、その回の時間1枚を消費。コラボの招待対象から外す |
| 戻る | 本編中なら次の自分の順番から再開。手札・残り時間・生活効果を引き継ぐ |
| 今回の参加を終える | 以降の手番・招待・入力待ちから外す。未使用時間を他の人に配らない |
| 通信や端末の操作が止まった | ホストがタイマーを一時停止し、本人の意向に応じて再開・スキップ・見学を選べる |

手番開始前から見学中の人も、その人の順番に残り時間があれば1枚減らす。全員が見学・終了状態なら待ち続けず、ホストが休憩または本編終了を選ぶ。残り1人なら1人モードの進め方で続けられる。

復帰で失った手番は補充しないが、カードの没収や追加の減点はしない。残り時間が0でも、最後の職業選択と終盤の処理には参加できる。本編終了後に復帰しても、本編の手番を取り戻す形では延長しない。

途中で見学・終了した人について、結果画面に自動で「最下位」「0点」「敗北」を付けない。終盤に戻って結果を出すかは本人が選ぶ。参加しない人の内省を自動入力しない。

コラボの招待を断ることは、自分の通常手番のスキップとは別。招待の見送りや返答の時間切れでは時間を消費せず、主催者は1人でそのイベントを続けられる。途中で相手が見学になっても主催者の進行を止めない。

## 選択時間と迷ったときの操作

- 説明を読み終え、選択肢がそろってから計測を始める。
- 通常手番中の選択時間は合計で30秒などにする。画面が切り替わるたびに制限時間を丸ごと補充しない。
- 自分から「もう少し考える」を選ぶと、1手番につき1回だけ15秒延長できる。
- 「おまかせ」を本人が選んだ場合、ゲーム上の移動・役割・適性などの有効な候補からランダムに1つ選ぶ。能力診断や職業推薦として選ばない。
- 結婚・購入・子どもに関する生活プランは「おまかせ」で決めず、保留・変更しない選択にする。
- 制限時間を過ぎたら追加減点をせず、その手番の未実行部分をスキップして進める。確定済みの移動・判定・獲得は取り消さない。未選択の職業カードや適性カードを勝手に追加しない。
- 時間切れのときに不利益のある生活プランを自動で受け入れない。未選択のライフイベントは見送る。
- コラボの招待返答は10秒を目安にし、返答がなければ今回は見送り。2人が役割を選ぶ時間は別に確保し、そのイベントで全員に順番に招待を送り直さない。
- ホストは読み上げや機器のトラブルでは一時停止できる。本人の迷いに対する延長は上記の15秒を基本とし、時間設定そのものは開始前に選ぶ。
- 初期の理想・最終職業・振り返りは、通常手番のタイマーとは別に扱う。全体で各1分程度の選択枠を取り、理想や振り返りは「まだ決めない／今回はパス」で進める。最終職業は本人が「今の目標で決める」を選べる。無反応なら参加を保留し、他の人を待たせない。

タイマーは静かな残り時間表示を基本とし、減点や大きな警告音とは結び付けない。初回から全員に同じ制限を強制せず、制限なしもホスト設定に残す。

## マスとイベントの試作方針

| マス | 処理案 |
|---|---|
| 適性を伸ばす | 持っている適性のうち上限未満のものを選び、1枚追加 |
| 新しい体験 | 上限未満の適性候補3種類から1枚選んで追加。初めての種類も出る |
| 職業との出会い | 未保持の職業候補3枚から1枚を追加。当面の目標も選び直せる |
| 個人イベント | 取り組む役割を選び、サイコロで結果を判定 |
| コラボイベント | 相手1人を誘い、それぞれ役割を選んで結果を判定 |
| 暮らしのイベント | 暮らしの選択肢と効果を見て選ぶ。次の成長判定に一時的な変化がつく |

追加する進路イベントは、上記のランダムなマスと区別し、序盤・中盤の節目に出す案。下記の回数・時間の設計を決めてから盤面へ統合する。

伸ばせる既存の適性がない場合や、職業を全種類保持している場合の代替処理、マスの比率と盤面の長さは未確定。選択不能な手番を作らない方向で詰める。

コラボは1イベントにつき最大2人、招待は1回まで。相手が見送った場合や、参加可能な相手がいない場合は、主催者が1人で同じイベントに挑戦できる案。見送りによる減点はない。

### サイコロ判定の調整案

通常の成長マスは確定で1枚もらえるため、イベントが「成功しても1枚、失敗なら0枚」だけでは選ぶ意味が薄くなる可能性がある。試作では成功時に2枚を獲得する案を置く。

| 判定結果 | 効果 |
|---|---|
| 5〜6 | 狙った適性を2枚獲得（各適性3枚の上限まで） |
| 3〜4 | 別の適性候補2種類から1枚を選んで獲得 |
| 1〜2 | 今回の適性カード獲得なし |

- 狙った適性を既に持つ場合、出目に+1。持つ枚数によって補正を重ねない。
- ライフイベントの補正がある場合は合算する。現在の案では合計補正は-1〜+2、最終的な判定値は1〜6に収める。
- 判定前に選択肢と報酬、時間コストを見せる。
- 移動用とイベント判定用のサイコロは別に振る。
- コラボでは2人が個別に役割を選び、個別に判定する。
- 結果は今回のゲームの挑戦に限定し、本人の向き・不向きを判定しない。

ライフイベント補正がなく、上限による切り捨てを考えない場合、新しい適性への挑戦の期待獲得枚数は1枚、既存の適性を使う場合は約1.33枚。ただし、狙った適性と別の適性の価値は手札ごとに異なり、上限付近では獲得枚数も下がる。この計算だけではイベントの有利・不利は確定しない。

## ライフイベントの追加案：暮らし

ユーザーの希望に沿い、結婚、自動車購入、家の購入、子どもの誕生を検討対象に加える。追加希望の高校入学・大学進学・専門学校・就職は、次節の「進路イベント」として分けて検討する。ここでは企画案として扱い、本体コンテンツへの投入は行わない。

### 暮らしの選択と、時間を使う活動を結び付ける

結婚や購入の有無そのものを得点化せず、その暮らしで選んだ活動が、適性を伸ばす機会に影響する設定にする。取得済みの適性が減る仕組みにはしない。

イベントは「これから選べる暮らしのプラン」として提示する。実生活の希望や家族構成を答える必要はなく、今回のキャラクターの選択として遊べる。結婚や子どもの誕生を、サイコロだけで強制的に発生させない。

| 暮らしの場面 | 時間を使う活動の選択肢例 | 成長判定が有利になる適性の例 |
|---|---|---|
| 結婚して新しい暮らしを始める | 役割を話し合う／分担して準備する | コミュニケーション／協力する力 |
| 自動車を購入する | 新しい場所へ出かける／移動の方法を工夫する | 気づく力／工夫する力 |
| 家を購入する | 作業場所を整える／空間の使い方を考える | ものづくり／アイデア |
| 子どもを迎える・子どもが生まれる | 世話の役割を分担する／日々の変化を見つける | 協力する力／気づく力 |

各場面では、上記の活動2案と「今回はこのプランを選ばない」の計3択を基本とする。活動を選ぶと、その活動に対応する1種類が成長しやすくなる。

共同生活、車を必要なときだけ借りる、借りた住まいを整える、地域で子どもに関わる活動などにも同じ仕組みのイベントを用意できる。特定の家族構成や所有の有無だけが、高得点への必須条件にならないようにする。これらの具体的なカードの収録範囲と頻度は未確定。

### 一時的な成長補正

初回は、どの生活プランも同じ強さの効果から試す。

- 選んだ活動に対応する適性を狙う判定：出目に+1。
- それ以外の適性を狙う判定：出目に-1。
- 自分の次の2回のイベント判定に適用し、その後解除する。コラボ中の自分の判定も数える。
- マスで確定獲得するカード、移動の出目、職業の追加、最終得点計算には補正を掛けない。
- 新しい生活プランを選んだら、前の補正を置き換える。重ね掛けや残り回数の足し算はしない。
- 「今回は選ばない」場合は新しい補正を付けない。既存の補正がある場合、その残り回数は変えない。
- 判定が失敗でも1回分を消費する。終了時に残った効果を得点や減点に変換しない。
- ライフイベントの選択はその通常手番の時間1枚に含め、追加の時間チップは要求しない。

これは「今はある活動に時間を使うので、ほかの活動を試す余裕が少し減る」というゲーム上の時間配分を表す。結婚や子育てで本人の能力が必ず上下する、という意味にはしない。

例：新しい暮らしの役割を相談するプランを選ぶと、次の2判定ではコミュニケーションを狙う出目に+1、それ以外を狙う出目に-1。すでにコミュニケーションを持っていれば、既存適性による+1と合わせて+2になる。いま必要な適性と生活プランが合うか、別の発見も狙いたいかを考えて選ぶ。

### 時間とバランスの未検証点

- 初回の暮らしのイベントは1人1回までを提案。2回目以降に同じ種別のマスに止まったら「新しい体験」の処理に置き換える。進路イベントは別の回数枠で検討する。複数の暮らしのイベントが続く構成は、少人数・長めの設定で別途試す。
- 選択で通常手番を1回使うので、残り時間が少ない場合は補正を使う機会がない可能性がある。効果と残り時間を見て選べる表示が必要。十分な判定機会が来る盤面かも確認する。
- 特定の適性が対象になる回数が偏らないよう、上の4場面以外の候補も含め、全体の出現率を調整する。
- +1/-1の補正が強すぎないか、使わない選択が常に有利にならないか、時間の見積もりも含めて試遊で確認する。

## 進学・就職を扱う進路イベントの追加案

ユーザーの追加希望：高校入学、大学進学、専門学校、就職などもライフプランに含め、普通科や専門分野などの選択が、ゲーム内の適性の変化につながるようにしたい。

今回の明示的な要望に沿って、学校名・学科名・進学と就職を扱う企画案を追加する。進路の正解や本人の適職を判定するものにはしない。学科名などの用語と、ゲーム用に作る効果を区別する。

### 進路の種類と、そこで選ぶ活動を分ける

高校の学科として普通科・専門学科・総合学科を区別する。専門学校（専修学校専門課程）は、これらの高校の学科とは別に扱う。制度用語の確認元は文部科学省の [総合学科について](https://www.mext.go.jp/a_menu/shotou/kaikaku/seido/04033101.htm) と [専門学校のことが知りたい](https://shirusen.mext.go.jp/senmon/)。確認日：2026-09-27。

ゲーム上の流れは、次の2つの節目に分ける案。

1. 序盤：高校などの進路と、そこでやってみる活動を選ぶ。
2. 中盤：大学・短大、専門学校、就職などの次の進路と、そこでやってみる活動を選ぶ。

これは試作用に整理した進路の例であり、現実の進路をすべて網羅した分類ではない。「高校→大学→就職」を全員共通の必須ルートにはしない。高専・高等専修学校などを追加する場合は別の種類として整理し、高校の専門学科や専門学校と混ぜない。現実の入学条件・修業年限・資格要件を、この簡略化したゲームだけで説明したことにしない。

### カードの例

以下はゲーム内で選べる活動と、得られる適性カードの例。同じ進路にも複数の活動を置き、学校種や学科名だけで適性を固定しない。下記の活動は他の進路にも登場してよい。

| 進路の例 | 活動の選択肢例 | 選んだ活動で得るカード |
|---|---|---|
| 高校・普通科 | 身近な場所を観察する／イベントの案を考える | 気づく力／アイデア |
| 高校・専門学科（工業系） | 道具を使って作品を組み立てる／作り方を改良する | ものづくり／工夫する力 |
| 高校・専門学科（商業系） | 品物の魅力を紹介する／展示の役割を分担する | コミュニケーション／協力する力 |
| 高校・総合学科 | 作品づくりと発表を組み合わせ、どちらに取り組むか選ぶ | ものづくり／コミュニケーション |
| 大学・短大 | 気になるテーマを調べる／仲間と調査を進める | 気づく力／協力する力 |
| 専門学校（デザイン分野の例） | デザインの案を考える／作品を形にする | アイデア／ものづくり |
| 就職 | お客さんに使い方を説明する／作業の手順を改善する | コミュニケーション／工夫する力 |

特定の進路の優劣や実際の教育効果を数値化した表ではない。同じ職業を目指す場合も、異なる進路や活動で適性カードを集められるようにする。

### 最初に試す効果

複雑さを増やしすぎないよう、進路イベントでは活動を選んで対応する適性カードを1枚得る、という案から試す。

- 持っている適性なら成長、持っていない適性なら新しい発見になる。各種類3枚の上限を守る。
- どの進路も基本は同じ1枚。大学を選んだこと自体への追加得点や、就職を選んだことへの減点は付けない。
- 進路の選択時に、取得済みの適性や職業カードを失わせない。進路名だけで最終職業の候補を除外しない。
- この確定獲得にサイコロ判定や暮らしの+1/-1は適用しない。既存の暮らしの効果の残り回数も消費しない。
- 進路による継続的な成長補正は、最初の試作では重ねない。必要なら、体験カードの候補が変わる追加案として後で比較する。
- 対応する適性が上限なら、確定前に上限であることと、ほかの体験を選べることを見せる。代替候補の具体的な作り方は、既存の上限時の代替処理と合わせて決める。
- 「今回は進路を決めない」場合も、学校・就職のラベルを付けずに共通の体験を選べる案にする。同じ1枚の獲得機会を持たせる。体験自体もスキップできる。

例：ものづくりを持たない人が、工業系の進路で「作品を組み立てる」を選ぶと、ものづくりを1枚発見する。同じ進路でも「作り方を改良する」を選べば工夫する力が増える。デザイン分野や地域の制作体験からも、ものづくりを得られる。

### 就職と最後の職業選択の関係

中盤の「就職」は、ゲーム中に仕事を経験するルート。最終職業をそこで固定しない。保持する職業から当面の目標を確認し、ほかのルートと同様に、以後も職業との出会いや目標変更を使えるようにする。

進学後の就職や、働いた後に別の学び・仕事を選ぶ場面も表せる。これらの再選択を何回入れるか、カード名と説明をどうするかは未確定であり、初回から追加の手番を無制限に増やさない。

### UIと45分枠への組み込み

- 「どの進路を試す？」→「そこで何をしてみる？」の順に選ぶ。各画面の候補は基本3つ以内に絞り、「別の候補を見る」と「今回は決めない」を使えるようにする。学校の種類を一画面に詰め込まない。
- 選択肢には進路名に加えて、体験の短い説明と得られるカードを表示する。本人の実際の志望校や進路希望を答える必要はない。
- 進路カードの表示はゲーム中のルート確認のために使う。本人の進路希望としての記録や、適職・学校の自動推薦には使わない。
- 序盤・中盤の2回を入れる案では、既存の通常手番を進路選択の手番に置き換え、時間チップ1枚で処理する。その手番に通常の移動・ランダムマスの処理を追加しない。進路を決めない共通体験でも同じ扱いにする。
- 4回設定で2回を進路選択にすると、自由な移動・コラボなどの機会が少なくなる。短い設定では進路イベント1回にまとめる案も比較し、回数を確定する。
- コラボ参加で時間が減った人への節目の提示、進路選択前に休んだ人の復帰、序盤・中盤の発火条件は未確定。残り時間を超えて進路手番を追加したり、見学専用の人へ選択を要求したりしない。
- 2段階の選択による読み上げ・操作時間を実測する。既存の1手番45秒という仮定と、45分全体の見積もりを更新する。機能を足しても45分以内だとは扱わない。

### 追加の試遊項目

1. 学校の種類の違いと、ゲーム上の獲得カードの例を区別して理解できるか。
2. 同じ進路でも違う適性を伸ばせ、違う進路からも同じ職業を目指せるか。
3. 高校での選択が、その後の進学・就職や最終職業を固定してしまわないか。
4. 進路を決めない・体験をパスする場合も、進行が止まらないか。
5. 進路2回と暮らしのイベントを入れても、成長・発見・コラボ・職業追加を試す機会が残るか。1〜8人で45分枠に収まるか。

## プレイヤー向けUI・UXの提案

2026-09-27の画面案。ゲーム本体の実装ではなく、配置・文言・操作の流れを検討するもの。

### 今やることを中心にした、落ち着いたボードゲーム

既存のroom-Kの配色を使い、生成りの背景、白いカード、紺の主要ボタン、青緑の選択状態を基本にする。少し丸みのあるカードと、街を巡るような盤面で遊びの雰囲気を作る。中学生にも合う通常の漢字表記にし、幼いキャラクターや装飾を増やしすぎない。

- PCでは上部に現在地と近くのマス、中央にイベントと選択肢、横に自分のカードを置く。盤面全体や他プレイヤーの詳細は必要なときに開く。
- スマートフォンでは「誰の番か→イベント→選択肢→決定」の縦並び。手札は押すと開く。PCの盤面をそのまま縮小しない。
- 最初に適性をすべて覚えさせず、その場で関係する適性を選択肢に添える。詳細な配点や判定説明は選択時・確認時に段階的に見せる。
- 選択肢は基本3つ。同じ強さの見た目で①②③を付け、口頭でも選べるようにする。選択中は色に加えて「選択中」の文字を出す。
- 選ぶだけでは確定せず、「これにする」を1つの主要ボタンにする。確定前は選び直せる。主要ボタンの位置と押す順序をなるべくそろえる。
- 適性は6種類のカード枚数として見せる。各種類は3個の枠と数字を併記する。能力偏差値、本人の適職診断、他人との成長比較に見える表示にしない。
- 職業は収集したカードとして見せ、最初の理想と今の目標を区別する。24職業全部を毎回並べず、通常の追加候補は3枚。得点上の効果はゲームのルールとして説明する。

### 選択の前後に見せる情報

1. 選択前：何をするか、狙える適性、必要な時間チップ、一時的な補正。
2. 選択後：選んだ行動の確認と、今回のサイコロ判定で起こること。
3. 結果：出目と補正、増えたカード、更新後の手札。未獲得なら「今回は、カードの獲得なし」とする。

新しい適性の発見と、持っている適性が増えることを同じ程度に喜べる演出にする。結果演出は短く、音は任意。動きを減らす設定でも結果が読めること。カードをドラッグしないと遊べない操作は採用しない。

### アニメーションの使い方

ユーザーの希望に沿い、操作への反応とゲーム内の変化が伝わる場面に短い動きを加える。以下の時間は試作上の目安。

| 場面 | 動きの案 | 時間の目安 | 今回の画面案 |
|---|---|---|---|
| 選択肢を選んだ | 選んだ番号が少し大きくなって戻る。選択状態の枠と文字は残す | 180ms | 追加 |
| 次の操作へ切り替わる | 内容をわずかに下から表示する | 200ms | 判定準備に追加 |
| サイコロの結果 | 確定した出目のサイコロが軽く回転して止まる | 500ms | 追加 |
| 適性カードの獲得 | 新しく埋まったカード枠が小さく現れる。手札を閉じているときは見出しだけで知らせる | 350ms | 追加 |
| 盤面での移動 | 駒を通るマスに沿って動かし、止まったマス名を表示する | 全体で600ms程度まで | 本体での実装候補 |
| 職業カードの追加 | 選んだ職業から手札へのつながりがわかる短い移動 | 300〜400ms | 本体での実装候補 |

- アニメーションは確定した状態を見せるためのもの。出目・カード枚数・時間チップの更新を演出終了待ちにしない。演出を飛ばしても結果は同じ。
- 操作を妨げず、結果と次の操作をすぐ表示する。演出だけのために追加の確認ボタンや待ち時間を設けない。連打で判定・獲得が重複しないようにする。
- 端末の「動きを減らす」設定を尊重し、画面内からも減らせる。動きを減らした場合は、確定した出目・選択中の文字・獲得した枚数を静止表示する。変更時は再生中の動きも止める。
- 初期表示・待機・見学・タイマーを常時動かさない。画面全体の揺れ、点滅、失敗時の大きな演出、長い紙吹雪は使わない。音は自動再生しない。
- 移動や獲得は一度の操作につき一度だけ見せる。再接続や画面の再表示で、過去の演出を繰り返さない。
- 動く対象がスマートフォンで画面外にある場合、強制スクロールせず、表示中の結果欄で変化を伝える。

アニメーションを付けた会話用画面案も、1イベントの操作を確かめる参考の範囲。駒の移動や初期配布など、ゲーム全体の演出は本体の試作段階で確認する。

コラボへの招待には「参加すると時間チップを1枚使う」を承諾前に表示する。断る選択もすぐ見つかる場所に置く。ライフイベントでは、効果の対象・残り判定回数・別の適性への影響を明記し、「今回は選ばない」を同じ画面に置く。

### 休む・待つ・見学する体験

- 「今回はスキップ」と「しばらく見学」を、主な選択肢の近くに低い強調度で常設する。理由入力や毎回の確認ダイアログを挟まない。スキップの時間コストを先に見せる。
- 休んでいる人には「カードはそのまま」と「次の自分の番から戻る」を表示する。見学中も自分の番では時間を使うことを伝える。
- 最初からの見学者には、現在のイベント・公開された選択と結果・公開カードを見せる。サイコロや確定ボタンは表示せず、プレイヤー復帰のボタンも置かない。
- 待ち時間は、今起きていることと次の順番がわかるようにする。自分の手札や職業の説明は確認できる。待っている間の入力課題は増やさない。
- タイマーは小さな秒数と延長ボタンにする。点滅・警告音・残り秒数の赤い大表示を避ける。「選択の秒数」とゲーム内の「時間チップ」は別の名称・位置で示す。
- 途中の順位や「あと何点で負ける」は強調しない。最後の得点は内訳を示し、本人の能力の順位と混同させない。逆転の可否は画面だけで解決せず、ゲームルールと併せて検証する。

### ホストと端末ごとの役割

画面共有中心で遊ぶ場合は、イベントと選択肢の読みやすさを優先し、ホストが「②番」などの口頭選択を代わりに操作できる設計にする。各自の端末から選ぶ方式を採用する場合も、同じ番号・同じ選択肢を示す。操作方式の採用範囲は実装前に決める。

ホストには進行・一時停止・残り時間・参加状態の管理をまとめた領域を用意する。ホストもプレイヤーになる場合、自分のゲーム上の選択と、他人の進行を動かす操作を視覚的に区別する。参加者・見学者には管理操作を出さない。

主要操作は44px以上、通常本文は16px前後、問いは24〜30pxを目安にし、320px程度の幅でも横にはみ出さないようにする。キーボードでも選択・確定でき、色だけに頼らず状態が読めること。切断時は「接続を確認しています」など現在の状態を示し、再接続で確定操作を二重に実行しない。

### 画面案で確認する範囲

今回の触れる画面案は、架空の手札と1つのイベントを使った「3択→判定→手札更新」、延長表示、スキップ、一時見学を対象にする。タイマーは停止した表示例であり、他端末との同期、複数人の手番進行、全職業カード、最終結果は実装していない。画面設定から盤面の表示量と見学専用の見え方を比べられる。内省やゲーム上の回答を保存せず、画面表示の設定だけを保持する。

本体の試遊では「初見で今の操作が見つかるか」「番号だけでも参加できるか」「読んでいる途中で時間切れにならないか」「休む・戻るが説明なしでわかるか」を優先して確認する。
