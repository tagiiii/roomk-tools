# 09 判断が必要な論点（承認待ち）

Phase 2 に進む前に判断が必要なもの。各項に推奨案を付す。

| # | 論点 | 選択肢 | 推奨 |
|---|---|---|---|
| 1 | 新アプリの名称とslug | 例: 「コトバであそぼ」= apps/kotoba-asobo/ ほか | `kotoba-asobo`（ポータル表示名「コトバであそぼ」） |
| 2 | 既存 slides.html（codenames/hint-de-pinto）を新エンジンへ移行するか | 移行する / 今回は触らない | **今回は触らない**。役割が違う（ゲーム説明 vs 授業進行）。共通化は新アプリ側での再実装にとどめ、既存は安定運用を優先 |
| 3 | RTDB単一ファイルアプリ（tatoe-gp/hint-de-pinto）のお題データ外部化 | 外部化する（AGENTS.mdの単一ファイル規約を改定）/ インライン維持 | **インライン維持**。件数がまだ小さく、規約改定のコストに見合わない。100件超になったら再検討 |
| 4 | 既存ファイルの絵文字混入（slides.html 2本・lint.sh・checkin/AGENTS.md） | 本プロジェクトで掃除 / 別タスク | **別タスク**として切り出す（本プロジェクトのスコープ外。新規分は混入ゼロを機械検査） |
| 5 | 「雑学王」の位置づけ | 独立回として残す / ウォームアップ枠＋予備回に再配置 | **ウォームアップ枠＋回1・41に再配置**（02の設計どおり）。子どもたちに人気なら独立回を増やす余地あり |
| 6 | 古典題材の範囲 | 百人一首・枕草子・平家物語等の定番を使う / 避ける | **定番を使う**。教科書と重なるが「学校を連想させない」の禁止対象は場面設定・例文であり、古典作品自体は言語文化として扱う。提示の仕方を「1000年前のことば探検」に徹底し、教科書的な出題形式（現代語訳しなさい等)を使わない |
| 7 | 敬語回の場面設定 | 店・イベント・ゲーム内世界など学校以外で統一 | **店・イベント等で統一**（02回32に反映済み）。「先生に対する敬語」は使わない |
| 8 | 発表者ビューのノート編集・localStorage保存 | 既存slides同様に踏襲 / 表示専用 | **踏襲**。メンターが自分用の補足を書ける利点が大きい。実装済みコードの再利用でコスト小 |
| 9 | チェックインの実装 | 新スライド内に簡易チェックインスライドを持つ / apps/checkin/ を併用 | **スライド内に簡易版**（ウィンドウ切替を減らす）。checkin併用も可能な設計 |
| 10 | 年間開始時期 | 4月開始（学年区切り）/ 任意の時期 | **任意の時期**。各回独立設計のためどこからでも開始可（学年暦を意識させない意図もある） |
