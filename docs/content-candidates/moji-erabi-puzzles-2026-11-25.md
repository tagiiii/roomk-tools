# 文字をえらんで言葉をつくるゲーム（仮）— 問題データの候補 第2版

作成: 2026-11-25（同日、第1版から答えの数をそろえた） ／ 設計書: [moji-erabi-design-v1.md](../moji-erabi-design-v1.md)
ステータス: **オーナーが選ぶ前の候補**（本体には入れていない）

## 作り方

- 文字の組から作れる並びを**すべて書き出して**（5枚・2文字なら20通り、6枚・3文字なら120通り、7枚・3文字なら210通り、7枚・4文字なら720通り）、言葉になっているものを目で拾った
- 答えがその文字で作れること（1枚は1回まで）・文字数・重なりをスクリプトで確かめた
- 「答え」はボードに伏せて並べる言葉。「グレー」は一覧に入れず、出たらみんなで確かめてホストが OK にできる言葉。「外す」はボードに出さず、OK の候補にもしない言葉
- 動詞は辞書の形（きく・かくす）だけ入れる。「ぬいた」のような変化した形は入れない
- 人名・地名・国名は入れない
- **答えは1問8〜10個を目安にする**（協力のボードで、早く終わりすぎず、最後で止まりすぎない数）

## 気づいたこと

- #7・#9 は7個だった。文字を入れかえる案（さくらまいし／あさひかりね など）では増えなかったため、グレーの「からさ」「さかり」を答えに上げて8個にした（2026-11-25 オーナー判断）。これで全12問が8〜10個
- #10 からは、問題とは別の文字数で「かす」が作れる。ゲームでは決められた文字数の言葉しか出せないので画面には出ない
- 決められた文字数以外の悪い言葉の検査は、よく出る悪い言葉の一覧と照らしただけ。本体に入れるときは、決められた文字数で作れるすべての並びをもう一度見なおす
- 「い・か・た・ら」がよく出る（#5・#8・#10・#11 で答えが一部重なる。からい・たいこ・こたつ・いくら・だいく）。1ゲームの中で続けて出さないように並べる
