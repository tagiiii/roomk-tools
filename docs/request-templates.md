# 依頼と引き継ぎの例

## 通常の修正

```text
［対象アプリ・ファイル］の［問題］を修正してください。
期待する動作：［具体的な場面と結果］
維持する点：［既存の仕様・意図的例外・文言］
完成条件：［表示・主要操作・再接続など今回に必要な条件］
この範囲の修正と必要な検証を進め、変更点・検証結果・未検証事項を示してください。
権限判断が必要な箇所だけ保留し、進められる作業は続けてください。
```

## 点検のみ

```text
［対象］を［観点］で点検してください。ファイルは変更しないでください。
AGENTS.mdと対象アプリの固有仕様・例外を基準に、根拠のある所見を優先度順に最大5件示してください。
確認済みと推測を分け、該当がなければ問題なしで終了してください。
```

## Claude Code / Codex の引き継ぎ

```text
次の［実装／独立レビュー］を引き継いでください。
目的・次の到達点：［内容］
対象：［リポジトリ、ブランチ、コミット、未コミット差分］
承認済みの範囲・受入条件：［内容］
維持する仕様・例外：［内容］
確認済み：［検査、結果、検査対象・設定・依存関係］
未決・未検証：［内容］
次の作業：［内容］
同じ承認や未変更の検査を繰り返さず、新しい差分に影響する確認を行ってください。
```

役割と独立レビューは `ai-roles.md`、権限と品質基準はルート `AGENTS.md` が正本。単発の依頼には改善ループ全体を貼り直さない。ループを依頼する場合は `kaizen-backlog.md` の対象項目を指定する。
