# 文字をえらんで言葉をつくるゲーム（仮） 設計書 v1

作成: 2026-11-25 ／ ステータス: **同日 `apps/kotoba-hiroi/`（ことばひろい）に本体化**。本体の仕様の正本は [apps/kotoba-hiroi/AGENTS.md](../apps/kotoba-hiroi/AGENTS.md)。この設計書は検討の記録として残す

テレビ番組で見た「5文字くらいの中から、決められた文字数の言葉を見つける」ゲームから着想（2026-11-25 オーナー相談）。

---

## 0. いまのツールとのちがい

| ツール | 形 | ちがい |
|---|---|---|
| ことばシャッフル（`kotoba-shuffle`） | バラバラの文字を**全部**使って、答え1つを当てる | こちらは**一部だけ選ぶ**・答えがいくつもある |
| もじそろえゲーム（`moji-soroe`） | タイルを引いて捨てて、2・3・3文字にそろえる麻雀型 | こちらは手番なしで、同じ文字をみんなで探す |

## 1. オーナーが決めたこと（2026-11-25）

| 項目 | 決定 |
|---|---|
| 遊び方 | **協力（かくれことばボード）と個人戦（ことば取り合い）を、ホストが待合室で選べる** |
| 形 | **ルーム型**（各自の端末・RTDB）。端末のない子はホストが代わりに押す |
| 判定 | 問題ごとの**答えの一覧にある言葉は自動で正解**。一覧にない言葉は、**みんなで確かめてホストが「OK」**で入れられる |
| 制限時間 | **ホストが選ぶ。はじめは「なし」** |

## 2. 骨組み（たたき台）

- ひらがなのタイルが5〜7枚並び、「3文字の言葉」のようにお題が出る
- タイルを順にタップして言葉を作り、「これにする」で出す（キーボードを使わない。iPad・日本語入力の不具合に左右されない）
- 1枚のタイルは1つの言葉の中で1回だけ使える
- 濁点・小さい文字（っ・ゃ など）の有無で難しさを変える

### 協力（かくれことばボード）

- 答えの一覧が「○○○」の伏せたマスで並び、みんなで見つけて埋める。全部埋まればクリア
- だれが見つけたかは出さない（見つけられなかった子が目立たないように）
- 一覧にない言葉をホストが OK にしたら、ボードの外の「みんなが見つけた言葉」に足す

### 個人戦（ことば取り合い）

- 同じ文字でいっせいに探し、早く出した人の言葉になる。取られた言葉はほかの人は出せない
- 順位の数字は出さない。0個の人を並べない（ルート AGENTS.md「参加のしかたと結果の出し方」）

## 3. まだ決めていないこと

- 名前（商品名・番組名は使わない）
- 1ゲームの問題数、文字の数（5〜7）と言葉の文字数（2〜4）の組み合わせ・レベルの分け方
- 個人戦の結果画面の出し方（自分の数だけ見せる／取った言葉を並べる など）
- 一覧にない言葉を確かめる画面の形（出した人の名前を出すか。却下した言葉はだれのものか出さない）
- 問題データ（文字の組と答えの一覧）。候補は Claude が作り、オーナーが選ぶ。本体への投入は人間が行う
- 利用シーン（コトバであそぼ・ひろば・サークルタイム・ボドゲクラブ の候補）
