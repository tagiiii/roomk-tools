# ツール一覧のカードのイラスト

一覧のカードは、種類の色の面の中央に、そのツールのイラスト（`apps/assets/illustrations/{app}.webp`）を角を丸めた四角で出す（2026-11-05 から）。
画面の例（スクショ）はカードの説明（マウスを当てたとき・キーボードで選んだとき・「説明」を押したとき）に出す。撮り方は [thumbnails.md](thumbnails.md)。

## 決まり

- 絵柄は fal の Recraft V3 の手描き風（`digital_illustration/hand_drawn`）。オーナーが 2026-11-06 に平らなベクター風と見比べて選んだ。全ツールでそろえる
- 色はその種類の色2つを渡す（同じ種類どうしは色合いがそろう）
- 人・人の顔・手・文字・数字は描かない。道具や場面で、そのツールらしさを出す
- 着想元のゲームの絵・駒・キャラクターに似せない（落ちものパズルの形、宇宙船の乗組員など）
- ルート AGENTS.md のコンテンツガイドラインに合わせる（学校・こわいもの・暗すぎる場面を描かない）
- 吹き出しや丸い形に目と口が付く程度はよい（人の顔ではないため）
- 大きさは 400×400 の webp（品質80。容量は絵によって 12〜30KB ほどで、検査はしない）。カードの `<img>` は `alt=""`（名前はカードに書いてある）

## 作り方

1. `scripts/illustrations/prompts.json` に `"{app}": "英語の文"` を足す。描くもの（道具・場面）だけを書き、絵柄の指定は書かない（スクリプトが足す）
2. 環境変数 `FAL_KEY` を入れて、リポジトリのルートで実行する（Python 3 と Pillow が要る。1枚 約0.04ドル）

   ```bash
   python3 scripts/illustrations/generate.py {app}
   ```

3. できた絵を**必ず目で確かめる**。指示に「人・文字なし」と入れても、人の顔の写真・人の集まり・腕・「$」などの記号・「BINGO」の文字が出ることがある（2026-11-06 は58枚中16枚を作りなおした）。合わないときは、描くものの文を言いかえて（例: 「カード」→「何も描いていないカード」、「objects only, no crowd」を足す）作りなおす
4. `apps/index.html` のカードの `.app-card__icon` の中、アイコンのすぐ後に入れる

   ```html
   <img class="app-card__illust" src="assets/illustrations/{app}.webp" alt="" width="400" height="400" loading="lazy" decoding="async" />
   ```

イラストがないカード・読み込めなかったカードは、今までどおりカードのアイコンを白い丸で出す。「よく開かれたツール」の帯も、カードにイラストがあれば同じ絵を出す。

## 種類のタブの絵

種類のタブ（すべて・人気・6種類）の丸い印も、同じ絵柄の小さな絵（`apps/assets/illustrations/tabs/{key}.webp`、200px）にしている。CSS で `:root.tab-img-{種類} .genre-tab[data-genre="…"] .genre-tab__icon` ごとに背景として指定する。
2026-11-06 に作ったときの描くもの: すべて＝小さなゲームの道具が入ったおもちゃ箱、人気＝リボンの付いた星、ことば＝重なった2つの吹き出し、クイズ・パズル＝はまり合う2つのパズルのピース、推理＝虫めがね、当てっこ＝光る電球、カード・ボード＝2枚のトランプと丸い駒、話す＝小さなハートの付いたココアのマグ。
色は各種類の色（2026-11-06 に作ったときは、すべては `#7F9BB5`・`#3E5872`、人気は `#E2B23E`・`#7F5300`。そのあと「すべて」の色はあたたかい `#C8A97E`・`#6A5440` に変えた）。絵は読み込めたものだけアイコンと入れかえる（スクリプトが読み込みに成功した種類だけ `<html>` に `tab-img-{種類}` を付ける）。種類を足すときは、同じ絵柄でもう1つ作り、CSS の絵を出す行とアイコンを隠す行に足す（足すまではアイコンが出る）。

この絵柄は枠いっぱいに描かれやすい。カードでは角を丸めた四角として面の中央に置くので、絵の端が切れていてもよい。描くものの主役がまん中に大きく入っているかを見る。

## ツールのはじめの画面

2026-11-06 から、各ツールのはじめの画面にも、ツール一覧のカードと同じ絵を出す（「ツールの中が無機質に感じる」という声から。オーナー判断）。
一覧のカードの頭と同じ組み方（種類の淡い色の面の中央に、角を丸めた絵）で、入口の型 `.app-entry` の上の端に置く（[ui.md](ui.md)「トップ画面の定石」）。見た目は design-system.css の「M-7」にある。

```html
<body data-genre="talk">
…
<section class="app-entry">
  <div class="app-hero"><img class="app-illust" src="../assets/illustrations/{app}.webp" alt="" width="156" height="156" decoding="async" onerror="this.parentNode.remove()" /></div>
  <h1 class="app-title">ツール名</h1>
  …
```

- 絵が読めないときは絵の面ごと消える。型を使わない画面で元のアイコンに戻したいときは、アイコンに `app-hero-fallback` を付けて絵の面と同じ親に置く（絵の面があるあいだは隠れる）
- はじめの画面でそのまま遊ぶツール（カードを並べるトークテーマカードなど）は `app-hero app-hero--compact` にし、img の幅と高さを 92 にする
- img の `width`・`height` は表示の大きさ（156 か 92）にする（古い CSS が残った端末でも大きく出ないように）
- 「みんなにみせる画面」など、ほかの入口の画面には出さない
