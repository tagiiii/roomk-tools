## 手順と結果

1. TOP の「同音異義語クイズ（難しめ）手ごたえあり」を選び、「ぜんぶ」→「スタート」。20問・ふつうの設定になった。
2. 画面に出た問題を順に回答し「次の問題へ」で進め、初回は Q8 / 20 で do08 に到達。
3. 問題文 `橋をかけることを表す熟語「かきょう」。漢字で書くと？` と、① 掛橋／② 架橋／③ 懸橋を確認。回答前の3選択肢は有効。
4. 「② 架橋」を選択。「せいかい！」「正解: ② 架橋」と解説全文を表示。3選択肢すべて disabled となった。
5. 「ここで結果を見る」→ 結果 `3 / 8` →「TOPに戻る」。回答した8問を分母に使用し、パック一覧・全20問設定・有効なスタートボタンが復帰した。
6. TOP から再スタートし、通常 UI で Q7 / 20 の do08 に到達。「① 掛橋」を選択すると「おしい！」「正解: ② 架橋」と同じ解説全文を表示。選択した①が赤、正解②が緑、3選択肢すべて disabled となった。
7. 再び途中終了すると結果 `1 / 7`。TOP 復帰後もパック選択の見出しが表示され、スタートボタンは有効だった。

表示された解説:

> 「かきょう」は「架橋」と書き、橋をかけることや、その橋を表す。「架」は、かけ渡すという意味の漢字。
