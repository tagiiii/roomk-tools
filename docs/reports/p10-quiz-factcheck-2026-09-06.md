### 1. ky03 — 「さいふのひもがながい」も文脈に合う

- 場所: `questions.js:2092`、`kanyouku`、深刻度: 中、確信度: 高。
- 原文: お金を簡単には使わない意味として「ゆるい／かたい／ながい」から選び、正答は「かたい」。解説は「『ながい』はこの文脈では使わない」。
- 根拠: 小学館のデジタル大辞泉と精選版日本国語大辞典は「財布の紐が長い」に、金を出し渋る意味を載せている。両辞書の関連本文を確認した。[辞書掲載本文](https://kotobank.jp/word/%E8%B2%A1%E5%B8%83%E3%81%AE%E7%B4%90%E3%81%8C%E9%95%B7%E3%81%84-508386)
- 影響: 正答「かたい」自体は妥当だが、「ながい」を誤答にする一意性が崩れる。単に正答番号を入れ替えても解決しない。
- 修正する場合の受入条件: 「ながい」の実在語義を否定しないこと。設問・選択肢を見直し、辞書上成り立つ別回答を不正解にしないこと。

### 2. s05 — サメ一般を「目をあけたまま」とする二択

- 場所: `questions.js:420`、`series-2choice`、深刻度: 中、確信度: 高。
- 原文: サメが眠るとき「目をとじる／目をあけたまま」の二択で後者が正答。解説は「まぶたがない種類が多いので、目を開けたまま休みます」。
- 根拠: Kelly ほか（2022）の draughtsboard shark（学名 *Cephaloscyllium isabellum*）7個体の研究には、閉眼・開眼双方の睡眠があり、夜の睡眠では開眼も観察された。論文本文の結果・考察を確認した。[著者研究室公開論文、Biology Letters 18:20210259](https://leskulab.org/wp-content/uploads/2022/03/kelly-et-al-2022.pdf)
- 影響: 種を限定しない設問で閉眼を誤答にできない。原文にない「すべてのサメにまぶたがない」「常に」を引用した指摘ではない。まぶたの有無の全種割合は今回確認していない。
- 修正する場合の受入条件: 対象種と条件を資料に合わせるか、種による違いを含む設問へ再設計すること。「すべて閉じる」への反転はしないこと。

### 3. ma17 — 「失笑」の「失」を「笑いを失う」と説明

- 場所: `questions.js:2806`、`machigai-nihongo`、深刻度: 中、確信度: 高。
- 原文: 解説の「笑いを失う（こらえきれず思わずこぼす）」という字義説明。
- 根拠: 文化庁の台本4ページは、この「失」を「失う」ではないと説明している。小学館の辞書公式コラムも同じ区別を示す。[文化庁台本](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/kotoba_shokudo/pdf/kotoba_18.pdf)、[小学館公式コラム](https://kotobanomado.jp/column/6720/)
- 影響: 正答Aや括弧内の「こらえきれず」という中心義とは別に、漢字の説明が逆方向の理解を招く。「解説全体が笑わない意味になっている」という指摘ではない。
- 修正する場合の受入条件: 誤った字義説明を除き、抑えきれず笑いが出る意味を保つこと。正答番号の変更はこの指摘からは要求しない。

### 4. z04 — バナナの仮茎を「茎が重なる」と説明

- 場所: `questions.js:38`、`zatsugaku-3choice`、深刻度: 中、確信度: 高。
- 原文: 「茎が重なって幹のように見えているだけ」。
- 根拠: フロリダ大学 UF/IFAS の園芸解説では、幹に見える仮茎は葉鞘が重なった構造で、地下の茎とは区別される。[UF/IFAS Banana Growing](https://ask.ifas.ufl.edu/publication/MG040)
- 影響: 草本という出題意図ではなく、植物の部位の取り違え。主担当は資料の Description 部分を本文で確認した。
- 修正する場合の受入条件: 葉の根元側の葉鞘が重なるという説明に整え、実在する地下の茎まで「ない」と説明しないこと。

### 5. khm03 — 「募・墓・幕・暮」の共通部品の由来

- 場所: `questions.js:3016`、`kanji-himitsu`、深刻度: 中、確信度: 高。
- 原文: 上部が「たまたま『艹』に似た形」で、植物の草とは由来が違うという説明。
- 根拠: 共通部品「莫」は、角川新字源改訂新版の字源説明では草むらと日から成り、もとは日暮れを表す。「募」などの形声の構成と、辞書の部首分類とは分ける必要がある。[漢字ペディア「莫」](https://www.kanjipedia.jp/kanji/0006323700/)、[同「募」](https://www.kanjipedia.jp/kanji/0006325800/)
- 影響: 今回の4字で、部首が異なる理由を「草と由来が無関係だから」と教えるのは不適切。あらゆる艹状部品の由来を一律に論じる指摘ではない。
- 修正する場合の受入条件: 部首（辞書の分類）・形声の音符・構成部品の歴史を混同しないこと。設問の理由選択肢と解説を合わせて見直すこと。
