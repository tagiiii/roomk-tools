## 1. z08 — 骨の重量比較から、空気の入る空間の有無へ

対象: `zatsugaku-3choice`、difficulty 3、正答②。

### 原文

```json
{
  "question": "「鳥は飛ぶために体が軽い」と考えると、骨はどうなっていそう？",
  "choices": ["かたくて重い骨で支える", "中が空洞で軽い骨が多い", "やわらかくて曲がりやすい"],
  "answerIndex": 1,
  "explanation": "重い骨では飛べないし、やわらかいと支えられない。軽くてかたい空洞の骨がちょうどいいんです。"
}
```

### 修正案

```json
{
  "question": "鳥の骨のつくりについて、正しいのは？",
  "choices": ["どの骨にも空気の入る空間はない", "内部に空気の入る空間がある骨もある", "骨はなく、筋肉だけで体を支えている"],
  "answerIndex": 1,
  "explanation": "鳥には、内部に空気の入る空間をもつ骨があります。骨の中に空間があることと、骨格全体の重さは別の話です。"
}
```

- **支持する本文**: Cornell Lab of Ornithologyの [Bird Academy’s A-to-Z Glossary of Bird Terms](https://academy.allaboutbirds.org/bird-academys-a-to-z-glossary-of-bird-terms/) の `pneumatic`／`pneumatic foramen`（2026-09-07に実装担当がHTML本文取得）。空気の入る空間をもつ骨と、上腕骨内部の空間へ通じる開口を説明する。この存在・構造の説明だけを採用し、同用語集にある骨の割合の一般化は採用しない。
- **重量との区別**: [2025年レビュー](https://pmc.ncbi.nlm.nih.gov/articles/PMC12077225/)について、[第2回科学証拠](evidence/p10-followup2-science-2026-09-07.json)には当時取得したAbstract／Introduction／Figure 1説明の記録がある。含気化と骨格全体の相対質量を区別する根拠として参照するが、今回は確認画面に止まり本文再取得できていない。今回新たに全文確認した資料とは扱わない。
- **外す主張**: 原文の「重い骨では飛べない」という断定を外す。また、原文から読み取り得る「空洞骨が多いので骨格全体も軽い」という推論を採点に使わない。後者は原文そのものの引用ではない。骨組織の密度、骨単体の質量、全骨格の質量、体重比を混同せず、旧文に比較対象を追加して誤りと認定しない。
- **一意性**: 本文で空気の入る骨が存在すると確認できるため②。①はその存在を否定し、③は鳥が骨をもつことを否定するので該当しない。全鳥種・全骨の一律構造や飛行可否を問わない。
- **変化の性質**: 飛行への推理から骨の構造の知識へ変わる。誤答の除外は以前より容易になり得る。difficulty値の自動変更はしない。

## 2. ks08 — 水温の速さを問わず、水面の広さを直接比較

対象: `kurashi-suiri`、difficulty 2、正答①。

### 原文

```json
{
  "question": "同じ水を、浅い皿と深いコップに入れた。早くぬるくなりやすいのは？",
  "choices": ["浅い皿", "深いコップ", "どちらも同じ"],
  "answerIndex": 0,
  "explanation": "手がかりは「空気にふれる広さ」。浅い皿は水が広がって空気にふれる面が大きいので、温度が変わりやすくなります。"
}
```

### 修正案

```json
{
  "question": "ふたのない皿とコップに水が入っていて、水面はどちらも丸い。皿の水面の直径は20cm、コップは8cm。空気にふれる水の面が広いのは？",
  "choices": ["皿", "コップ", "どちらも同じ"],
  "answerIndex": 0,
  "explanation": "空気にふれるのは、水の上の面です。丸い水面は、直径が大きいほど面も広くなります。"
}
```

- **一意性と根拠**: ふたなし・丸い水面・水面そのものの直径を明示した幾何学的比較。円の面積は半径の二乗に比例するので、直径20cmの皿が8cmのコップより広い。これは提示条件からの推論であり、実物容器の計測結果や外部実験の追試ではない。容器の「浅い／深い」だけで水面積は決まらないため、その推論を使わない。
- **参照した機関本文**: TU Delft／NVONの [18.8. Condensation heat in infrared](https://interactivetextbooks.tudelft.nl/showthephysics/demos/demo63/demo63.html)（2026-09-07本文再取得）。導入に蒸発冷却、物理背景に円形面積を用いた計算がある。これは水面積の円の関係と、水温が単なる空気との熱交換だけでは決まらない点の参照であり、元の皿対コップの昇温速度を支持する実験ではない。
- **外す主張**: 初期温度、水量、容器の材質・形、湿度、蒸発などの条件が不十分なまま浅皿の昇温が早いという順位。今回の案は温度変化や乾燥速度を一切採点しない。
- **体験上のトレードオフ**: 手がかりから温度変化を考える問題ではなく、広さの直接比較になるため、推理の手ごたえは下がる。数式・面積計算の入力は求めないが、数値と「直径」の語が加わる。この変更を含めてオーナーの承認を求める。難しさを維持したい場合は本案を保留し、未検証の温度比較へ戻さない。

## 3. ks13 — 曇天の湿度を決めず、日差しの働きを問う

対象: `kurashi-suiri`、difficulty 3、正答①。

### 原文

```json
{
  "question": "くもりの日は、せんたく物が晴れの日よりかわきにくい。晴れの日とくらべて足りないものは？",
  "choices": ["日光と、かわいた空気", "風の音", "洗ざいの量"],
  "answerIndex": 0,
  "explanation": "かわく手がかりは日光とかわいた空気。くもりの日はどちらも少ないので、かわきにくくなります。"
}
```

### 修正案

```json
{
  "question": "洗濯物に当たる日差しが、乾くのを助けるのはなぜ？",
  "choices": ["洗濯物を温め、水分の蒸発を助けるから", "風の音を大きくするから", "洗ざいの量を増やすから"],
  "answerIndex": 0,
  "explanation": "日差しには洗濯物を温める働きがあり、水分が蒸発するのを助けます。日差しがなくても、水分は蒸発します。"
}
```

- **日射の直接根拠**: 日本気象株式会社、K. Enohara [洗濯予報で用いる乾燥ポテンシャルの開発実験](https://ods.n-kishou.co.jp/tech/blog/detail/2409)（2020-03-13）。主担当が2026-09-07に本文を直接取得し、日差しが衣類を温め蒸発を促す説明を確認した。実装担当の今回取得はタイムアウトしたため、主担当の本文確認と区別して記録する。日本気象協会の記事とは扱わない。
- **独立に取得した補強本文**: American Chemical Societyの [Lesson 2.2: Changing State—Evaporation](https://www.acs.org/middleschoolchemistry/lessonplans/chapter2/lesson2.html)（更新2024-07-19、2026-09-07に実装担当がHTML本文取得）。加熱した濡れた紙の蒸発、比較時に統制する条件、加熱していない紙の水も蒸発する説明を確認。衣類の特定乾燥時間を測った資料ではない。
- **外す主張**: 曇天であることから晴天より地上の空気が乾いていないと判断する比較を外す。原文に「必ず」「常に」と明記されているわけではなく、旧文を無条件の比較へ一般化して反証することもしない。新案でも日差しが乾燥の唯一の条件、日差しがないと乾かないとは説明せず、風や湿度との効果順位は付けない。
- **一意性**: 日差しによる加熱と蒸発促進を表す①。②は風の強さではなく音、③は洗剤量であり、問う働きを表さない。晴天対曇天の乾燥時間を一律に採点する形ではない。
