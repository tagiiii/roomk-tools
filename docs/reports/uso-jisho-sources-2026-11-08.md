# うそつき辞書のお題の出典（2026-11-08）

P3 監査（2026-11-07）の所見5「99語の意味に語ごとの出典がない」への対応。お題（`apps/uso-jisho/index.html` の `WORDS`）を1語ずつ公開の辞書・資料と照らした。参照日はすべて 2026-11-08。

- 辞書の語義の欄は要約（引用ではない）
- 直したのは4語（下の表の「対応」）。そのほかは、子ども向けの言いかえとして語義と合っている
- 66番は「けいらん」を「じゃっぱ汁」（青森の郷土料理）に差し替えた。出典は農林水産省「うちの郷土料理」の「鱈のじゃっぱ汁」
