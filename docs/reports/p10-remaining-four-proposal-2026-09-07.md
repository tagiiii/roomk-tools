対象: `ruigigo`、difficulty 3、正答②。

```json
{
  "question": "「ずっと楽しみにしていた旅行が急に中止になって、すっかり＿＿」。合うのは？",

  "answerIndex": 1,
  "explanation": "「まいった」は手が打てず脱力する口語的な強調。「困った」は中立で軽く、「こまりはてた」は極度で文語寄り、「すっかり」の脱力感には座りがわるい。"
```

```json

  "choices": ["あつまった", "まいった", "みつかった"],
  "answerIndex": 1,
  "explanation": "「まいった」には、困ったり弱ったりしたという意味があります。「暑さにまいった」のように使います。"
}
```

- **本文根拠（調査担当が2026-09-07に取得）**: 小学館『デジタル大辞泉』[参る](https://kotobank.jp/word/参る-633122)の閉口・弱る・困る語義と暑さの用例。[漢字ペディア「参る」](https://www.kanjipedia.jp/kotoba/0002649600)の第5義も補強する。誤答は [漢字ペディア「あつまる」](https://www.kanjipedia.jp/kotoba/0003147400)の寄り合う意味と、[大辞泉「見付かる」](https://kotobank.jp/word/見付かる-638621)の発見・探し出される意味を確認した。
- **一意性・限界**: 問う語義に対応する②。①③は集合・発見を表し、その語義ではない。旧旅行文の誤りや、旧①③が②と同程度に自然であることを証明したとは扱わない。旧解説の強さ・文体・語感による排除を採点根拠にしない。
- **類似・体験変更**: ru20／kbn17／sk08にも困った状況などが出るが、笑い・故事の内容・矛盾を問う別問題。担当の全480問比較で新設問の完全一致・正規化一致はないが、全意味重複の保証ではない。微妙な語感比較から基本語義の区別へ変わり、実際の手ごたえは下がり得る。difficulty値は据え置く案である。

### 原文

```json
{
  "question": "日本語には「きらきら」「もふもふ」のような音でイメージを表すことば（オノマトペ）がとても多い。この種類のことばで、世界の言語の中でも日本語より多いとされている言語はどれ？",
  "choices": ["韓国語", "英語", "フランス語"],
  "answerIndex": 0,
  "explanation": "日本語のオノマトペは4500語以上とされ、世界の中でも豊富な言語の一つ。ただし韓国語はさらに多く8000語ほどあるとされ、日本語だけの特徴というわけではない。"
}
```

### 修正案

```json
{
  "question": "荷物などが「ごろごろ」転がる様子を「デグルデグル」と表すのは、次のどの言語？",
  "choices": ["韓国語", "英語", "フランス語"],
  "answerIndex": 0,
  "explanation": "韓国語では、荷物などがごろごろ転がる様子を「デグルデグル」と表します。日本語だけでなく、韓国語にも音や様子を表すオノマトペがあります。"
}
```

- **本文根拠（調査担当が2026-09-07に取得）**: 国立国語研究所 [韓国語の擬態語と日本語の擬態語の比較1](https://www2.ninjal.ac.jp/Onomatope/column/kankokugo_1.html)の具体例。荷物が転がる表現と対応する韓国語をHTML本文で確認し、同資料のカタカナ表記を採用する。音声による発音指導や厳密な転写の検証ではない。
- **一意性・限界**: 具体的な韓国語表現の言語識別として①。「豊富な言語」なら他候補を除けない問題を避ける。記事に併載された語数・世界最多、年齢や性別による例は採用しない。旧4,500対8,000の集計方法や比較可能性を新たに証明したものでもない。補助候補だった韓国語基礎辞典の別語ページは取得失敗し、根拠に使用していない。
- **類似・体験変更**: k05は日本語「ころころ」の意味、zk208はオノマトペの働きを問うため異なるが、既存オノマトペパックも含め題材は近い。現行には「デグルデグル」の別問題はない。言語間の数量比較から具体的な外国語表現の紹介へ変わり、未経験者には推測頼みになり得る。語を知る楽しさと手ごたえの変化を含め、採用はオーナー判断とする。

## 3. zk203 — 米国の多数説から、1本の虹の連続色へ

### 原文

```json

  "answerIndex": 0,
  "explanation": "アメリカなど欧米では虹を「6色」と見ることが多いとされる。虹は本来、境界のない色の連続体で、それを何色に区切るかは物理的な決まりではなく、文化や言語ごとの慣習による。"

```

### 修正案

```json
{
  "question": "1本の虹の帯の中で、色と色の間はどうなっている？",
  "choices": ["少しずつ色が変わり、つながっている", "白いすき間で区切られている", "黒い線で区切られている"],
  "answerIndex": 0,
  "explanation": "虹の色は、少しずつ変わりながら連続しています。「7色」といった分け方は、この連続した色を区切って呼ぶものです。"
}
```

- **本文根拠（調査担当と主担当が2026-09-07に取得）**: 英国気象庁Met Office [Rainbows: optical wonders](https://weather.metoffice.gov.uk/learn-about/weather/optical-effects/rainbows)の「The colours of a rainbow」。虹には連続した色の範囲があり、七つの色名は覚えるための区分として使われる説明をHTML本文で確認した。
- **一意性・限界**: 1本の帯内の連続性を表す①。二重虹の主虹と副虹の間にある暗い領域とは区別する。米国・欧米で何色という回答が多いかは検証しておらず、旧多数説が誤りと確定した変更でもない。実際の虹の観察・画像解析はしていない。
- **類似・体験変更**: zk207の解説も連続色を扱うが、設問は言語・文化の色数について。zk205の色名の区別とも問いは異なる。説明の近接は残るため、重複を全て解消したとは扱わない。国別知識から色のつながりを考える問題へ変わり、誤答の除外は容易になり得る。

```json
  "choices": ["最初に身につけたことば", "世界中で話す人が最も多いことば", "旅行先で一度だけ聞いたことば"],
  "answerIndex": 0,
```
