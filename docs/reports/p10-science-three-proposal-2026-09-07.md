## 1. z07 — フェネックの暑さ対策

対象: `zatsugaku-3choice` / difficulty 3。変更案は `question` と `explanation` のみ。

```json
{
  "question": "砂漠にくらすフェネックの大きな耳が、暑さ対策に役立つのはなぜ？",
  "choices": ["遠くの音をよく聞くため", "体の熱をにがすため", "砂がはいらないようにするため"],
  "answerIndex": 1,
  "explanation": "フェネックの大きな耳には、体の熱を逃がす働きがあります。獲物の音を聞くことにも役立ちます。"
}
```

- 旧残余: 聴覚と放熱を比較した「いちばん」「暑さ対策が主」という順位の根拠が不足。
- 対応: キツネ一般からフェネックに絞り、「主な機能」ではなく暑さ対策の働きを問う。聴覚機能も解説に併記し、聴覚より放熱が重要とは述べない。
- 根拠: Smithsonian’s National Zoo & Conservation Biology Institute の [How Does a Fennec Fox Survive in the Desert? And Other Questions, Answered](https://nationalzoo.si.edu/animals/news/how-does-fennec-fox-survive-desert-and-other-questions-answered)（2018-04-12、2026-09-07 本文再取得）。砂漠の生息地、大きな耳で砂中の獲物の音を聞くこと、耳から体熱を逃がして涼しく保つことを説明。機能の順位は示さない。
- 一意正答性: 「暑さ対策」に答える選択肢は②。①の聴覚機能そのものを否定する採点にはしない。正答番号と選択肢は維持する。

## 2. s06 — 若いひまわりの夜の向き

対象: `series-2choice` / difficulty 2。変更案は `question` / `choices` / `explanation`。

```json
{
  "question": "若いひまわりは、夜には翌朝に向けてどちらを向くように動く？",
  "choices": ["西を向くように動く", "東を向くように動く"],
  "answerIndex": 1,
  "explanation": "若いひまわりは昼に太陽を追って東から西へ向きを変え、夜には翌朝に備えて東向きに戻ります。"
}
```

- 旧残余: 夜の動きが昼より遅いという速度比較の裏付けが不足。
- 対応: 「夜はあまり動かない／ゆっくり」を外し、若い植物が夜に東へ戻る向きを問う。夜間に動く事実だけをもって、元の「あまり」が明確な誤りだったとは認定しない。
- 根拠: UC Davis Harmer Lab の [Research — Sunflower heliotropism](https://harmerlab.ucdavis.edu/research)（2026-09-07 本文再取得）。若いひまわりの昼の東→西、夜の西→東という動きと、翌朝を先取りする東向きへの復帰を研究者自身が説明。昼夜の角速度比較は採用しない。
- 一意正答性: 翌朝に向けた夜の復帰方向は②東。成熟した花や夜の全瞬間の方向を問う設問ではない。2択と正答番号②は維持するが、正答の意味は「動きの少なさ」から「東向きへの復帰」へ変わる。

## 3. s08 — 外側の長い毛に限定

対象: `series-2choice` / difficulty 3。変更案は `question` と `explanation` のみ。

```json
{
  "question": "ホッキョクグマの外側の長い毛そのものは、白い色がついている？ それとも透明に近い？",
  "choices": ["白い", "透明に近い"],
  "answerIndex": 1,
  "explanation": "ホッキョクグマの外側の長い毛は、透明で中が空洞になっています。"
}
```

- 旧残余: 下毛を含めた全毛種の管状構造を確認できず、取得資料間の記述の違いも解消できていない。
- 対応: 対象を外側の長い保護毛に明示的に絞る。「1本だけ見ると」という観察条件に依存する表現と、白く見える光学機序の説明は削除。下毛まで空洞とする説明はしない。
- 根拠1: San Diego Zoo Wildlife Alliance、飼育担当 Matthew Price の [Punk Rock Polar Bears?](https://sandiegozoowildlifealliance.org/story-hub/2015/08/28/punk-rock-polar-bears)（2015-08-28、2026-09-07 本文再取得）。外側の保護毛を明示して透明・中空と説明する。同記事が扱う付着物や藻類による見かけの着色と、毛そのものの性質を区別する。
- 根拠2: 同機関の [Polar Bear — ABOUT](https://animals.sandiegozoo.org/animals/polar-bear?qt-animals_page_content_tabs=1)（2026-09-07 本文再取得）。外側の長い保護毛と密な下毛の区別を確認。透明・中空の適用範囲には、より明示的な根拠1を用いる。
- 一意正答性: 毛そのものの性質を問うため②。付着物・照明・毛の集まり方を問わず、どんな観察でも透明に見えるという保証にはしない。正答番号と選択肢は維持する。
