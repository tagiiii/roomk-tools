# C-3 調査報告: muted テキスト×小フォントのコントラスト実測（WCAG AA）（2026-07-11）

バックログ C-3（調査・報告のみ、変更なし）の成果物。実ブラウザで computed style を取得し、
14px 以下のテキスト要素について前景色×実効背景色（半透明は祖先と合成）の
コントラスト比を実測した。判定基準は WCAG AA 通常テキスト 4.5:1。

## 設計トークン自体の判定（計算値）

| 組み合わせ | 比率 | AA判定 |
|---|---|---|
| `--color-muted` #5A6270 on surface #FFFFFF | **6.15:1** | 合格 |
| `--color-muted` #5A6270 on bg #F5F2EC | **5.50:1** | 合格 |
| `--color-text` #1A1A1A on surface | 17.40:1 | 合格 |
| `--color-primary` #1C3F5E on surface | 10.93:1 | 合格 |
| （参考）`--color-border` #C4D2D8 を文字に使うと | 1.55:1 | 不合格（文字使用の実例なし） |

**結論: デザインシステムの muted は小フォントでも AA 合格。** ハードコードされた
グレー系文字色（#999 等）も全アプリで検出ゼロ。心配されていた「muted×小フォント」は問題なし。

## 発見: jinro の独自配色 3 件（修正候補）

jinro は夜画面・フェーズバッジに独自色を使っており、共通トークン外で不合格が出た。

1. **`.night-waiting`**: スレートグレー #64748B ×夜背景 rgb(29,37,55) = **3.22:1**（14px）
   夜の待機メッセージ「ほかのプレイヤーの行動を待っています…」。#94A3B8 程度に明るくすれば 4.5 超
2. **`.phase-badge.morning`**: 白 bold 13px ×オレンジ #D97706 = **3.19:1**
   「2日目の朝」バッジ。#B45309（amber-700）に落とすか文字を 18.66px 以上 bold にすれば合格
3. **`.section-lbl`（ハンター等の役職色バリアント）**: ティール rgb(46,125,140) ×淡ティール = **4.42:1**（12px）
   僅差の不合格。文字色をわずかに濃く（例 #26697A）すれば合格

## 測定上の注意（次回のために）

- グラデーション背景（background-image）は自動測定不能のため除外し、該当箇所
  （jinro の役職カード裏「タップして確認」= 白×濃紺グラデ）は目視相当で高コントラストを確認済み
- 半透明オーバーレイは祖先との合成後に判定しないと誤検出になる（jinro `.overlay-sub` は合成後 7.87:1 で合格）
- 未測定アプリにも独自配色（jinro 型）があれば同様のリスクがあるが、共通トークンのみの
  アプリは設計上安全。月次ローテ監査で jinro 型（独自色持ち）を優先すると効率的
