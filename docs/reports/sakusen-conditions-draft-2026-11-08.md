# 作戦会議の19本: 「話す量」「自分の話」の値の案（2026-11-08・オーナー確認待ち）

P-33・P-34（2026-11-08 承認）にもとづく、ツール一覧のカードに持たせる値の案。各ツールの AGENTS.md と画面から読める事実だけで決めた（根拠はツールごとに file:line で確かめた）。子どもへの合い方や「向く子」は書いていない。**確かめてもらってから、ツール一覧に実装する。**

- 話す量: 選ぶだけ／ひとことで／話す・説明する／話さなくてよい（見る・聞く）
- 自分の話: 外の題材で遊べる／自分のことを少し話す／自分のことを話すのが中心
- 上下はつけない。複数あてはまるものは複数。「話さなくてよい」は、声を出さずに参加できる仕組み（選ぶだけ・ホストが代わりに押す・チャットで送る等）が実装にあるときだけ付けた
