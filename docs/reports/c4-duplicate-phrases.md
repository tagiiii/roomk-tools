# C-4 調査報告: 同一アプリ内の言い換え重複（2026-07-11）

バックログ C-4（調査・報告のみ、変更なし）の成果物。`node scripts/content-audit.mjs` の
類似ペアレポート（総エントリ 3032・類似ペア 1069）から同一アプリ内のペアを抽出し、
定型文由来の誤検出を除いて精査した。修正は人間承認後。

## 集計

- 類似ペア 1069 件中、同一アプリ内は 1047 件。ただし大半は「同一問題内の選択肢どうし」で、
  問題をまたぐ実質的なペアは **83 件**（quiz 9・kotoba-asobo 74）
- さらに問題文レベルの言い換えは 35 件で、下記のとおりほとんどが定型文由来の誤検出

## 実質的な重複（入れ替え・修正候補）

1. **quiz: 「情けは人の為ならず」が2パックに重複**（ma01 / kbn03、score 0.69）
   同じことわざの意味を問う問題が別パックに存在。両パックを続けて遊ぶと答えを知っている状態になる。
   → どちらかを別のことわざに入れ替える候補
2. **quiz: 雑学キング2で答え「中国語」が2問**（zk211 / zk213）
   同一パック内で正解が同じ問題が2問あり、消去法のメタ読みができてしまう。
   → どちらかの問題を入れ替える候補
3. **kotoba-asobo: u1s05 内で w1 と q1 が同一文**（「反対どうしのペアを組み合わせるなら?」）
   同じセッションのウォームアップと本編第1問が完全一致。編集ミスの可能性が高い。
   → セッション u1s05 の確認を推奨
4. kotoba-asobo: u1s02-c1 と u5s33-c1 のクールダウン質問が完全一致
   （「いちばん気に入ったことばを教えて」）。セッション間の定番質問としては自然なので
   **仕様の可能性が高い**が、40回プログラムの中で近接して使われないかだけ確認を推奨

## 誤検出（仕様・対応不要と判断）

- 難読地名・駅名パックの「〜の駅名「X」は、何と読む？」定型（quiz の残り7ペアはすべてこれ）
- kotoba-asobo のウォームアップ定型（「ウォームアップは『いくつ言える?』で遊びます…」）
- kotoba-gacha の助詞テンプレート重複（同じ助詞の組は設計上必然。「は/も」×3 のみやや偏り）

## 食べ物ジャンル偏重の材料（入れ替え候補づけ）

- 同一アプリ内の実質ペア 83 件中 **16 件が食べ物系**
- 参考: アプリ間の完全一致 136 グループ中 10 グループが食べ物系
  （りんご・たまご・ぶどう・さかな・**おにぎり×3アプリ**・いちご・すし・やきにく など）
- 新規コンテンツ投入（Tier D-3）の際は、食べ物以外のジャンル（乗り物・自然・行事など）を
  優先すると重複が減る
