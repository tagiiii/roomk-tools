## 1. kj19 — 「守」を、確認できた漢字辞典の説明にそろえる

対象: `kanji-quiz`、difficulty 3、正答①。

### 原文

```json
{
  "question": "「守」という字は「うかんむり（屋根・家）」の中に「寸（手）」がある。どんな様子を表している？",
  "choices": ["家の中で手を出してまもる", "外を走っていく", "火をけす"],
  "answerIndex": 0,
  "explanation": "家の中で手を使って大切なものを守る様子から、「まもる」の意味になったと説明されることがあります。"
}
```

### 修正案

```json
{
  "question": "漢字辞典では、「守」は宀（うかんむり）と寸（右手）を組み合わせた字と説明されます。もとになった意味は？",
  "choices": ["家の中のことを取りしきる", "外を走っていく", "火をけす"],
  "answerIndex": 0,
  "explanation": "『角川新字源』では、家の中のことを取りしきる意味から、「まもる」意味につながったと説明されています。"
}
```

- **本文根拠**: 日本漢字能力検定協会 [漢字ペディア「守」](https://www.kanjipedia.jp/kanji/0003048600)、出典『角川新字源 改訂新版』（KADOKAWA）。2026-09-07にHTMLの「なりたち」本文と出典表示を取得。宀と寸（右手）の組み合わせ、家内の事をつかさどる意味から守る意味へのつながりを確認した。「取りしきる」は「つかさどる」の平易な言い換えで、特定の物や手の動作は付け足さない。
- **一意性・限界**: 辞典が示す家内の事を扱う意味に対応する①。②の走行・③の消火は、この辞典の説明ではない。唯一の字源説や歴史的動作の再現とはせず、辞書帰属を解説に明示する。旧文の「説明されることがあります」を無条件の断定へ強めず、別説の不在や誤りを証明したとも扱わない。
- **体験変更**: 手を出して守る姿の想像から、辞典の説明を選ぶ問いへ変わる。「取りしきる」はやや難しい語で、必要に応じメンターの読み上げ・言い換えを要する。difficulty値は自動変更しない。

## 2. kbn07 — 歌舞伎の由来説から、「おはよう」の語形の変化へ

対象: `kotoba-bunka`、difficulty 3、正答①。

### 原文

```json
{
  "question": "朝の挨拶「おはよう」は、もともと歌舞伎の楽屋で使われていたことばが広まったという説がある。それはどんな場面で使われていたことば？",
  "choices": ["朝早くから来てくれた人をねぎらうことば", "舞台に出る直前に気合いを入れることば", "公演が無事に終わったことを喜ぶことば"],
  "answerIndex": 0,
  "explanation": "歌舞伎では、主役級の役者が朝早く楽屋入りすると、まわりの人が「お早くからご苦労さまです」とねぎらったことから、それが省略されて「おはようございます」になったという説がある。江戸時代の芝居小屋から広まり、朝以外でも使われる元気な挨拶として定着した。"
}
```

### 修正案

```json
{
  "question": "挨拶の「おはよう」は、どのことばの形が変わったもの？",
  "choices": ["おはやく", "おやすみ", "おかえり"],
  "answerIndex": 0,
  "explanation": "『日本国語大辞典』では、「おはやい」の形の一つである「おはやく」が変化したことばと説明されています。朝に初めて会ったときなどの挨拶に使います。"
}
```

- **本文根拠**: 小学館『精選版 日本国語大辞典』[「御早」コトバンク掲載](https://kotobank.jp/word/御早-2017445)。2026-09-07にHTML本文を取得。「おはやい」の連用形「おはやく」の変化、早く出てきた相手への挨拶、朝初めて会ったときの挨拶という説明を確認。専門語「連用形」は案では「形の一つ」と平易に表す。
- **一意性・限界**: 辞書が語形の変化を示す①。②③はこの語形成の説明ではない。歌舞伎の主役、特定のねぎらい文の省略、江戸の芝居小屋からの伝播は支持範囲に含めず削除する。ねぎらいの心理も辞書から推定しない。掲載された古い用例を発祥の証明とせず、旧説が存在しない・誤りだと判定したものでもない。
- **体験変更**: 由来の場面を想像する問題から、音の似た形を選ぶ問題になる。短く読みやすくなる一方、正答を推測しやすく手ごたえは下がり得る。difficulty値は据え置き、変更の採用可否はオーナー判断とする。
