### C1 — value-card: 安全な非回答導線の欠如（旧 P6-1 分割）
- **論点**: 順位付け・PNG 保存は既知の意図的例外で対象外（蒸し返さない）。全画面に「パス/えらばない/やめる」導線がない点だけを調査。
- **調査結果**: value-card は内省ツール群で**唯一、画面上に非回答・離脱導線がない**。唯一の後退路 RESULT「やり直す」（`index.html:94`）は全工程（30→5枚→順位付け→メモ）完了後にしか押せない。同一運用前提（操作者=メンター/閲覧者=子ども）の双子 `checkout-card` は「きょうはパス」（`index.html:47`）を実装済み。
- **Codex 較正**: 「子どもは閲覧者だから急性実害ほぼ無い」は**過小評価**。操作上の詰まりは弱くても、完遂圧と撤回許可のメンター依存は残る。**調査=C・修正=B**。既存ガード（非回答を同格に置く哲学）から導線追加を導けるため P票不要。
- **推奨**: **Tier B**（GAME/RANKING に低強調の「きょうはここまで」→TOP を追加。順位/PNG は不可侵・機能削除なし・キーボード操作可）。no-op（メンター運用で足りると判断）を選ぶ場合は、**哲学ガードの例外承認として別途 P票が必要**。
- **実装済（2026-07-13・`a004d08`）**: GAME/RANKING に `btn-ghost btn-sm` の「きょうはここまで」→`goToTop()`（sortable 後片付け込み）を追加。順位/PNG/30→5 不変・updates.json 告知追記。AIブラウザ動作確認＋独立レビューエージェント＋Codex の二重レビュー合格。人間の体験レビューは事後。

### C2 — docchi: ask 文言の宛先確認（旧 P6-2）
- **調査結果**: ask 全85問はすべて子どもに直接語りかける会話質問（`app.js:23-118`。「きょうは何を食べた？」等）で、checkout-card/kimochi-map で削除された「ふかぼりしない」型の運用心得とは種類が違う → **§0.5-3 に明確な抵触なし**。唯一の曖昧さは、ラベル「きいてみるなら」（`app.js:200`）＋ドキュメント上「メンター向けの追い質問例」（`AGENTS.md:36,55`）という framing。

### C3 — quiz: 事実系（非難読）検証カバレッジ（旧 P3-2）→ P票化（P-10）

## 判断待ち（別レーン・P票①→②の順）

### P票①（先）— 非序列の支援機会語彙の確定
- **判断する一文**: ツール選択の語彙を、子どもの固定ラベルではなく「その日の本人の希望＋観察可能なセッション条件（所要/人数/発話量/自己開示の深さ）」で構成してよいか。
- **推奨案**: 語彙を最小の非序列セットに絞り、構造項目は P票②へ分離（承認面を小さくし部分承認を通しやすく）。
- **絶対条件**: 「不安が強い子」等の子ども属性ラベルを語彙に含めない。「話さなくてよい/弱い関心/パス」を灰色・末尾に置かず同格に。

### P票②（後）— ポータル選択メタデータ項目の確定
- **判断する一文**: `data-scenes`（場所）を残し、選択メタ属性（duration / party / voice / disclosure / record / opt_out）をスタッフ閲覧面に足すスキーマで確定してよいか。
- **Codex 較正**: **disclosure を3段階スコアにしない** → 観察可能な項目に分解（過去想起の要否 / 個人情報の要否 / 全体共有の要否 等）。`axis`（4軸）は人間のマッピング確定後のみ・値は AI が推定しない。
- 子ども向け画面には出さない。変更は `data-scenes` への追加のみ（後方互換）。
