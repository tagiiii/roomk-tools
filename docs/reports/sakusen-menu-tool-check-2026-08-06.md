## 横断で見つかったパターン

1. **パス系・エスケープ系の選択肢ほど番号がない。** tsuyomi-card「わからない/えらばない」、sakusen-kaigi「話さなくてもよい」「数字では決めにくい」、kimochi-map の3ボタンなど。非序列哲学で最も大事にしている選択肢が、チャットのみ参加の子には一番選びにくい構造になっている。
2. **画面共有前提なのに主要操作が最小フォント。** kyoumi-sugoroku 選択肢15px、challenge-tane 移動チップ13px、tsuyomi-card カード14px、value-card 本文13px、ikutsu-ieru 回答タイル14px/名前11px。
3. **15分枠との整合が未整備。** suki-type-check（表記矛盾）、sakusen-kaigi・kotoba-asobo・value-card（所要記載なし）。計画の共通設計要件2「2回に分ける前提の明記」が既存ツール側に未反映。
4. **ポータルの作戦会議タグ欠落。** quiz / kanji-sagashi / machigai-sagashi / pita-hame / kotoba-asobo に `data-scenes` の `sakusen` がない。メニューに載せるなら追加が必要（nitaku-board は対象外なら現状維持）。

## 手直しの推奨パッケージ（ユーザー承認待ち）

### パッケージA: 番号・文字サイズの一括修正（メニュー掲載の前提）
- talk-card: カード番号を丸数字化（app.js:149）
- kimochi-map: 「わからない/どれでもない/えらばない」に①②③、語彙チップの番号方式は設計判断（72語はグループ内連番等）
- tsuyomi-card: 「わからない/えらばない」に番号追加、グリッド3カラム化＋16px
- value-card: 丸数字化（app.js:91,166）、本文14px以上、AGENTS.md 所要追記
- kyoumi-sugoroku: 選択肢20px＋モーダル拡幅、1人時の文言分岐、既定人数1
- challenge-tane: 移動チップの番号設計＋13px解消
- sakusen-kaigi: specialButton への番号付与、ふりかえり8択・いつ/どのくらいチップの番号付与
- docchi: ③④の視覚同格化、コピー機能追加

### パッケージB: 15分枠の整備
- suki-type-check / sakusen-kaigi / kotoba-asobo / value-card の AGENTS.md に所要と区切り位置を明記
- kotoba-asobo は途中再開手段（スライドジャンプ or URLパラメータ）が別途必要（規模大きめ・後回し可）

### パッケージC: ポータルタグ
- メニュー掲載が確定したアプリに `data-scenes` へ `sakusen` を追加

## メニュー構成への反映案

- ikutsu-ieru・kotoba-asobo は初期メニューから外し、改修後に追加
- nitaku-board は「話す」カテゴリから外す（常設ボードとして hiroba/circle 運用のまま）
- pita-hame はソロ直行の導線（ソロを先頭 or ディープリンク）を作ってから掲載
