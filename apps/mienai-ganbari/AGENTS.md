# みえないがんばり 仕様書

## 目的・使用シーン

子どもがふだん見えにくい気づかい・我慢・外出の負荷などを、メンターと一緒にそっと確認するための内省ツール。チェックした項目は数字やスコアではなく、画面下に落ちる葉っぱとして表現する。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（または本人）|
| 閲覧者 | 本人（Zoom/Meet 画面共有で共同編集）|

**利用シーン**
- 面談で「最近、見えないところでがんばっていたこと」を一緒に探す
- 本人が言葉にしづらい疲れや気づかいを、項目選択をきっかけに話す
- 数字や達成評価ではなく、眺めて「けっこうあったね」と気づく

## 技術スタック

- 単一HTMLファイル（CSS・JS インライン）
- オフライン動作（Firebase 不要）
- localStorage で状態保存
- チェックボックス + DOM 生成の葉っぱ演出
- Material Symbols Rounded と共通デザインシステムを使用

## 画面構成・フロー

```
[1画面で完結]
  ├─ ヘッダー（タイトル + 問いかけ）
  ├─ カテゴリ別チェック項目
  │     - 人といるとき
  │     - 外に出たとき
  │     - 家で
  │     - 自分の気持ち
  ├─ 自分のことば
  │     - 自由入力で項目追加
  │     - 追加項目は削除可能
  ├─ そっとリセット
  └─ 画面下部の葉っぱエリア
        - チェックすると葉っぱが落ちる
        - チェックを外すと対応する葉っぱが消える
```

チェック・自由入力・葉っぱ位置は 150ms デバウンスで localStorage に保存し、ページ読み込み時に復元する。

## データ構造

```js
// localStorage key: 'mienai-ganbari:v1'
{
  // チェック状態: { itemId: true }
  checked: {
    p1: true,
    f3: true
  },
  // 自由入力アイテム: [{ id, text }]
  customs: [
    { id: 'c_xxxxx', text: '自分で書いたことば' }
  ],
  // 葉っぱの表示位置・種類・色
  leaves: {
    p1: { ex: 120, ey: 72, rot: -12, variant: 0, color: 2 }
  }
}
```

- 固定項目は `CATEGORIES` 配列で管理する
- 自由入力は最大40文字
- ユーザー入力は `textContent` または `escHtml()` を通して描画する
- 保存データに件数・スコア・履歴日は持たない

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| design-system.css | カラートークン、余白、カード、ボタン |
| Material Symbols Rounded | カテゴリアイコン、チェック、削除、リセット |

utils.js / firebase-config.js は不使用（オフライン単一ファイルのため）。

## 特有のルール・制約

- チェックした「がんばり」の個数を数字で表示しない。実装上も件数表示用のDOMや集計処理を持たず、チェック状態は葉っぱの有無としてだけ見せる
- 記録を「証拠化」しない。サーバー保存・共有URL・PDF/画像エクスポートを持たず、localStorage に本人の端末内データとして保存する
- 評価機能を入れない。「できた」「達成」「良い/悪い」「多い/少ない」の判定文やスコアを表示しない
- リセットは「そっとリセット」とし、confirm 後にチェック・自由入力・葉っぱをまとめて消す
- 葉っぱの位置はチェックごとにランダム生成し、整列やランキングのように読めない見た目にする
- CSS 接頭辞は `mg-` + BEM。例: `.mg-header__title`, `.mg-item__box`, `.mg-leaf--falling`

## 設計思想

このツールは「がんばりを数える」ためではなく、「見えにくい負荷に気づく」ためのツール。チェックは達成記録ではなく、話し始めるための小さな印として扱う。

- **数値化しない**: 個数・合計・割合を出すと、本人や大人が比較・評価しやすくなるため避ける
- **証拠化しない**: 保護者・先生への報告材料ではなく、本人とメンターの対話の素材に留める
- **評価しない**: がんばりを褒めて増やす方向に誘導せず、「気づく」「休む」「言葉にする」余地を残す
- **項目は軽く選べる表現にする**: 「あてはまるものを、そっとタップ」という文脈で、答えたくない圧を下げる

## 入れない機能（意図的に未実装）

| 入れない機能 | 入れない理由 |
|------------|------------|
| チェック数・合計表示 | 数値化・比較・評価につながる |
| 日別履歴・連続記録 | 記録を続けること自体が新しい負荷になる |
| 達成バッジ・称号・ほめ演出 | 「もっとがんばる」方向に寄せない |
| 良い/悪い判定、注意表示 | 本人の感じ方より大人側の評価が前に出る |
| PDF・画像エクスポート、共有URL | 証拠化・提出材料化につながる |
| ユーザー登録・サーバー保存 | 本人の内省を外部管理データにしない |
| 学校・家庭などへの報告欄 | 大人への説明責任をこのツールに持ち込まない |
