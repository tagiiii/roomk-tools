# いろつなぎ 仕様書

## 目的・使用シーン

上から2つ1組で落ちてくる玉を回して置き、同じ色を縦か横に4つ以上つなげて消す、ひとりで遊ぶ落ちものパズル。

- **core value**: 手を動かすだけで遊べる。消えたあとに玉が落ちてまたつながる「れんさ」で、置き方を考える楽しさがある。盤がいっぱいになっても、からにして続くので途中で抜ける子が出ない
- 対象: 小学校中学年〜中学生。ひろば（`data-scenes="hiroba"`）
- ひとりで遊ぶ（ルームなし・通信しない）。画面共有で見せながら遊んでもよい
- 1ラウンド2〜5分（時間を決めたとき）

> 経緯: 2026-11-13 フィードバックボードに「特定の市販の落ちものパズル（同じ色を4つつなげて消すもの）を入れてほしい」という要望が届いた。特定のゲームの再現はしない（名前・キャラクター・見た目・音・点の数え方の表を写さない）ため、オーナーの選択で同日 `drafts/iro-tsunagi/` に独自の名前と見た目で試作（PR #223）→ 同日オーナーが「すとんブロックに届いた要望で、同じように来そうなものを先に直して本体に」と指示し、下の「先に入れたもの」を足して本体化した。
> 着想元のゲーム名は、画面・検索のキーワード・早見表・更新情報のどこにも書かない。早見表では系統ラベル「落ちものパズル系」で紹介する（app-registration.md「アプリ名のつけかた」の段階3。すとんブロックにならった。段階を変えるならオーナーが決める）。

### 先に入れたもの（すとんブロックに届いた要望から）

すとんブロック（同じ落ちものパズル）に届いた要望28件のうち、このツールにも同じことが言われそうなものを、本体化のときに先に入れた（2026-11-13）。

| すとんブロックに届いた要望 | いろつなぎで入れたこと |
|---|---|
| ひとりのときにポーズがほしい | 「とめる」（P・Esc）。あそびかたを開いたとき・画面が裏に回ったときも自動でとめる |
| 横の押しっぱなしで速くなるまでが遅い | 左右はOSのくり返しにたよらず、はじめに1マス→0.13秒待って→0.03秒ごとに1マス（キーも画面のボタンも同じ） |
| 下の押しっぱなしを同じ速さに・加速後より遅く | 下は押したときに1マス、そのあと0.08秒ごとに1マスの同じ速さ（途中で速くしない） |
| W・A・S・D でも動かしたい | A・D で左右、S で下、W で右に回す（大文字でも） |
| 入らないはずの回転が入る | 1列のすき間で縦のまま回せないときは、1回目は回らず、0.35秒以内にもう一度回すと上下が入れかわる（`engine.js` の `rotate(g, dir, flip)`） |
| 送ったときなどの一言が盤にかぶって邪魔 | 「◯れんさ！」「全部消えた！」は盤にかぶせず、盤の左の外（スマホは盤の上の行）に出す |
| 7種類で1周がなくなった？（出かたの仕組みを知りたい） | 色の袋（どの色も4つずつ入れて混ぜ、2つずつ出す・からになったら入れなおす）。あそびかたの「玉の出かた」に書いた |
| 盤を空にした回数・全部消した回数を記録 | 結果に「全部消した ◯回」「からにした ◯回」（からにした回数は「からにしてつづける」のときだけ） |
| やられたとき、なぜかわかりづらい | 盤がいっぱいのとき、ふさがった「玉が出る所」を赤くぬってから、からにする |
| わかりやすいサウンドがほしい | 効果音（はじめは切・その端末だけ）。動かす・回す・置く・一気に落とす・消える（れんさで高くなる）・全部消えた・おしまい |
| ハードドロップ・ライン消しのアニメーション | 一気に落とした列に残像、消えると玉がふくらんで消え粒が飛ぶ。動きを減らす設定では、消える玉に白い縁を付けるだけ |

入れなかったもの: ルーム・対戦（じゃまを送りあう）・音楽。ルームは RTDB と `database.rules.json` の変更（オーナーの承認が要る）が要るので、要望が来てから考える。

## 技術スタック

- オフライン単独動作（Firebase 不要）。効果音を「入」にした端末だけ、同じフォルダの `sfx/*.mp3` を読む
- ファイル構成: `index.html` + `engine.js`（ルールだけ。画面に触らない）+ `app.js`（画面と操作）+ `style.css`。4つはセットで変わるので、変えたら `?v=` をそろえて上げる
- 盤と玉は canvas に描く
- CSS 接頭辞: `.it-`
- テスト: `tests/iro-tsunagi/`（ルールのテストと、エミュレーターの要らない E2E。README.md）。URL に `?seed=` を付けると玉の順番が決まり、`?test=1` のときだけ `window.__iro` から状態を読める（画面からは使わない）

## ルール

| 項目 | 内容 |
|---|---|
| 盤 | 横6・たて12。その上に見えない段が1段ある（y = −1。あそぶ画面では半分だけ淡い帯で見える） |
| 出る所 | 軸の玉が左から3列目のいちばん上（x = 2, y = 0）、もう1つがその上の見えない段。ここ（x = 2, y = 0）がふさがっていると盤がいっぱい |
| 色 | 3〜5色（はじめの画面で選ぶ。はじめは4色）。色ごとに中の形を変える（1 赤・丸／2 青・三角／3 緑・四角／4 黄・星／5 紫・ひし形） |
| 出かた | 色の袋（`PER_COLOR` = 4 つずつ）を混ぜて2つずつ出す。はじめの1袋（6組）は3色だけ |
| 回す | 右回り・左回り。入らないときは、反対へ1つずらす → 1つ上げる、の順にためす。1列のすき間は上の「2回押し」 |
| 置く | 着地して 0.45 秒で置かれる（着地したまま動かす・回すと待ち時間がもどる。10回まで）。一気に落とすとすぐ置く |
| 消える | 置いた2つの玉は、下があいていればそれぞれ落ちる。同じ色が縦か横に4つ以上つながると消える（見えない段の玉は数えない）。落ちてまた消えると、れんさ |
| 点 | 消えた玉の数 × 10 × れんさの数 ×（同時に消えたまとまりが2つ以上ならその数）。独自の数え方（着想元の表は写さない） |
| 盤がいっぱい | 「からにしてつづける」（はじめ）なら、出る所を赤くぬって1.3秒見せてから盤をからにして続く。「おしまい」なら結果へ |
| 時間 | なし（はじめ）・2・3・5分。0になったら「時間になったよ」で結果へ |
| 落ちる速さ | ゆっくり 0.9秒・ふつう 0.6秒・はやい 0.35秒に1マス |

## 画面構成・フロー

```
はじめの画面（入口の型 .app-entry）
  色の数・落ちる速さ／くわしい設定（時間・盤がいっぱいになったら・効果音）
  「はじめる」
    ↓
あそぶ画面
  左: 一言（◯れんさ！・全部消えた！） / まん中: 盤 / 右: つぎ（2組）・のこり時間・点・最高れんさ・「とめる」「おわる」
  スマホ・さわれる画面: 下に操作ボタン6つ（左・左回し・右回し・右・下げる・一気に落とす）
    ↓ 時間・おしまい・「おわる」
結果（点・最高れんさ・消した玉・全部消した・からにした）
  「もう一回」／「はじめの画面へ」
```

- キーボード: ← →（A D）・↓（S）・スペース・↑（W）か X で右回し・Z で左回し・P か Esc でとめる
- 効果音の入・切は、その端末の localStorage（`irotsunagi:sfx`）に残す（読めなければ切）

## 共通モジュールの使用箇所

- `design-system.css`（ボタン・入口の型 `.app-entry`・種類の色 `data-genre="puzzle"`）
- `howto.js`（あそびかた）・`stats.js`（はじめるたびに `start` を数える）
- 効果音のファイルは `apps/suton-block/sfx/` と同じもの（ElevenLabs で作った。作り方は `scripts/suton-block/sfx.py`）を写して使う

## 特有のルール・制約

- 子どもが使う画面で、はじめから音は鳴らさない（効果音は「切」がはじめ）
- 比べる相手はいない（ひとり用）。点・最高れんさは結果に出すが、どこにも残さない
- ツール一覧のイラストはまだない（作るかはオーナーが決める。fal を使う）。はじめの画面の絵の面も、絵ができるまで置かない
