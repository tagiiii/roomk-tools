# 以心伝心しないゲーム 仕様書

## 目的・使用シーン
お題に対して「みんなとかぶらない回答」を目指すパーティーゲーム。
メンターが操作し、参加者は Metalife のチャットで回答する。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（ホスト） |
| 回答者 | 参加者（Metalife チャットで回答） |

**利用シーン**
- セッション中のアイスブレイク・レクリエーション
- 参加者同士の交流促進

## 技術スタック
- オフラインアプリ（Firebase 不要・ログイン不要）
- ファイル構成: `index.html` + `app.js` + `style.css`
- 共通デザインシステム使用
- CSS prefix: `.isd-`

## ゲームの流れ

1. ホストがラウンド数を選んでゲームスタート
2. 3枚のカードからお題を1つ選ぶ
3. お題が大きく表示される（画面共有で参加者に見せる）
4. 参加者は Metalife のチャットで回答
5. かぶらなかった人の勝ち（判定は口頭で行う）
6. 次のラウンドへ（設定ラウンド数まで繰り返し）
7. 全ラウンド終了 → おつかれさま画面

## 画面構成

```
[TOP画面]
  ラウンド数選択（3/5/7/10） → ゲームスタート

[お題選択画面]
  ラウンド表示 + カード3枚（タップで選択）
  → M-4 フリップアニメーション
  → 他2枚が dimmed

[お題表示画面]
  お題を大きく表示（画面共有用）
  → 「次のラウンドへ」or「結果発表へ」ボタン

[結果画面]
  おつかれさま + もう一度遊ぶ / TOPに戻る
```

## お題リスト
`app.js` 内の `const topics = [...]` に100問を定義。

### カテゴリ構成
| カテゴリ | 問数 |
|---------|------|
| 食べもの系 | 20 |
| 動物・生きもの系 | 15 |
| 色・形・もの系 | 15 |
| 場所・乗りもの系 | 10 |
| スポーツ・遊び系 | 10 |
| 季節・イベント系 | 10 |
| 日常・おもしろ系 | 10 |
| 人・キャラ系 | 10 |

### お題作成ガイドライン
- 「〜といえば？」形式で統一
- 学校・勉強・宿題を連想させる表現は使用しない
- 恋愛・暴力・ホラーは禁止
- 正解のない開かれた質問にする

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | お題プールのシャッフル |
| M-4 カードフリップ | .flip-card クラス（CSS + JS） |
| M-5 popIn | お題表示・結果画面の出現アニメーション |
| M-6 ボタン | .btn-primary / .btn-ghost / .btn-lg |

## 特有のルール・制約
- お題プールが3問未満になったら全100問を再シャッフルして補充
- キーボード操作対応（Tab + Enter/Space でカード選択）
- スコア管理・判定はアプリ外（口頭）で行う
- 最小推奨人数: 3人
