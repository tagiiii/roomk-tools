# クイズパック 仕様書

## 目的・使用シーン

雑学3択、連続2択、ことばクイズなどをパック単位で進めるオフラインクイズツール。
メンターが画面共有し、参加者と相談しながら遊ぶ用途を想定する。

## 技術スタック

- オフラインアプリ（Firebaseなし）
- `index.html` + `app.js` + `questions.js` + `style.css`
- 共通デザインシステムと `shuffle` / `popIn` / `copyToClipboard` を使用

## 画面構成

```
TOP（パック選択＋問題数・手ごたえ選択） → QUIZ（可変問数） → END（結果）
```

## 特有のルール

### 問題数・手ごたえの選択（現場の「問題が少ない／簡単すぎる」への対応）

TOP で **問題数（5問 / 10問 / ぜんぶ）** と **手ごたえ（ふつう / チャレンジ）** を選ぶ。

- 難易度配分（`app.js` の `TARGETS`）
  | | 5問 | 10問 |
  |---|---|---|
  | ふつう | d1:1 / d2:2 / d3:2 | d1:2 / d2:4 / d3:4 |
  | チャレンジ | d1:0 / d2:1 / d3:4 | d1:0 / d2:3 / d3:7 |
- 「ぜんぶ」＝在庫全部。ただしシャッフル系（`isShuffle`）は長すぎるので `SHUFFLE_ALL_CAP`（30問）でキャップし、ボタン表記も「30問」に変える。
- 配分に満たない層は補充（チャレンジ=d3→d2→d1、ふつう=d1→d2→d3）。
- **実質全問出る設定（例：10問パック×10問）では手ごたえを自動で「ふつう」に固定**（配分を変えられないため）。プレビュー行で理由を表示。

### 鮮度・進行

- 出題は**表示した時点**で `usedIds` に記録。**未出題を難易度配分より優先**して抜く（2パス：未出題→足りなければ既出）。「もう一度あそぶ」で重複を避ける。`usedIds` は TOP に戻る／別パック選択でリセット。
- QUIZ 画面の「ここで結果を見る」で途中終了できる。**スコアの分母は回答済み数**（未回答を不正解にしない）。最終問題では「結果を見る」と重なるため中断ボタンは隠す。

### パック分類

- TOP は「手ごたえあり（`CHALLENGE_PACK_IDS`）／ふつうのパック／まぜこぜ」の3セクション。
- 「ぜんぶシャッフル」は全パックを混ぜて出題。

### 表現

- 問題・解説は学校、成績、恋愛、暴力、ホラーを避ける
- 絵文字は使わず Material Symbols を使う
- スコアは表示するが、END 文言は点数より「面白かった問題」に寄せる（roomK の非評価思想）
