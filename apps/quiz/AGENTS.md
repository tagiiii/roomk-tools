# クイズパック 仕様書

## 目的・使用シーン

雑学3択、連続2択、ことばクイズなどをパック単位で進めるオフラインクイズツール。
メンターが画面共有し、参加者と相談しながら遊ぶ用途を想定する。

## 技術スタック

- オフラインアプリ（Firebaseなし）
- `index.html` + `app.js` + `questions.js` + `style.css`
- 共通デザインシステムと `shuffle` / `popIn` / `copyToClipboard` を使用

## 画面構成

```
TOP（パック選択） → QUIZ（5問） → END（結果）
```

## 問題データ

`questions.js` の `QUIZ_PACKS` を編集する。

| フィールド | 内容 |
|-----------|------|
| `id` | 問題ID |
| `difficulty` | 1〜3。ラウンド内の抽出バランスに使う |
| `question` | 問題文 |
| `choices` | 選択肢配列 |
| `answerIndex` | 正解選択肢の index |
| `explanation` | 解説文 |

## 特有のルール

- 1ラウンド5問
- 難易度1から1問、難易度2から2問、難易度3から2問を抽出
- 「ぜんぶシャッフル」は全パックを混ぜて出題
- 問題・解説は学校、成績、恋愛、暴力、ホラーを避ける
- 絵文字は使わず Material Symbols を使う
