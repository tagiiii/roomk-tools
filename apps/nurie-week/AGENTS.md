# 塗り絵カレンダー 仕様書

## 目的・使用シーン

不登校・過剰適応など、子ども自身が「自分の時間の使い方」を客観視するきっかけを作るための、メンター＋本人 共同の振り返りツール。1週間×24時間のグリッドをカテゴリ色で塗ることで、量・偏り・余白を眺めて気づきを得る。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（または本人）|
| 閲覧者 | 本人（Zoom/Meet 画面共有で共同編集）|

**利用シーン**
- 面談での「最近どんな1週間？」の振り返り
- 予定詰まりすぎの子の現状認識
- メンターと「この時間って何やってた？」の対話の素材

## 設計思想（必ず守る）

このツールは「**眺めて気づく**」ことが目的。**評価・比較・最適化**に寄せない。

- **本人が主語**: メンターは塗る伴走者であり、評価者ではない
- **証拠化しない**: 保護者・先生への報告材料に寄せない（本人のための内省ツール）
- **時間軸を曖昧に保つ**: 日付は表示せず曜日のみ。「先週」「いつもの1週間」はユーザーに委ねる
- **多重表示**: 色 + アイコン + ラベルでカテゴリを表現（色覚特性・画面共有での「あの色」の指差し対応）
- **カテゴリはフラット**: 「良い時間／悪い時間」のニュアンスを排除し、全カテゴリを対等に扱う

## 入れない機能（意図的に未実装）

便利そうに見えても、以下は **「未実装」ではなく「入れない」**。原則を逸脱する誘惑が強い項目を理由付きで列挙する。

| 入れない機能 | 入れない理由 |
|------------|------------|
| 合計時間・割合グラフ | 数字を出した瞬間「多い／少ない」の評価が立ち上がる |
| 前回・先週との差分表示 | 増減が「改善／悪化」の文脈に変わる |
| 「詰まりすぎ」警告 / バランスチェック | 本人の判断余地を奪う |
| 理想の1週間モード / おすすめテンプレート | あるべき姿の押し付けになる |
| カテゴリの良い／悪い色分け（信号色など） | 全カテゴリはフラットでなければならない |
| おすすめカテゴリ自動判定 | 「これは何の時間？」と本人が意味づける対話の余地が減る |
| 睡眠時間の自動グレーアウト | 「自分の睡眠を観察すること」自体に価値がある子もいる |
| 共有用のきれいな出力 / PDF化 | 証拠化につながる。必要ならスクショで十分 |
| 「データは共有されません」のような打ち消し文 | 安心させようとした文言が逆に不安を喚起する（実際に削除した経緯あり） |
| ユーザー登録・ログイン・サーバー保存 | 本人の所有物として localStorage で完結させる |

## 技術スタック

- 単一HTMLファイル（CSS・JS インライン）
- オフライン動作（Firebase 不要）
- localStorage で状態保存
- pointer events でマウス・タッチ・ペン入力を統一処理

## 画面構成・フロー

```
[画面1枚で完結]
  ├─ ヘッダー（タイトル + サブ）
  ├─ 凡例（5色 + 消しゴム、選択中ボタンは枠+チェック+太枠で多重表示）
  ├─ ツールバー（すべてクリア）
  └─ グリッド（曜日×24時間 = 168マス）
        - 深夜帯（0-5, 23時）は薄背景で常時表示（折りたたまない）
        - クリック単体塗り
        - ドラッグで連続塗り（pointermove + elementFromPoint）

[保存]  150ms デバウンスで localStorage に書き込み
[復元]  ページ読み込み時に localStorage から状態を復元
[クリア] confirm() で確認後、全マスを 0 にリセット
```

## カテゴリ

5色 + 消しゴム。**ID 1-5 はバージョン間で固定**（保存データの後方互換性のため）。

| ID | ラベル | アイコン | 色 |
|----|--------|---------|-----|
| 1 | 予定 | event | #5B8FB9 |
| 2 | 自分で決めた | star | #E07A5F |
| 3 | 生活 | restaurant | #81B29A |
| 4 | 寝てる | bedtime | #9B89B3 |
| 5 | ひとり時間 | weekend | #F2CC8F |
| 0 | けす（消しゴム） | ink_eraser | — |

**カテゴリ変更時の注意**: 色の微調整は問題ないが、ID 振り直し・ラベルの大幅変更は既存 localStorage との互換性を壊す。変更時はマイグレーションを検討する。

## データ構造

```js
// localStorage key: 'nurie-week:v1'
// 形式: 168要素の整数配列（0=空, 1-5=カテゴリID）
// index = day * 24 + hour（day: 月=0, 日=6 / hour: 0-23）
[0, 0, 1, 1, 1, 2, /* ... */]
```

読み込み時は整数 0-5 のみ受け付ける（範囲外は 0 に丸める）。

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| design-system.css | カラートークン、ボタン (.btn-ghost / .btn-sm) |
| Material Symbols Rounded | 凡例アイコン、クリアボタン |

utils.js / firebase-config.js は不使用（オフライン単一ファイルのため）。

## CSS 命名規則

接頭辞 `nw-` + BEM。例: `.nw-cat-btn__swatch`, `.nw-grid__day--sun`, `.nw-cell--latenight`。

## 特有のルール・制約

- pointer events で全入力統合（mouse / touch / pen 区別なし）
- `touch-action: none` でスマホでのスクロール干渉を防ぐ
- `user-select: none` でドラッグ中のテキスト範囲選択を抑止
- 保存は 150ms デバウンス（連続クリックでの過剰書き込み抑止）
- カテゴリ凡例の選択状態は `aria-pressed` + 枠 + チェックアイコンの **多重表示**（色だけに頼らない）
- 曜日順は **月始まり 月-日**（週末を末尾にまとめて見せる）
