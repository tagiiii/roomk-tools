# まちがいさがし 仕様書

## 目的・使用シーン

文章の中にある言葉の違いを見つけ、正しい表現を確認するオフラインツール。
画面共有で「どこが違うか」を一緒に探す用途を想定する。

## 技術スタック

- オフラインアプリ（Firebaseなし）
- `index.html` + `app.js` + `questions.js` + `style.css`
- 共通デザインシステムと `shuffle` / `popIn` を使用

## 画面構成

```
TOP（ジャンル選択） → PLAY（5問） → END
```

## 問題データ

`questions.js` の `QUESTIONS` と `CATEGORIES` を編集する。

| フィールド | 内容 |
|-----------|------|
| `category` | ジャンルID |
| `original` | 正しい文 |
| `modified` | まちがいを含む文 |
| `answer` | 何が違うかの説明 |
| `wrongPart` | 差分表示用の短い説明 |

## 特有のルール

- 1ラウンド5問
- ジャンル別または「ぜんぶシャッフル」で出題
- 正解を強く競わせず、発見として扱う
- 古典・慣用句などを扱う場合も、学校・テストを連想させる文脈に寄せすぎない
- 絵文字は使わず Material Symbols を使う
