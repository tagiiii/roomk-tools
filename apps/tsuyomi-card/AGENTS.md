# つよみカード 仕様書

## 目的・使用シーン

不登校の小中学生との1対1オンライン面談で使う「強みの見せ合い」カードワーク。
「そういうところが あるかも」という弱いトーンの強みカードを、子どもとメンターが
それぞれ選んで見せ合い、自己理解と関係構築につなげる。所要時間 10〜15分。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（子どものターンも子どもの指示で代理操作） |
| 閲覧者 | 子ども（Zoom/Meet等の画面共有で閲覧） |

## 技術スタック

- オフラインアプリ（Firebase不要・ログイン不要・永続化なし）
- 分割ファイル構成: `index.html` + `app.js` + `style.css`（talk-card / value-card 型）
- 共通デザインシステム（design-system.css）+ Material Symbols Rounded
- 外部ライブラリなし

## 画面構成・フロー

```
TOP → PICK（子ども: 0〜3枚 or わからない/えらばない）
        → PICK（メンター: 1〜2枚）
          → SHOW（見せ合い + 任意でJSON保存）
```

- PICK 画面は子ども/メンター共用。`state.phase`（`'kid'` | `'mentor'`）で見出し・上限・ボタンを切り替える
- 「まえに もどる」で前のフェーズへ戻れる（選択は保持）
- 「さいしょから」で全状態をリセットして TOP へ

## カードデータ

42枚。`app.js` の `CARD_TEXTS` 配列を直接編集する。

### カード文言ガイドライン（必ず守る）

- **非断定形のみ**: 「〜かも」「〜ほうかも」「〜ときが あるかも」。「あなたは〇〇だ」という断定形は禁止
- 学校・勉強文脈の強み（成績・テスト・発表・宿題など）は禁止
- 他人との比較（「〜より」「だれよりも」「いちばん」）は禁止
- 小学校中学年でも読める表現・分かち書き
- 「たまに出る力」のトーン。毎回出せることを前提にしない

## 心理的安全設計（このツールの核）

- **未選択カードのグレーアウト・✕表示をしない**。「選ばれなかったカード＝弱み」という見え方を作らない
- **一致・不一致の判定や祝福演出をしない**。「同じのあった！」はメンターが口頭で言う
- **枚数を数字で表示しない・比較しない**（選択上限の案内トーストのみ枚数に言及する）
- 「わからない」「きょうは えらばない」はカードと同格の正式なこたえ（kimochi-map と同思想）。
  押すと尊重の一言を返す（なぐさめ・分析はしない）
- 見せ合い画面の「わからない」「えらばなかった」表示もカードと同じ見た目にする

## JSON 書き出し（保存のみ・読み込みなし）

sakusen-kaigi 方式の書き出しのみ対応。読み込み機能は意図的に持たない。

```json
{
  "app": "tsuyomi-card",
  "schemaVersion": 1,
  "fileMarker": { "color": "みどり", "animal": "ネコ" },
  "createdAt": "ISO 8601",
  "kid":    { "answer": "cards | wakaranai | erabanai", "cards": [{ "id": 1, "text": "…" }] },
  "mentor": { "answer": "cards", "cards": [{ "id": 2, "text": "…" }] }
}
```

- `fileMarker` は色×動物方式（個人名なし）。見せ合い画面到達時に自動生成し、画面下部に表示する
- ファイル名: `tsuyomi-card_{animal}-{color}_{YYYY-MM-DD}.json`

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost / .btn-lg / .btn-full |
| escapeHtml | カード文言・マーカーの DOM 挿入時の XSS 対策 |
| showToast | 選択上限の案内・保存完了の通知 |

## CSS命名規則

接頭辞: `.ty-`（tsuyomi-card。`tc-` は talk-card が使用済みのため不可）

| クラス | 用途 |
|--------|------|
| `.ty-card` | 選択画面のカード（button） |
| `.ty-card--selected` | 選択中のカード（アクセント枠 + チェックアイコン） |
| `.ty-noanswer__btn` | 「わからない」「きょうは えらばない」ボタン |
| `.ty-show-group` | 見せ合い画面の子ども/メンター枠 |
| `.ty-show-card--answer` | 見せ合い画面の「えらばなかった」系表示 |
| `.ty-marker` | きろくの目じるし（色×動物） |

## 入れない機能（意図的に未実装）

- 一致判定・祝福演出・スコア・ランキング
- 選択枚数の表示・両者の枚数比較
- 未選択カードのグレーアウト・除外表示
- JSON の読み込み（書き出しのみ）
- 永続化（localStorage 含む）・履歴

## 特有のルール・制約

- 子どもの選択上限は3枚、メンターは2枚。超過時は showToast('…', 'info') でやわらかく案内する
- 子どもは0枚でも次へ進める（「つぎへ」ボタンは常に有効）。メンターも同様に強制しない
- カードには丸数字（①〜㊿）を付け、子どもが「12ばん！」と口頭・チャットで指定できるようにする
  （`circledNumber()` が Unicode の ①〜⑳/㉑〜㉟/㊱〜㊿ を生成）
- カードを選ぶと「えらばない」状態は解除、「えらばない」を押すとカード選択はそっとクリアする

## 既存ガイドラインからの例外

- なし（コンテンツガイドラインに準拠。強みカードだが評価・比較・学校文脈を含まない）
