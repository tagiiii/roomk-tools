# 漢字さがし 仕様書

## 目的・使用シーン
にている漢字の中からお題の漢字を見つける観察力ゲーム。
メンターが操作・画面共有し、参加者と一緒に漢字を探す。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 参加者 | 生徒（Zoom/Meet等の画面共有で閲覧・口頭参加）|

**利用シーン**
- セッション中のアクティビティ
- 集中力・観察力を使うウォームアップ

## 技術スタック
- オフラインアプリ（Firebase不要・ログイン不要）
- 共通デザインシステム使用
- ファイル構成: `index.html` + `app.js` + `style.css`

## 画面構成・フロー

```
[設定画面]
  難易度（やさしい / ふつう / むずかしい）
  制限時間（15秒 / 20秒 / 30秒）
  → はじめる

[お題プレビュー]
  対象の漢字を大きく表示（個数は非表示）
  → スタート

[プレイ画面]
  タイマーバー + 漢字グリッド（閲覧のみ・操作なし）
  参加者は画面を見て漢字を数える
  → タイマー終了

[答え合わせ画面]
  グリッドが固定表示される（まだ答えは非表示）
  → 参加者に口頭で何個見つけたか聞く
  → 「答えを見る」ボタンで正解をハイライト表示
  → 「次の問題」（同じ設定で続行）
  → 「設定を変える」（設定画面に戻る）
```

## 難易度プリセット

| レベル | グリッド | ターゲット数 | 回転 | サイズ揺れ | 問題の紛らわしさ |
|--------|---------|------------|------|----------|--------------|
| やさしい | 5×5 | 3〜5個 | なし | なし | 低 (visualDifficulty 1) |
| ふつう | 6×6 | 4〜6個 | ±15° | 小 | 低〜中 (1-2) |
| むずかしい | 7×7 | 5〜8個 | ±30° | 大 | 中〜高 (2-3) |

## 問題データ
`app.js` 内の `const QUESTIONS = [...]` を直接編集する。

各問題の構造:
```js
{ target: '犬', distractors: ['大', '太', '天'], visualDifficulty: 1 }
```

### 問題作成ガイドライン
- `target` と `distractors` は視覚的に似た漢字を選ぶ
- `visualDifficulty` は 1（見分けやすい）〜 3（非常に似ている）
- 不快感のある漢字の組み合わせは避ける
- ターゲットがディストラクタに含まれないこと

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | セル配置のランダム化、問題プールの管理 |
| M-5 popIn | プレビューの漢字表示、答え合わせのハイライト |
| M-6 ボタン | .btn-primary / .btn-secondary |

## CSS命名規則
接頭辞: `.ks-`（kanji-sagashi）
例: `.ks-header__title`, `.ks-grid`, `.ks-cell`, `.ks-cell--found`

## 特有のルール・制約
- プレイ中のグリッドは閲覧のみ（タップ/クリック操作なし）
- 正解数はプレビュー画面では表示しない（答え合わせまで隠す）
- タイマー終了後すぐには答えを表示しない（「答えを見る」ボタンで公開）
- 使用済みの問題は同一セッション内で重複しない（プール枯渇時にリセット）
- `prefers-reduced-motion` 有効時は回転・サイズ揺れを無効化
