# え!? 実は○○なんですかゲーム 仕様書

## 目的・使用シーン

ある参加者の「意外な一面」を他の参加者が推理するアイスブレイクゲーム。
セッション序盤の場づくりや、お互いをもっと知り合いたいときに使う。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（ホスト） |
| 閲覧者 | 参加者全員（Zoom/Meet の画面共有で閲覧）|

## フェーズと画面の対応

| フェーズ | 画面の状態 | 操作できること |
|---------|-----------|-------------|
| 未選択 | カード3枚が裏向き | カードをクリック・「3枚引き直す」 |
| 選択済み | 選んだカードが表向き・他2枚が薄く | コピー・「新しいカードを引く」 |

## ゲームフロー

1. **主役を決める** — ホストが「今日の主役」を1人指名する。
2. **お題を選ぶ** — ホストはカード3枚の中から「これ聞いてみたい！」と思うお題をひとつクリックしてひらく。お題が全員に表示される。
3. **YES / NO を予想する** — 参加者全員が「YES かな？ NO かな？」を声で予想して話し合う（アプリ上のボタン操作は不要）。
4. **主役が答える** — 主役が「YES！」か「NO！」かを発表して答え合わせ！
5. **次のラウンドへ** — 「新しいカードを引く」で別の主役に交代する。

## 技術スタック

- オフライン単一アプリ（Firebase不要・ログイン不要）
- 共通デザインシステム（M-1〜M-6）を使用

## ファイル構成

```
apps/jitsuwa-game/
├── index.html   # UI（hero・prompt panel・カードグリッド・ガイド）
├── style.css    # アプリ固有スタイル
```

## プロンプトリストの管理

`app.js` 内の `const prompts = [...]` を直接編集する（現在126枚）。

### カテゴリ構成（各21枚）

| カテゴリ | テーマ |
|---------|--------|
| 食べものの好み | 辛い/甘い/特定の食材に対する意外な好み |
| 日常の習慣・生活 | 朝型/整理整頓/入浴など日常の意外な習慣 |
| 得意なこと・意外な能力 | 記憶力/リズム感/折り紙など |
| 趣味・コレクション | フィギュア/植物/カードゲームなど |
| 性格・行動パターン | マイペース/几帳面/空想好きなど |
| 意外な一面・あれこれ | その他の個性的なトレビア系 |

### 新しいプロンプトを追加するときのガイドライン

- 「え!? 実は〜なんですか？」の形式を守る
- ポジティブまたはニュートラルな内容にする（ネガティブな評価・コンプレックスを連想させない）
- 学校・勉強・成績・恋愛・暴力・ホラーなどの禁止トピックを避ける（AGENTS.md 参照）
- 小学校中学年〜中学生が「あるある！」「えー知らなかった！」と感じられる内容にする
- 短く読みやすい日本語で（ひらがな多め、目安30字以内）

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-3 shuffle | プールのシャッフル（重複なしサイクル） |
| M-2 copyToClipboard | コピーボタンのフィードバック |
| M-4 カードフリップ | 正解カード選択時のフリップ演出 |
| M-5 popIn | プロンプトパネルの出現アニメーション |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost |

## セッション進行のヒント

- 主役は毎ラウンド交代すると全員が楽しめる。
- 答えが当たっても外れても「え!? そうなんですか！」と盛り上げるのがコツ。
- 主役が「どれも当てはまらない」と感じた場合は「一番近いもの」を選んでもOK。
- カードが刺さりすぎると感じた子がいたら「全カードをリセット」で気分を変えられる。
- 1ラウンド1〜2分が目安。人数が少なければ1人2回まわしても楽しい。
