# 神経衰弱 — アプリ固有仕様

共通の権限・品質基準はルート [AGENTS.md](../../AGENTS.md)。

## 目的・使用シーン

裏になったカードを2枚めくって同じ絵をそろえる、定番の遊び。メンターなどとゆっくり遊ぶ。

> 経緯: 2026-11-12 オーナーの依頼（リバーシのようにメンターなどとゆっくり遊べる新しいツール・小学生でもルールがすぐわかるもの・幅広い層が遊べるよう激ムズも・CPU 対戦も）で `drafts/shinkei-suijaku/` に試作 → 同日オーナーが「この形で本体化」と承認。

- 名前は「神経衰弱」（伝統的なトランプ遊びの一般名称。app-registration.md「アプリ名のつけかた」の例外。2026-11-12 オーナー決定）
- 既製のカードの絵柄は使わない。絵は Material Symbols と、自前で描く図形

### セッション条件（ツール一覧のカードと同じ）

| 項目 | 値 |
|---|---|
| 人数 | 1〜4人（CPU と対戦は1人、人どうしは2〜4人） |
| 目安時間 | 5〜15分 |
| 利用シーン | ボドゲクラブ・ひろば・作戦会議（`bodoge hiroba sakusen`） |
| 話す量 | 選ぶだけ（`pick`） |
| 自分の話 | 外の題材で遊べる（`outside`） |

`silent` は付けていない。1台の画面を共有して遊ぶとき、押すのはメンターで、子どもは番号を声かチャットで伝えるため。

## 技術スタック

オフライン（通信しない）。`index.html` + `app.js` + `data.js` + `style.css`。Firebase は使わない（stats.js の利用回数だけ）。
ルーム（それぞれの端末で押す・観戦）は入れていない（2026-11-12 オーナー「1台の形のまま本体化」）。入れるときは `database.rules.json` に名前空間を足す承認が要る。

4つのファイルはセットで変わるので、変えたら `?v=` をそろえて上げる。

## 画面構成・フロー

1. **はじめの画面**（`#ss-front`・入口の型 `.app-entry`）: 対戦の相手・CPU の強さ（CPU のときだけ）・人数（人どうしのときだけ）・名前・むずかしさ →「はじめる」
2. **遊ぶ画面**（`#ss-app`）: 上の帯（名前・むずかしさ・「設定にもどる」）／名前の札（番の印・ペアの数）／ひとことの案内／盤
3. **おわり**: 盤の上に「ぜんぶそろった！」の面。「もう一回」（同じ設定・はじめの人を順に交代）と「設定にもどる」

読み込み直すと、はじめの画面にもどる（続きは残さない）。

## ルールと設定

| 項目 | 内容 |
|---|---|
| 対戦の相手 | CPU（はじめの値）／人どうし（2〜4人・1台で交代） |
| むずかしさ | かんたん 12枚／ふつう 20枚／むずかしい 30枚／激ムズ 40枚（`data.js` の `levels`） |
| ふつうの絵 | Material Symbols の絵25種類からくじで選ぶ（`icons`） |
| 激ムズの絵 | 形（丸・三角・四角・星・ハート）× 数（1〜4）の20ペア。形も数も同じカードがペア。色は形ごとに決まっていて、色だけで見分ける所はない |
| 番 | 2枚めくって同じ絵ならもらえて、もう1回。ちがったら裏にもどして次の人 |
| カードの番号 | 裏にも表にも出す（画面共有で「5番と12番」と伝えられるように）。40まであるので丸数字ではなくふつうの数字（ui.md「選択肢・カードの番号付け」からの意図した例外） |
| 取ったカード | 表のまま薄くして場に残す。だれが取ったかは出さない |
| 待ち時間 | ちがったカードは1.6秒見せてからもどす。そろったカードは0.8秒。CPU は1枚ごとに0.9秒おく（`app.js` の `T`）。`?fast=1` で短くなる（確かめる用） |
| 音 | 鳴らさない |

### CPU

| 強さ | 覚え方（`data.js` の `cpuLevels`） |
|---|---|
| よわい | めくられたカードを3割覚える。覚えているペアがあっても、半分は取りにいかない |
| ふつう（はじめの値） | 65%覚える |
| つよい | すべて覚える |

めくり方（`cpuTurn`）: 覚えているペアがあれば取る。なければ知らないカードを1枚めくり、相手を覚えていればそれを、いなければ知らないカードをもう1枚めくる。
覚えるのは、人がめくったカードも CPU がめくったカードも同じ（`observe`）。
強さの値は 2026-11-12 に AI が決めた仮置き（オーナー確認待ち）。

### 結果の出し方

- 対戦中、名前の札に全員のペアの数を出す（0ペアもふくむ）。ふつうの神経衰弱と同じ形（2026-11-12 オーナーに「出したままにする」と伝えたうえで本体化の承認）
- おわりは、いちばん多く取った人の名前とペアの数だけ（全員同じなら「引き分け」）。順位の一覧は出さない

## データ構造

保存するものはない。状態は `app.js` の `setup`（設定）と `game`（`cards`・`players`・`turn`・`open`・`lock`・`memory`）だけで、メモリの中にある。
タイマーは `later()` で登録し、対戦が替わると（`game` が別の物になると）動かない。

## 共通モジュールの使用箇所

- `design-system.css`（`data-genre="board"`・`.app-entry`・ボタン・入力欄）
- `howto.js`（あそびかた。説明スライドはない）
- `stats.js`（利用回数）

### 利用回数

「1回」は1ゲーム（はじめてから、ぜんぶそろうまで）。

| 項目 | 数えるとき |
|---|---|
| `start`・`players-{N}` | ゲームがはじまった（「はじめる」と「もう一回」）。N は CPU をのぞいた人数 |
| `finish` | ぜんぶそろった |
| `again` | 「もう一回」を押した（そのまま次がはじまるので `start`・`players-{N}` も数える） |

CPU と対戦かどうか・むずかしさは分けていない。

## 特有のルール・制約

- イラスト（`apps/assets/illustrations/shinkei-suijaku.webp`）は 2026-11-12 に作った（星のカードが2枚そろい、下に裏のカードが並ぶ絵。指示文は `scripts/illustrations/prompts.json`。6回めで採用）。ツール一覧のカードと、はじめの画面の絵の面（`.app-hero`）に出す。サムネイル（画面の例）は作っていない
- 盤は画面の高さに収まるように、幅を高さからも決めている（`.ss-board-wrap` の `max-width`。`--cols`・`--rows`・`--maxw` は `app.js` の `applyCols` が入れる）。600px 以下では列の数を減らす（`levels` の `colsSp`）
- 取ったカードを薄くするとき、`.ss-card__inner` に `opacity` を付けない（3D の裏返しがつぶれて裏の面が出る）。面のほうに付ける
- SVG の名前空間は、`index.html` の空の `<svg id="ss-svg-ns">` から取っている（試作用 lint が外部 URL の文字列を禁じていたため。そのままにしてある）
