# おとなトークカード 仕様書

## 目的・使用シーン
オンライン支援現場の朝のサークルタイム「自由時間（最初の15分）」を、
**大人の雑談時間**として使うためのトーク提示ツール。
質問するのも答えるのも大人（スタッフどうし）。子どもはその雑談を横で聞く（聞くだけでよい）。
大人の仕事や歩んできた道を雑談ごしに知ることで、**ゆるくキャリアにつながる**時間をめざす。

トークテーマカード（`talk-card`）の姉妹ツール。あちらは「子どもが答える」のに対し、
こちらは「大人どうしが質問し合い、子どもは聞き役」という点が決定的に異なる。

| ロール | 説明 |
|--------|------|
| 操作者 | スタッフ（メンター） |
| 質問者・回答者 | 大人（スタッフどうし） |
| 聞き役 | 子ども（Zoom/Meet 等の画面共有で聞く。気が向けば参加してもよい） |

**利用シーン**
- サークルタイム冒頭の自由時間（大人の雑談タイム）
- 子どもが大人の仕事・人生・選択を知るきっかけづくり
- アイスブレイク・話題に詰まったときの話題提供

## 技術スタック
- オフライン単独動作（Firebase 不要・ログイン不要）
- ファイル構成: `index.html` + `app.js` + `style.css`（talk-card と同パターン）
- 共通デザインシステム & `shared/js/utils.js` の `shuffle`(M-3), `copyToClipboard`(M-2), `popIn`(M-5) を使用
- CSS 接頭辞: `.ot-`

## 画面構成・フロー

```
[初期表示]
  カテゴリフィルター（ぜんぶ＋6カテゴリ。初期は全選択）
  カード3枚を裏向きで表示（番号のみ）

[カテゴリチップをタップ]
  → 選択カテゴリを切替（最低1つは残す）
  → プールを再構成し3枚引き直し

[カードをタップ]
  → M-4 フリップ → 他2枚が dimmed
  → お題表示エリアが M-5 popIn で出現（カテゴリ名 + 質問）

[お題表示エリア]
  → コピーする（M-2）／ 別のカードを引く（3枚リセット）

[引き直し]
  → カード選択前のみ有効。選択中カテゴリのプールから3枚抽出
```

## データ構造
Firebase 不要。すべてクライアントサイドで完結。

- `CATEGORIES`: カテゴリ定義（`key` / `label`）
- `topics`: `{ t: 質問文, c: カテゴリキー }` の配列（`app.js` を直接編集）

### カテゴリ（軽い雑談 → 仕事・歩んできた道 → これから の順）
| key | label | ねらい |
|-----|-------|--------|
| icebreak | アイスブレイク | 人となりを身近に感じる軽い雑談 |
| kids | 子ども時代 | 大人にも子ども時代があったと知る |
| work | 仕事のこと | 働く大人の姿が見える |
| path | 歩んできた道 | キャリアの道のり。寄り道・回り道も歓迎 |
| values | 考え方 | 大事にしていること・価値観 |
| future | これから | 大人にも夢がある |

### お題作成ガイドライン
- **回答者は大人**なので、talk-card で避ける「学校・勉強・進路」の話題は扱ってよい
  （学生時代・進路選択はキャリアの核として積極的に使う）
- ただし**聞いている子どもにプレッシャーを与えない**こと。
  子ども自身の進路・成績・将来を問い詰める方向には絶対にしない。
  あくまで「大人が自分の経験を、開かれた軽いトーンで語る」質問にする
- 正解のない開かれた質問にする。説教臭く・キャリア指導臭くしない
- 比較や優劣を促す質問は避ける

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-2 copyToClipboard | コピーボタンのフィードバック |
| M-3 shuffle | お題プールのシャッフル |
| M-4 カードフリップ | .flip-card クラス（CSS + JS） |
| M-5 popIn | お題表示エリアの出現アニメーション |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost |

## 特有のルール・制約
- カード枚数は固定3枚（`drawHand()` の `splice(0, 3)`）
- プール残数が3未満になったら選択中カテゴリのお題を再シャッフルして補充
- カテゴリフィルターは最低1つを残す（全解除不可）
- カード表面・お題表示エリアにカテゴリ名を表示する
- キーボード操作対応（Tab + Enter/Space でカード選択）
