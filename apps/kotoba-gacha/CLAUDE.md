# ことばガチャ 仕様書

## 目的・使用シーン
ひとこと（助詞）を入れ替えると、文の「空気」がどう変わるかを遊ぶ言葉アプリ。
メンターが画面共有しながら、参加者と「どれが好き？」を話し合う対話のきっかけに使う。

**文法を学ぶアプリではなく、言い方で空気が変わるのを遊ぶアプリ**という振り切りが企画の芯。
UI上は「助詞」「てにをは」などの文法用語を一切出さない。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 生徒（画面共有で閲覧）|

## 技術スタック
- 単一アプリ（Firebase 不要・ログイン不要）
- 共通デザインシステムを使用
- CSS 接頭辞: `.kg-`

## 画面構成
```
[TOP 画面]
  タイトル「ことばガチャ」/ サブ「ひとこと変えると、空気が変わる」
  → はじめる

[プレイ画面]
  右上に控えめな進捗 (1 / 10)
  お題文（◯ の位置がスロット）
  助詞カード（2〜3個、お題ごとに固定）
  選択後 → 完成文カード + ヒント文（何度でも切り替え可）
  → つぎのお題 / TOPにもどる

[おしまい画面]
  10問ぜんぶ見たよ
  → もう一回（シャッフルして再スタート）/ TOPにもどる
```

## お題リスト
`app.js` 内の `const QUESTIONS = [...]`（10問）。初版確定済み。

### お題作成ガイドライン（重要）
- **文法用語は UI に出さない**（内部の変数名として `particle` は使ってよい）
- 「正しい・間違い」ではなく「感じが変わる」が伝わる候補だけ採用する
- どの選択肢も文として**自然に成立**することを優先
- ヒント文は感覚語のみ（「〜な感じ」「〜っぽい」）、10〜18字程度
- お題は「食べ物」「気持ち」「人との関係」などトピックを分散させる
- `こそ` `って` `で / に` は初版では不採用（固い／正誤寄りになりやすい）

## 特有のルール・制約
- お題ごとに候補（助詞）は**固定**。ランダムに混ぜない
- 選択は**何度でも切り替え可能**。1回で固定しない
- 選んだ助詞は完成文で `--color-accent` 色付け
- お題は起動時に `shuffle()` でランダム順
