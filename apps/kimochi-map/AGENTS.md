# きもちのことばマップ 仕様書

## 目的・使用シーン

不登校の小中学生との**1対1オンライン面談**で使う感情語彙ツール。
メンターが画面共有して使うのが基本形。子どもは口頭・チャットで「3つめのやつ」などと答える。
子ども自身が URL を開いて自分でタップする回もある。

感情語彙のマップから「今日（または最近）の気持ちに近いことば」を探して眺め、
**気持ちを言葉にする練習**をするためのツール。診断・記録のためではなく、**語彙と対話のため**のツール。

| 項目 | 内容 |
|------|------|
| 対象 | 不登校の小中学生（1対1面談） |
| 所要時間 | 5〜10分 |
| 操作者 | メンター（画面共有）または子ども本人 |

## 技術スタック

- オフライン単独動作（Firebase 不要・ログイン不要）
- **永続化は一切なし**。localStorage / sessionStorage も使わない。**リロードで消えるのが正しい仕様**
- ファイル構成: `index.html` + `app.js` + `style.css`（talk-card と同パターン）
- 共通デザインシステム（design-system.css）と Material Symbols Rounded を使用。絵文字禁止
- CSS 接頭辞: `.km-`（BEM 記法）
- レスポンシブ対応（600px 以下で1カラム）

## 画面構成・フロー

```
[初期表示]
  問いかけ「きょうの きもちに ちかい ことばは ある？」
  （「今の気持ちは？」と直球で聞かない）
  ＋「わからない」「どれでもない」「今日は選ばない」ボタン（常時表示・同格）
  ＋ 全グループのことばチップ一覧（マップ）

[ことばチップをタップ]
  → 選択（複数選択可）。選択パネルが出る
  → 同グループ内の前後2語が破線でゆるくハイライト（「こっちのほうが ちかい？」）
  → 任意で大きさを選べる: 小さめ／ふつう／大きめ（スキップ可）
     選ぶとマップ上のチップの文字サイズが変わる

[「わからない」等をタップ]
  → 尊重する一言（例:「OK、それも だいじな こたえ。」）を表示
  → ことばの選択はそっと解除され、マップは眺めるだけモードで居られる

[けす]
  → いつでも全選択解除

終了ボタン・結果画面はない。閉じて終わり。
```

## データ構造

Firebase 不要。すべて `app.js` 内の `GROUPS` 配列で完結。

- `GROUPS`: `{ key, name, words: [...] }` の配列（6グループ・計72語）
- グループ名は子どもの言葉: にこにこ系／ぽかぽか系／もやもや系／ざわざわ系／ぐったり系／すっきり系

### 語彙リスト方針（編集時に必ず守る）

1. **60〜80語**を維持する（現在72語）
2. 小学校中学年でも読める**ひらがな中心**の表記（漢字を使う場合はやさしい漢字のみ）。
   ※これは**語彙72語とグループ名**の規定。語彙は表記トーン方針（ルート AGENTS.md）の
   対象外で、2026-08-06 のUI通常表記化でも変えていない。**UI文言（見出し・ボタン・
   案内・尊重の一言）は通常表記（漢字まじり）**とする（読めない子にはメンターが読み上げる）
3. 各グループ内は**「近い言葉」が隣り合う順**に並べる
   （選択時に前後 `NEAR_RANGE`(=2) 語がハイライトされるため、並び順に意味がある）
4. ネガティブ語彙は必ず入れるが、**深刻度の上限は「つらい」「しんどい」まで**。
   絶望・消えたい・死・自傷を連想させる語は入れない
5. 学校・勉強・成績・登校関連の文脈、恋愛に関わる語は入れない
6. グループ名は医学・心理用語（抑うつ・不安障害等）にしない

## 設計思想（心理的安全が最優先）

- **「選ばない」も正式な回答**。「わからない」「どれでもない」「今日は選ばない」は
  すみに小さく置くのではなく、問いかけ直下にことばと同格の見た目で常時表示する
- 押したときの一言は「尊重の返事」であって、なぐさめ・分析・アドバイスではない
- グループに優劣をつけない: 全グループ同トーンの穏やかな色。
  **ネガティブ系を暗い色・警告色（赤・黒等）にしない**（style.css のグループ色定義を参照）
- 大きさは「小さめ／ふつう／大きめ」の3語のみ。数値・スライダー・パーセントは使わない
- **メンター向けの注意書きは画面に出さない**（checkout-card と同方針・ユーザー指示）。
  進行の心得は本ドキュメントに書く: **ことばを さがすだけで OK。ふかぼりしない**

## 入れない機能（意図的に未実装）

- **記録・保存・履歴**: 選んだ内容をどこにも残さない。気持ちを証拠化しない
- **コピー・共有・スクショ支援**: 選択結果をテキスト化して持ち出す機能は作らない
- **診断・分析・アドバイス**: 「この気持ちのときは〜しよう」的な表示は一切しない
- **点数化・グラフ化**: 気持ちを数値にしない（kyapa-graph とは逆の哲学。mienai-ganbari と同系統）
- **終了ボタン・結果画面**: まとめを見せると「答え合わせ」になるため作らない。閉じて終わり

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承（色・角丸・余白） |
| M-6 ボタン | 「けす」ボタン（.btn-ghost .btn-sm） |

utils.js は使用していない（shuffle・copy とも不要なため）。

## 既存ガイドラインからの例外

共通コンテンツガイドラインは「暴力・ホラー・死などダークな内容を使わない」
「好き・楽しいなどポジティブな軸を推奨」としているが、本アプリは感情語彙ツールとして
**ネガティブな気持ちのことば（もやもや／いらいら／つらい／しんどい 等）を意図的に収録する**。

- 理由: ネガティブな気持ちに「ことば」を与えることがこのツールの目的の半分であり、
  ポジティブ語だけでは「いやな気持ちは言ってはいけない」というメッセージになってしまうため
- 歯止め: 深刻度の上限は「つらい」「しんどい」まで（上記・語彙リスト方針 4）
- グループの見た目でネガティブを特別扱いしない（色・配置に優劣をつけない）

## 特有のルール・制約

- 「今の気持ちは？」という直球の問いかけ文言に変更しない（詰問にならない距離感を保つ）
- 「えらばない」系ボタンを目立たない場所に移動しない（同格性がこのツールの核）
- 選択状態はメモリ上のみ（`state`）。永続化を追加しない
