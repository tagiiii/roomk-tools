# チェックアウトカード 仕様書

## 目的・使用シーン

不登校の小中学生との1対1オンライン面談の**最後の1〜2分**に、メンターが画面共有して1問だけ引くミニツール。
今日の体験を次回へつなげる短い問いかけで面談を締めくくる。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 子ども（Zoom/Meet/Metalife 等の画面共有で閲覧）|

**最重要の設計要件**: メンターによる評価・感想の聞き取りに見えないこと。
「今日どうだった？」型の質問はメンターからの評価質問に見えるため、問いは「子どもが選ぶ・決める」形に寄せている（docs/content-plan.html の codex 指摘への対策）。

## 技術スタック

- talk-card 型のオフライン構成（`index.html` + `app.js` + `style.css`）
- Firebase・localStorage 等の永続化は**一切使わない**
- 共通デザインシステム（M-1〜M-6）+ Material Symbols Rounded（絵文字禁止）
- CSS 接頭辞: `ck-`（BEM 記法）

## 画面構成・フロー

1画面完結。トップ画面なし。開いたら即カードが引ける。

```
[初期表示]
  裏向きの大カード + 「カードを引く」「今日はパス」

[カードを引く]（カード本体クリック / Enter / Space でも可）
  → M-4 フリップでランダムに1問表示
  → ボタンが「別のカードにする」に切り替わる

[別のカードにする]
  → いつでも引き直せる（回数制限なし、記録なし）
  → 裏に戻る → 裏向きの間に問いを差し替え → 再フリップ

[今日はパス]
  → 「OK！また来週！」等の軽い一言だけを M-5 popIn で表示して終わる
  → 戻るボタンは意図的に置かない（誤操作時はリロード。状態がないので即復帰）
```

## 問いデータ

`app.js` 内の `const QUESTIONS = [...]`（24問）を直接編集する。3方向をバランスよく（各8問）:

1. **次回につなぐ問い**: 「次の作戦会議でやってみたいこと、ある？」
2. **今日を軽く締める問い**: 「今日はここまででOK？」
3. **ゆるい未来の問い**: 「来週までに楽しみなこと、ある？」（「がんばること」は聞かない）

### 問い作成ガイドライン（禁止事項）

- 評価・感想・成果を問う形（「今日はどうだった？」「何を学んだ？」「がんばれた？」）
- 学校・勉強・登校に関連する内容
- 「目標」「宿題」という語
- 答えが長くなる問い（一言で済むものだけ）

表記は**通常表記（漢字まじり）**（2026-08-06 ユーザー判断で分かち書きから刷新。
ルート AGENTS.md「表記トーン」参照。読めない子にはメンターが読み上げる）。
カード表面には常に「わからない・ないしょ・パスも全部正解」を小さく添える。

## 心理的安全設計

- 答えなくても面談が終われる。「今日はパス」は正式なボタンで、パス後の文言（`PASS_MESSAGES`）は失敗に見えない軽い一言のみ
- 「1問だけ。ふかぼりしない」はメンター側の運用ルール。画面には注意書きを表示しない（子どもにも見える画面共有にメンター向け文言を出さない方針。2026-07-04 ユーザー指示で削除）

## 入れない機能（意図的に未実装）

- 出題履歴・集計・お気に入り・保存（その場で流れて消えるのが正しい）
- 複数問の連続出題を促す UI（1問だけ。長引かせない）
- 回答の入力欄・記録欄（口頭で答えて終わり。証拠化しない）
- パス後の「もどる」ボタン（パスで面談が締まったことにする）

連続で同じ問いが出ないようにするための「直前の1問」と、シャッフル済みプール（在庫）だけをメモリに持つ。

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | 問いプールのシャッフル |
| M-4 カードフリップ | `.flip-card`（`.ck-card`） |
| M-5 popIn | パス後メッセージの出現 |
| M-6 ボタン | `.btn-primary` / `.btn-secondary` / `.btn-ghost` |

## 特有のルール・制約

- 問いは静的文字列のみで DOM 挿入は `textContent` を使用（`innerHTML` 不使用）
- `style.css` で `[hidden] { display: none !important; }` を定義している（`.btn` の `display` 指定が UA の hidden スタイルを上書きするため）
- キーボード操作対応（Tab + Enter/Space でカードを引ける）
- プールが空になったら全問を再シャッフルして補充。補充直後に直前の問いが先頭に来た場合は末尾へ回す
