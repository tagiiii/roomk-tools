# バリューカード 仕様書

## 目的・使用シーン

メンタリングセッションで使う「自分の大事を見つけるカードワーク」。
メンターが操作し、生徒に画面共有して使う。
単なる価値観診断ではなく、メンターとの対話の材料として設計。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 生徒（Zoom/Meet等の画面共有で閲覧）|

**利用シーン**
- セッション中の自己理解ワーク
- 生徒の興味・価値観の探索
- 振り返り（結果画像を保存して後日参照）

## 技術スタック

- オフラインアプリ（Firebase不要・ログイン不要）
- 共通デザインシステム（M-1〜M-6）を使用
- 外部ライブラリ: SortableJS（並び替え）、html2canvas（画像書き出し）

## 画面構成・フロー

```
TOP → GAME（交換） → RANKING（並び替え） → RESULT（メモ+画像保存）
                                                  ↓
                                               TOP に戻る
```

### TOP（screen-top）
- タイトル・サブタイトル表示
- 「はじめる」ボタン → GAME へ
- 「あそびかた」トグルパネル

### GAME（screen-game）
- 30枚からランダムに5枚配布
- カードをタップで選択 → 「交換する」で山札と入れ替え
- 交換回数: 5回（交換済みカードは山札に戻さない）
- 「この5枚で決定する」→ RANKING へ

### RANKING（screen-ranking）
- 5枚を縦に並べて順位付け
- 操作: 上下矢印ボタン（タップ）+ ドラッグ&ドロップ（デスクトップ）
- 「順番を決定する」→ RESULT へ

### RESULT（screen-result）
- 確定順位でカードを表示
- 各カードの下に textarea（ひとことメモ、任意、最大100文字）
- 「画像を保存する」→ html2canvas で PNG 書き出し（メモも含む）
- 「最初からやり直す」→ TOP へ

## カードデータ

30枚。`app.js` 内の `cardData` 配列を直接編集する。

### カード作成ガイドライン
- 学校・勉強・宿題を連想させる表現は使用しない
- 抽象的な語彙を避け、子どもが実感できる具体的な言葉にする
- 「〜が好き」「〜が大事」「〜したい」のトーンで統一
- 恋愛・暴力・ホラーなどダークな内容は含めない

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | カードプールのシャッフル |
| M-5 popIn | （現状未使用、追加時に利用可能） |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost / .btn-lg / .btn-full |
| escapeHtml | メモ・カード内容のXSS対策（画像生成時のDOM挿入含む） |

## CSS命名規則

接頭辞: `.vc-`（value-card）

| クラス | 用途 |
|--------|------|
| `.vc-header__title` | ページタイトル |
| `.vc-card` | ゲーム画面のカード |
| `.vc-card--selected` | 選択中のカード |
| `.vc-rank-item` | ランキング画面のカード行 |
| `.vc-result-item` | 結果画面のカード+メモ |

## 特有のルール・制約

- カードは常に表向き（flip-card は使わない）
- 交換済みカードはプールに戻さない（毎回新しいカードに触れる体験）
- 交換回数は5回固定
- ランキングの主操作はタップ（上下ボタン）、ドラッグはデスクトップ補助
- メモの画像書き出し時は escapeHtml で XSS 対策
- html2canvas のキャプチャ用 DOM は一時生成→完了後に削除
