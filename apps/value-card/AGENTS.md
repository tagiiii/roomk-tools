# バリューカード 仕様書

## 目的・使用シーン

メンタリングセッションで使う「自分の大事を見つけるカードワーク」。
メンターが操作し、生徒に画面共有して使う。
単なる価値観診断ではなく、メンターとの対話の材料として設計。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 生徒（Zoom/Meet等の画面共有で閲覧）|

**利用シーン**
- セッション中の自己理解ワーク
- 生徒の興味・価値観の探索
- 振り返り（結果画像を保存して後日参照）

## セッション条件（ツール一覧のカードと同じ。2026-11-08）

スタッフがツールを選ぶときの条件。値はツール一覧（`apps/index.html`）のカードの札・`data-scenes`・`data-speech`・`data-self` と同じにする（話す量・自分の話は P-33・P-34 で承認。決めた根拠は [sakusen-conditions-draft-2026-11-08.md](../../docs/reports/sakusen-conditions-draft-2026-11-08.md)）。変えるときはカードと一緒に変える。子ども向けの画面には出さない。

| 項目 | 値 |
|---|---|
| 人数 | 1人〜 |
| 目安時間 | 5〜10分 |
| 利用シーン | 作戦会議 |
| 話す量 | 選ぶだけ・話す・説明する |
| 自分の話 | 自分のことを話すのが中心 |

## 技術スタック

- オフラインアプリ（Firebase不要・ログイン不要）
- 共通デザインシステム（M-1〜M-6）を使用
- 外部ライブラリ: SortableJS（並び替え）、html2canvas（画像書き出し）

## 画面構成・フロー

```
TOP → GAME（交換） → RANKING（並び替え） → RESULT（画像保存）
                                                  ↓
                                               TOP に戻る
```

### TOP（screen-top）
- タイトル・サブタイトル表示
- 「はじめる」ボタン → GAME へ
- パネル1枚（説明＋分量の目安＋注意点の箇条書き＋「はじめる」）。あそびかたは howto.js のモーダルに一本化（2026-11-06。画面の中の「あそびかた」トグルパネルは廃止）

### GAME（screen-game）
- 30枚からランダムに5枚配布
- カードをタップで選択 → 「交換する」で山札と入れ替え
- 交換回数: 5回（交換済みカードは山札に戻さない）
- 「この5枚で決定する」→ RANKING へ
- 「きょうはここまで」（常設・控えめなボタン）でトップへ戻る。途中でやめるのも正式な終わり方（2026-07-13 の監査 C1 で GAME・RANKING に足したもの。2026-11-08 P6 監査で文書に書いた）

### RANKING（screen-ranking）
- 5枚を縦に並べて順位付け
- 操作: 上下矢印ボタン（タップ）+ ドラッグ&ドロップ（デスクトップ）
- 「順番を決定する」→ RESULT へ
- 「きょうはここまで」は GAME と同じ

### RESULT（screen-result）
- 確定順位でカードを表示（入力欄は置かない）
- 「画像を保存する」→ html2canvas で PNG 書き出し（順位・キーワード・説明のみ）
- 「最初からやり直す」→ TOP へ

## カードデータ

30枚。`app.js` 内の `cardData` 配列を直接編集する。

### カード作成ガイドライン
- 学校・勉強・宿題を連想させる表現は使用しない
- 抽象的な語彙を避け、子どもが実感できる具体的な言葉にする
- 「〜が好き」「〜が大事」「〜したい」のトーンで統一
- 恋愛・暴力・ホラーなどダークな内容は含めない

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | カードプールのシャッフル |
| M-5 popIn | （現状未使用、追加時に利用可能） |

## CSS命名規則

接頭辞: `.vc-`（value-card）

| クラス | 用途 |
|--------|------|
| `.vc-header__title` | ページタイトル |
| `.vc-card` | ゲーム画面のカード |
| `.vc-card--selected` | 選択中のカード |
| `.vc-rank-item` | ランキング画面のカード行 |
| `.vc-result-item` | 結果画面のカード |

## 特有のルール・制約

- **順位づけと画像の保存は意図的な例外**（設計の世代が古い外れ値。docs/audit-prompts.md §0.5-2）。内省系のほかのツールは評価・保存を足さないが、value-card は「大事の順番」を自分で並べて残すこと自体がワークなので残している。名前は画像に入れない。勝手に外さず、変えるときはオーナーが決める

- カードは常に表向き（flip-card は使わない）
- 交換済みカードはプールに戻さない（毎回新しいカードに触れる体験）
- 交換回数は5回固定
- ランキングの主操作はタップ（上下ボタン）、ドラッグはデスクトップ補助
- 画像書き出し用 DOM に挿入するカード内容も escapeHtml で XSS 対策
- 結果画面に理由や感想を書かせる入力欄を置かない。旧「ひとことメモ」（「なんでこれが大事？」）は尋問のようになり場が重くなるため、2026-09-25 にオーナー判断で廃止した
- html2canvas のキャプチャ用 DOM は一時生成→完了後に削除
