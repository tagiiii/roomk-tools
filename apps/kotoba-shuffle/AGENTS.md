# ことばシャッフル 仕様書

## 目的・使用シーン

バラバラになった文字を並べ替えて、ことばを当てるオフライン脳トレツール。
メンターが画面共有しながら、参加者と一緒に答えを考える用途を想定する。

## 技術スタック

- オフラインアプリ（Firebaseなし）
- `index.html` + `app.js` + `words.js` + `style.css`
- 共通デザインシステムと `shuffle` / `popIn` を使用

## 画面構成

```
TOP（レベル選択） → PLAY（5問） → END（結果）
```

## 問題データ

`words.js` の `WORDS` を編集する。
現在は100語で、内訳は3文字30語 / 4文字26語 / 5文字23語 / 6文字21語。

| フィールド | 内容 |
|-----------|------|
| `difficulty` | 文字数。3〜6を使用 |
| `word` | 正解の言葉。ひらがな中心 |
| `hint` | ヒント文 |

## 特有のルール

- 1ラウンド5問
- レベルは3文字 / 4文字 / 5文字 / 6文字
- シャッフル結果が正解と同じ並びにならないようにする
- 絵文字は使わず Material Symbols を使う
- 問題文・ヒントは roomK 共通のコンテンツガイドラインに従う
