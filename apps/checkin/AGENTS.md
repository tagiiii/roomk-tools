# チェックインアプリ 仕様書

## 目的・使用シーン
room-Kのオンライン支援セッション開始時に、参加者が「今の気持ち・状態」を絵文字で共有するツール。
スタッフが「ルーム」を作成し、参加者がコードで入室して一斉にチェックインを行う。

## 画面構成・フロー

### スタッフ側
1. **ルーム作成画面** - 「ルームを作る」ボタンでセッションIDを生成
2. **待機画面** - 参加者の入室・チェックイン状況をリアルタイム表示
3. **結果画面** - 全員のチェックイン結果を一覧表示

### 参加者側
1. **入室画面** - ニックネーム入力 + ルームコード入力
2. **チェックイン画面** - 気持ち絵文字を選択して送信
3. **完了画面** - 送信完了メッセージ（他の人の結果は任意で表示）

## Firestoreデータ構造

```
checkin_rooms/{roomId}
  - createdAt: Timestamp
  - status: "waiting" | "open" | "closed"
  - hostName: string

checkin_rooms/{roomId}/entries/{entryId}
  - nickname: string
  - emoji: string        // 選択した絵文字
  - label: string        // 絵文字のラベル（例: "元気！"）
  - submittedAt: Timestamp
```

## チェックイン絵文字の選択肢（案）
| 絵文字 | ラベル |
|--------|--------|
| 😊 | 元気！ |
| 😐 | まあまあ |
| 😔 | ちょっとしんどい |
| 😴 | 眠い |
| 😤 | もやもやしてる |
| 🔥 | やる気満々 |

## 特有のルール・制約
- ルームコードは6桁英数字（`generateSessionId()` を使用）
- 参加者のニックネームは最大10文字
- ルームは終了後に Firestore から削除する
- スタッフ画面は `?host=1` クエリパラメータで識別（認証なし）
