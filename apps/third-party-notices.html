外部ライブラリ・フォントのクレジット

外部ライブラリ・フォントのクレジット
room-K ツール群 / 確認日: 2026-09-17（7・8 は 2026-10-13 に追加・確認。8 の字数は 2026-10-14 に更新）

本ツール群は以下の外部ライブラリ・フォントを利用しています。
各資源にはそれぞれのライセンスが適用されます。
本ツール群独自の販売制限等は、これらの第三者資源自体には適用されません。
以下に出典、ライセンス原文、配布物内の著作権表示を収録しています。

直接利用する資源

1. Firebase JavaScript SDK 10.14.1
   提供元: Google / Firebase contributors
   用途: 認証・データ同期・利用状況の集計
   ライセンス: Apache-2.0（公式LICENSE内にprotobufのBSD-3-Clauseも収録）
   https://github.com/firebase/firebase-js-sdk

2. SortableJS 1.15.7
   著作権表示: Copyright (c) 2019 All contributors to Sortable
   用途: バリューカードの並び替え
   ライセンス: MIT
   https://github.com/SortableJS/Sortable

3. html2canvas 1.4.1
   提供元: Niklas von Hertzen
   用途: バリューカードの画像書き出し
   ライセンス: MIT
   https://github.com/niklasvh/html2canvas
   公式配布物内のcss-line-break、utrie、base64-arraybuffer、
   text-segmentationおよびMicrosoftのヘルパーの表示も後掲します。

4. Noto Sans JP
   著作権表示: Copyright 2014-2021 Adobe (http://www.adobe.com/),
   with Reserved Font Name 'Source'
   用途: 各画面の日本語フォント
   ライセンス: SIL Open Font License 1.1
   https://github.com/google/fonts/tree/main/ofl/notosansjp

5. Zen Kaku Gothic New
   著作権表示: Copyright 2022 The Zen Kaku Gothic Project Authors
   用途: 説明スライドの日本語フォント
   ライセンス: SIL Open Font License 1.1
   https://github.com/googlefonts/zen-kakugothic

6. Material Symbols Rounded
   提供元: Google
   用途: 各画面のアイコン
   ライセンス: Apache-2.0
   https://github.com/google/material-design-icons

7. Klee One
   著作権表示: Copyright 2020 The Klee Project Authors
   (https://github.com/fontworks-fonts/Klee)
   用途: よく見て漢字の、語を出す教科書体のフォント
   ライセンス: SIL Open Font License 1.1
   https://github.com/google/fonts/tree/main/ofl/kleeone

8. KanjiVG
   著作権表示: Copyright (C) 2009/2010/2011 Ulrich Apel
   用途: よく見て漢字の、字の画と部品のデータ
   ライセンス: Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
   https://creativecommons.org/licenses/by-sa/3.0/
   https://kanjivg.tagaini.net/
   https://github.com/KanjiVG/kanjivg
   改変: 177字分のSVGから画のパスを取り出し、部品ごとの画の番号と
   部品の名前を足して、1つのファイル（yokumite-kanji/kvg-data.js）に
   まとめています。このファイルも CC BY-SA 3.0 で提供します。

読み込み方法

JavaScriptライブラリはバージョンを指定したCDNから読み込みます。
フォント・アイコンはGoogle Fonts API経由で読み込みます。
フォントAPIの配信内容は固定版ではありません。以下の原文は確認日の
公式リポジトリに基づきます。KanjiVG を除き、各資源そのものは改変していません。
KanjiVG は、上記のとおり改変したデータをこのツール群に同梱しています。

この一覧は外部コード・フォントの表示を整理したものです。
ゲームの着想元は「ゲームえらび早見表」を参照してください。
https://tagiiii.github.io/roomk-tools/guide/
