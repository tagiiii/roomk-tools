# ひともじチェンジ 仕様書

## 目的・使用シーン

はじめのことばを1文字ずつ変えて、ゴールのことばまでつなぐことば遊び（例: いぬ→いか→たか→たこ→ねこ）。
メンターが画面共有して1台で操作し、参加者が「ここを『か』にしたら？」と声やチャットで案を出す形を想定する。
1対1でも、サークルタイムの10人程度でも遊べる。

- 2026-11-25 オーナーの依頼で作成。参考にしたのは、YouTube のショート動画「さかなを変換しておにくにするゲーム」（3人がホワイトボードで順番に1文字ずつ書き換える）。遊びそのものは、ルイス・キャロルの「ダブレット」に始まる昔からのことば遊び（英語では word ladder）で、だれかの商品名ではない
- 名前は動きをそのまま表す「ひともじチェンジ」。参考の動画やチャンネルの名前は、画面・更新情報・検索のことばに入れない

## セッション条件（ツール一覧のカードと同じ）

| 項目 | 値 |
|---|---|
| 人数 | 人数制限なし |
| 目安時間 | 5〜15分 |
| 利用シーン | コトバ（kotoba）・サークル（circle）・ひろば（hiroba） |
| 種類 | ことばのゲーム（kotoba） |

## 技術スタック

- オフラインアプリ（Firebaseなし）
- `index.html` + `app.js` + `words.js` + `style.css`
- 共通: design-system.css、`utils.js` の `shuffle` / `popIn`、howto.js、stats.js

## 画面構成・フロー

```
はじめの画面（お題の選び方: 2文字 / 3文字 / 自分で決める → スタート）
  → 遊ぶ画面（お題 → ここまでのことば → いまのことば → 文字の表）
  → ゴール（つながった回数・ほかのつなぎ方の例 → 次のお題 / はじめの画面へ）
```

- いまのことばの文字を押す → 文字の表（50音・濁音・半濁音・小さい字・「ー」）から選ぶ → 1文字だけ変わったことばが「ここまでのことば」に足される
- **文字は打ち込まず、場所と文字を押して選ぶ**。こうすると「1回に1文字だけ・文字の数は変わらない」を必ず守れて、日本語入力の変換中の不具合も起きない
- 濁点・半濁点（か→が）も1回の変更。小さい字と「ー」も1文字として数える
- 「1つ戻す」でいくらでも戻れる。ゴールと同じ文字には、タイルの下に緑の小さな印が出る
- 「ヒント」: 1回目は変える場所を光らせ、あと何回くらいでゴールできそうかを出す。2回目は次のことばの例を出す。ことばを変えると最初からになる
- 「お題を変える」で、そのお題をやめて次のお題へ。家のボタンで、はじめの画面へ
- 2文字・3文字のお題は、全部を出し切るまで同じお題を出さない（出し切ったら混ぜ直す）

## 判定のしかた（意図的な設計）

- **途中のことばがあるかどうかを機械で判定しない**。みんなで「あり」と決めれば進む（もじそろえゲームと同じ考え）。辞書を持つと、方言や子どもが知っていることばが弾かれて、言い合いの種になるため
- ゴールは、いまのことばがゴールのことばと同じになったときだけ自動で出す
- `VOCAB` は、ヒントと「ほかのつなぎ方の例」を探すためだけに使う（幅優先探索のいちばん短い道）。リストにないことばを出しても止めない。リストにないことばからでも、1文字ちがいでリストのことばにつながればヒントは出る

## 比べない・点をつけない

- 点数・順位・時間制限はない。ゴールの画面は「N回の変更でつながった」だけを出す
- 「ほかのつなぎ方の例」は、自分たちの道と同じときは出さない。例の回数と自分たちの回数を並べて比べる言い方はしない

## お題データ（`words.js`）

| 名前 | 中身 |
|---|---|
| `PUZZLES` | `{ chars, start, goal }`。2文字31題・3文字15題 |
| `VOCAB` | ヒントに使うことばのリスト（約380語。2文字と3文字） |

### お題の確かめかた

- どのお題も、`VOCAB` のことばだけでつながることを確かめてから入れる（2026-11-25 時点で、2文字は2〜5回、3文字は3〜6回でつながる）。ブラウザでヒントを2回ずつ押してゴールまで行けることでも確かめられる
- `VOCAB` のことばは、ルートの AGENTS.md「使用しない表現・トピック」に当たらないものだけにする（学校・こわい・恋愛のほか、見た目をからかうのに使われうることばも入れない。例: おかめ を外した）。ヒントの例として画面に出るため
- お題を足したら `node scripts/content-audit.mjs` で重複と禁止題材を確かめる（台帳は `COVERED_APPS`。`はじめ→ゴール` の形で登録している）

## 自分で決めるお題

- ひらがな（カタカナは自動でひらがなにする）・同じ文字の数・2〜5文字・ちがうことば、のときだけ始められる
- つながるかどうかは確かめない（つながらないお題でも遊べる。ヒントが見つからないときは、そう出す）

## メンター向けの心得

- 声を出さない子は、チャットで「1文字目を『か』」のように送ってもらい、メンターが押す
- 出たことばが「ある」かどうかで迷ったら、言った子に意味を聞いてみんなで決める。迷ったら「あり」寄りでよい
- 詰まったら、まず1回目のヒント（変える場所）だけを出す

## 共通モジュールの使用箇所

- `howto.js`: あそびかたモーダル
- `stats.js`: 開いた回数。お題を始めるたびに `chars2` / `chars3` / `custom` を数える
