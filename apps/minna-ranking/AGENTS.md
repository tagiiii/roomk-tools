# みんなでランキング 仕様書

## 目的・使用シーン

MetaLife の自由スペースで、2〜4人の子どもがわいわい遊ぶ並べ替え遊び。
正解のないお題をたわいなく並べ替えて盛り上がる。合意しなくてもよく、「うちらのランキング」ができたら終わり。

| ロール | 説明 |
|--------|------|
| 操作者 | 子ども1人（画面共有でも、各自の端末で同じお題を開いてもよい） |
| 参加者 | 他の子はマイク・チャットで意見を出す |

- メンターがいなくても成立する
- **1人ランキングも正式な遊び方**（意見が出なくても操作者1人で完結する）
- 所要時間: 1お題 10分前後

## 技術スタック

- talk-card 型のオフライン構成（`index.html` + `app.js` + `style.css`）
- Firebase・localStorage 等の**永続化は一切使わない。リロードで消えるのが正しい仕様**
- CSS 接頭辞: `mr-`（BEM 記法）

## 画面構成・フロー

```
[トップ] screen-top
  → お題ガチャ（ランダム。直前と同じお題は連続で出さない）
  → お題をえらぶ（一覧。丸数字①②③…付き）
  → じぶんたちでつくる（お題30文字・アイテム15文字×2〜8個）

[ランキング] screen-rank
  → カードを ドラッグ＆ドロップ / ▲▼ボタン で並べ替え
  → アイテム追加（15文字以内・合計12個まで・重複NG）
  → 「ランクがいへ」で下の「ランクがい」エリアへ移動（削除ではない）→「もどす」で復帰
  → 「うえとタイ」でとなり合うカードを同率にできる
  → 「けっかをコピー」（M-2）でプレーンテキスト化 → MetaLife チャットに貼る
  → 「つぎのお題へ」でいつでもトップに戻る（確認ダイアログなし）
```

## データ構造

Firebase 不要。すべてクライアントサイドで完結。

```js
const state = {
  topic: '',   // 現在のお題
  items: [],   // [{ id, text, tied }] 上から順にランキング
  out: [],     // [{ id, text }] ランクがい
};
```

### タイ（同率）の仕様

- `tied: true` は「**うえのカードと同率**」を意味する
- 順位は 1,1,3 方式（タイの次はその分とばす）
- 先頭カードの `tied` は意味を持たないため描画時に自動解除
- カードを移動すると移動したカード自身の `tied` は解除される。移動先の下にいたカードの `tied` は残る（＝新しい「うえ」と同率になる）。おかしければ子どもがトグルで直せる軽い仕様

### けっかをコピーの出力形式

```
お題：最強の朝ごはん
1位 パンケーキ
1位 トースト
3位 おにぎり
ランクがい：シリアル、ヨーグルト
```

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-2 copyToClipboard | 「けっかをコピー」のフィードバック |
| escapeHtml | `const esc = escapeHtml` として全 innerHTML 挿入で使用 |
| showToast | 入力バリデーションのエラー表示 |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost |

## お題データ

`app.js` 内の `const TOPICS = [...]`（現在45問、各6〜8アイテム）。

### お題作成ガイドライン

**ものごとを楽しく並べるお題だけ**にする。

禁止:
- 人物・成果・行動を並べるお題（人気者・がんばった人・すごい人など）
- 学校・勉強・成績・登校を連想させるもの
- 恋愛・怖い話
- 優劣の主張が対立を生みやすい繊細な話題

## 心理的安全設計（最重要）

- 「みんなが合意した1つの正解」を求めない。画面に「けっかは きょうの気分でOK」のトーンの一言を常置
- タイマー・制限時間・採点を入れない
- 確定・保存・戦績の概念はない（「つぎのお題へ」でいつでも流せる）

## 特有のルール・制約

- 並べ替えはドラッグ＆ドロップ（PC）と▲▼ボタンの両方。600px 以下では▲▼を大きくし、ドラッグハンドルは非表示
- 自由入力の上限: お題30文字・アイテム15文字・つくるモード8個・ランキング中の追加は合計12個まで
- 「ランクがいへ」は削除ではなく移動。「もどす」でランキング末尾に復帰
- 丸数字は `circledNum()` で①〜㊿まで自動生成（お題一覧が50問を超えたら要拡張）
