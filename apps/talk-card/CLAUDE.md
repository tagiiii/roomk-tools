# トークテーマカード 仕様書

## 目的・使用シーン
不登校支援のオンラインメンタリングセッションで使用するトークテーマ提示ツール。
メンターが操作し、生徒に画面共有して使う。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 生徒（Zoom/Meet等の画面共有で閲覧）|

**利用シーン**
- セッション開始時のアイスブレイク
- 話題に詰まったときの話題提供
- 生徒の興味・価値観の探索

## 技術スタック
- 単一アプリ（Firebase不要・ログイン不要）
- 共通デザインシステム（M-1〜M-6）を使用

## 画面構成・フロー

```
[初期表示]
  カード3枚を裏向きで表示（番号のみ）

[カードクリック]
  → M-4 フリップアニメーション
  → 他2枚が dimmed（薄くフェードアウト）
  → お題表示エリアが M-5 popIn で出現

[お題表示エリア]
  → コピーする（M-2: ボタンフィードバック付き）
  → 別のカードを引く（3枚リセット）

[引き直し]
  → カード選択前のみ有効
  → プールから新たに3枚を抽出
```

## Firestoreデータ構造
Firebase不要。すべてクライアントサイドで完結。

## お題リスト
`app.js` 内の `const topics = [...]` を直接編集する（現在100枚）。

### お題作成ガイドライン
- 学校・勉強・宿題を連想させる表現は使用しない
- 正解のない開かれた質問にする
- 子どもが「答えたくない」と感じにくい軽いトーン

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-2 copyToClipboard | コピーボタンのフィードバック |
| M-3 shuffle | お題プールのシャッフル |
| M-4 カードフリップ | .flip-card クラス（CSS + JS） |
| M-5 popIn | お題表示エリアの出現アニメーション |
| M-6 ボタン | .btn-primary / .btn-secondary / .btn-ghost |

## 特有のルール・制約
- カード枚数は固定3枚（`drawHand()` の `splice(0, 3)` を変更すれば増減可）
- プール残数が3未満になったら全お題を再シャッフルして補充
- キーボード操作対応（Tab + Enter/Space でカード選択）
