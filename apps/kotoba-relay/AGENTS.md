# ことばリレー 仕様書

## 目的・使用シーン
オンラインメンタリングの場で、画面共有しながら「つなぎ言葉」を使って話をふくらませるアイスブレイク用ツール。
メンターが操作し、参加者は順番に一文ずつ続きを考える。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 閲覧者 | 参加者（Zoom / Meet 等の画面共有で閲覧） |

**利用シーン**
- セッション冒頭のアイスブレイク
- 複数人で軽く盛り上がりたいとき
- 話し始めるきっかけがほしいとき

## 技術スタック
- オフラインアプリ（Firebase不要・ログイン不要）
- `index.html` + `app.js` + `style.css` の分割構成
- 共通デザインシステム（`apps/shared/css/design-system.css`）を使用
- 共通ユーティリティの `shuffle()` と `popIn()` を使用

## 画面構成・フロー

```text
[初期表示]
  「スターターを引く」ボタンを表示

[開始]
  → スターターを15件からランダム表示
  → つなぎ言葉カードの山札をシャッフル
  → 履歴エリアを空の状態で表示

[つなぎ言葉を引く]
  → 山札から1枚引く
  → 履歴に番号付きカードとして積み上げる
  → 最新カードを popIn で表示

[パス]
  → 「パス」カードを履歴に追加

[もう一度]
  → 新しいスターターで最初からやり直す

[おしまい]
  → 初期画面に戻る
```

## データ構造
Firebase不要。すべてクライアントサイドで完結。

### スターター
`app.js` 内の `const starters = [...]` に30件を定義。

### つなぎ言葉カード
`app.js` 内の `const connectors = [...]` に40件を定義。
各カードは以下の形式を持つ。

```js
{ word: 'だから', type: 'go' }
```

`type` は見た目の色分けに使用する。

| type | 意味 |
|------|------|
| `go` | 順接・展開 |
| `turn` | 逆接 |
| `jump` | 転換・脱線 |
| `plus` | 強調・追加 |
| `like` | たとえ |
| `pass` | パス |

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| デザイントークン | 余白・色・ボタン・角丸などの共通スタイル |
| `shuffle()` | つなぎ言葉カード山札のシャッフル |
| `popIn()` | スターター表示時と履歴追加時の出現アニメーション |

## 特有のルール・制約
- 参加者が答えに詰まっても続けやすいように `パス` を許可する
- `pass` 型カードも山札に含まれ、通常の履歴カードと同じ描画経路で表示する
- 履歴は全文ではなく「引いたつなぎ言葉」の並びを積み上げ表示する
- つなぎ言葉カードが尽きたら自動で再シャッフルして補充する
- スターターとカード文言は、学校・勉強・怖い話・恋愛などを避けた軽い内容にする
- 多人数での口頭進行を前提とし、入力欄や採点機能は持たない
