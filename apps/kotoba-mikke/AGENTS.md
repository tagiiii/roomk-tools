# ことばみっけ 仕様書

## 概要・使用シーン

小学館「コトバト」（辞書を使った語彙力バトル）に着想を得た、お題に合うことばをさがす言葉あそび。
メンターが画面共有しながら進行する。**辞書は必須にしない**（あってもよい）。

- アプリはお題「『あ』からはじまる、やさしい言葉」などを1つ出す（**頭文字 × テーマ**）
- 子どもは思いついたことばを **Metalife のチャット**に送る
- メンターはチャットの答えを**声で受ける**（順位をつけず、人ではなくことばを受ける）
- **アプリはお題を出す・チャットにコピーする・引き直すことに徹する**。答えの収集・表示はしない

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（スタッフ）。お題を出し、チャットにコピーし、必要なら引き直す |
| 閲覧者 | 子ども（小学生〜中学生）。チャットにことばを送り、画面のお題を見る |

### 相性のよい使い方
- サークルタイムの言葉あそび（10人程度でも成立）
- 話し始めるきっかけ・ウォームアップ

## 技術スタック

- **オフライン**（Firebase 不要・ログイン不要・単一メンター操作）
- `index.html` + `app.js`（ESモジュール）+ `style.css` の分割構成
- 共通デザインシステム（`../shared/css/design-system.css`）を使用
- 共通ユーティリティの `copyToClipboard`、`../shared/js/howto.js` を使用
- CSS 接頭辞: `.kmk-`（BEM）

## 画面構成・フロー

**2画面**だけのシンプル構成。あそびの中身はチャットと会話に返し、アプリは humble な進行補助に徹する。

```
TOP（screen-top）
  → お題（screen-odai）
      お題「『あ』からはじまる、やさしい言葉」を大きく表示（頭文字を強調）
      ・お題をチャットにコピー（Metalife 貼り付け用）
      ・はじめの文字を かえる / おだいを かえる / ぜんぶ かえる（引き直し = つぎのお題）
      ・TOPにもどる
```

## お題データ（`app.js`）

お題は **頭文字プール `INITIALS` × テーマプール `THEMES` をその場でランダム合成**する
（例「『あ』からはじまる、こわいもの」）。直前と同じにならないよう `pickDifferent` を使う。

- `INITIALS`：清音のみ。**を・ん・ぬ・る・れ** と、小書き・濁点/半濁点始まり・旧字・長音は入れない
  （答えが極端に少ない/出しにくいため）。迷う字はカタカナ語（同じ音）で拾える。
- `THEMES`：コトバトのお題に準拠した**単一テーマ**。「**〜言葉**」12個と「**〜もの**」16個の2系統。
  **感情の幅（ポジ〜ネガ）をあえて広く取る**（やさしい／わるい、うれしい／かなしい、あかるい／くらい 等）。
  「こわいもの＝おばけ・かみなり」のように辞書や想像から言葉をさがす言葉あそびであり、
  ダーク・暴力そのものを扱うわけではない。
- 引き直しは3種：`rollOdai('both'|'initial'|'theme')`。ボタンは「はじめの文字を かえる」（`initial`）/
  「おだいを かえる」（`theme`）/「ぜんぶ かえる」（`both`）。難しい組合せを軽く変えられる
  （引き直しを失敗扱いにしない）。

### コンテンツ方針（意図的な例外）

roomK 全体の [AGENTS.md](../../AGENTS.md) は「こわい・ダークな内容を避ける」としているが、
**このアプリはコトバト再現として感情の全幅を採用する**（ユーザー判断・2026-07-16）。
`kyapa-graph` が「数値化しない」哲学を意図的に変えたのと同じ、明示的な例外として扱う。
メンター監督下で使う前提。ネガ寄りのお題は「言葉さがし」として受け、実在の人や特定の子に向けない。

## 特有のルール・制約

- **点数・勝敗・累計・順位を作らない/残さない。** カウンタを持たない。
- **保持・保存しない。** アプリが持つ状態は「今のお題」だけ。`localStorage` / `sessionStorage` 不使用。
- **子どもの答えをアプリで収集・表示しない**（誰かの答えを「選んで映す」画面を作らない）。
  答えはチャットに全員フラットに並び、メンターは声で受ける。
- 絵文字は使わない（アイコンは Material Symbols）。updates.json も同様。
- viewport は `maximum-scale=1` を付けない（非RTDBアプリ。lint VIEWPORT-2）。
- お題は常に1つだけ大きく表示するので、選択肢の丸数字番号（①②③）は不要。
- タイマーは置かない（急かさないため）。

## メンター心得（画面には出さない。ここにだけ書く）

- 答えは**もの・生きもの・架空のもの**からさがすよう促す（実在の人をネタにしない）。
- **「わるい言葉」などネガ寄りのお題**は、実際の暴言・悪口ではなく「言葉さがし」として受ける。
  特定の子・実在の人に向かいそうなら、そっと別のお題に切り替える。
- チャットの答えに**順位・優劣をつけない**。特定の答えを「いちばん」にしない。
- 声で受けるときは**毎回ちがう子**に触れ、同じ子ばかりにならないようにする。拾い残しは「あとで見るね」とフォロー。
- 受けるときは、そのことばの**いいところをひとこと**言う（人ではなくことばを観察する）。
- **同じ答え・パス・あとから・口頭での回答もOK**。全部を読み上げなくてよい。
- 答えにくそうなお題は「**べつのお題**」で軽く変える。難しさを子どもに背負わせない。
