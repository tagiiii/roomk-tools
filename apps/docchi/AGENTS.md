# どっちにする？ 仕様書

## 目的・使用シーン

不登校の小中学生との1対1オンライン面談で使う、軽い2択カードツール。
軽い2択を「自分で選ぶ」体験を重ねることで、「自分で決めていい」という感覚を育てる。関係づくりのアイスブレイクにも使う。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター（画面共有して進行。子どもの答えを聞いてから選択肢をタップ） |
| 参加者 | 子ども（口頭・チャットで回答。自分のスマホでURLを開いて使う回もある） |

**所要時間**: 5〜10分（カード5〜10枚程度）

## 技術スタック

- talk-card 型のオフライン構成（`index.html` + `app.js` + `style.css`）
- Firebase・localStorage・sessionStorage 等の**永続化は一切使わない**
- 共通デザインシステム（design-system.css）+ Material Symbols Rounded（絵文字禁止）
- CSS 接頭辞: `dc-`（BEM 記法）
- レスポンシブ対応（600px 以下で選択肢を縦積みに）

## 画面構成・フロー

```
[トップ画面]
  タイトル + カテゴリ選択（すべて／たべもの／あそび／もしも／どうぶつ／せいかつ）
  → はじめる

[カード画面]
  お題文 + 2択（① vs ②）を大きく表示
  ③どっちもいい ④どっちでもない も常に正式な選択肢として表示
  → タップで選んだ選択肢がふわっとハイライト（正解演出・効果音なし）
  → 選び直し自由
  → 「つぎへ」でいつでも次のカードへ（スキップ自由、確認・記録なし）
  画面下: メンター向けの軽い追い質問例を1つ表示（例:「いつからすき？」）
```

- カードはシャッフル出題。プールを消化したら再シャッフルで補充（直前と同じお題が続かないようガード）
- 何枚やったかのカウントや成績表示はしない

## データ構造

`app.js` 内の `const TOPICS = [...]`（85問）。永続化なし・全てクライアントサイドで完結。

```js
{ cat: 'tabemono', q: 'あさごはんにするなら？', a: 'パン', b: 'ごはん', ask: 'きょうは何を食べた？' }
```

| フィールド | 説明 |
|-----------|------|
| `cat` | カテゴリID（tabemono / asobi / moshimo / doubutsu / seikatsu、各17問） |
| `q` | お題文 |
| `a` / `b` | 2択の選択肢（①②として表示） |
| `ask` | メンター向けの軽い追い質問例（画面下に小さく表示） |

## 共通モジュールの使用箇所

| モジュール | 使用箇所 |
|-----------|----------|
| M-1 デザイントークン | design-system.css から継承 |
| M-3 shuffle | お題プールのシャッフル |
| escapeHtml（`esc` として import） | お題文字列の innerHTML 挿入時（静的データだが全て通す） |
| M-6 ボタン | .btn-primary / .btn-ghost |

## 設計思想（心理的安全が最優先）

- **選ぶこと自体が目的**。どちらを選んでも楽しい2択だけを出し、答えの内容は評価も記録もしない
- 「りゆうは なくてもOK。パスもOK！」をカード画面に常時表示し、なんとなくで選んでよいことを UI 文言で伝える
- ③④（どっちもいい・どっちでもない）は逃げ道ではなく**正式な選択肢**として常に表示する
- スキップに確認・記録・咎める表示は出さない
- 追い質問例は押し付けにならないトーン（「きいてみるなら…」）で小さく表示するだけ

## 入れない機能（意図的に未実装）

| 機能 | 入れない理由 |
|------|------------|
| 選択の集計・履歴・振り返り | その場で流れて消えるのが正しい。記録は「試される感」につながる |
| 何枚やったかのカウント・成績表示 | 達成度の演出は評価に転じる |
| 理由の入力欄・理由を促す仕組み | 「なんとなく」で選ぶ自由を守る |
| 正解演出・効果音 | 正誤の概念を持ち込まない。ハイライトは控えめなふわっと表示のみ |
| 永続化（Firebase / localStorage） | オフライン完結。データを残さない |

## お題ガイドライン

共通コンテンツガイドライン（ルート AGENTS.md）に加えて:

- どちらを選んでも楽しい軽い2択のみ（例: きのこの山 vs たけのこの里）
- **禁止**: 学校・勉強・宿題・成績・登校の連想 / 恋愛 / 怖い話・死 / 優劣や正誤がつく2択 / 答えにくい個人的な事情に触れる2択（家族構成・友だちの有無など）

## 特有のルール・制約

- 選択肢の番号は丸数字 `①②③④`（AGENTS.md の番号付け規約）。番号は `dc-choice__num`（アクセントカラー）で表示
- お題文字列は静的データだが、`innerHTML` に挿入する際は必ず `esc()`（utils.js の escapeHtml）を通す
- お題の追加・編集は `app.js` の `TOPICS` 配列を直接編集する（カテゴリごとに約17問のバランスを保つ）
