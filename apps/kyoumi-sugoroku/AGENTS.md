# 興味スゴロク 仕様書

## 目的・使用シーン
不登校支援のオンラインメンタリングセッションで、子どもとの対話のきっかけをつくるスゴロクツール。
メンターが画面共有で操作し、マスに止まった人が出てきた質問について話す。

| ロール | 説明 |
|--------|------|
| 操作者 | メンター |
| 参加者 | 生徒1〜4人（画面共有で閲覧） |

**利用シーン**
- セッション開始後のアイスブレイク
- 自己紹介や興味の探索
- 話題に困ったときの対話のきっかけづくり

## 技術スタック
- オフライン単独動作（Firebase 不要）
- ファイル構成: `index.html` + `app.js` + `style.css`（talk-card, jitsuwa-game と同パターン）
- 共通デザインシステム & `shared/js/utils.js` の `shuffle`, `popIn` を使用

## 画面構成・フロー

```
[設定画面]
  何人であそぶ？（1〜4、トグルボタン）
  マス数（10/15/20、トグルボタン）
  テーマ選択（初期値：全選択、2つ以上必須）
  ↓ ゲームスタート
[ゲーム画面]
  ボード（5列蛇行グリッド） + コマ + サイコロ + 現在ターン表示
  ↓ サイコロを振る
[質問モーダル]
  選ばれたテーマ・質問を表示
  - 選択肢あり: 3択 + 「自由に話す」
  - 選択肢なし: 「話せた！次の人へ」
  常時: 「別の質問」（テーマ維持で再抽選）
  ↓
[ゴール時]
  ゴールモーダル → もう一度あそぶ
```

## 設計方針：入力を最小化

オンラインメンタリングのセッション開始時に使うため、**設定操作は「トグルを数回押してスタート」で済む**ように絞り込んである。

- **プレイヤー名入力は廃止**。画面外（Zoom/Meet）で既にメンターと子どもが顔を合わせているため、ゲーム内の名前は必要なく、入力の摩擦だけが残る。`プレイヤー1` 〜 `プレイヤー4` を自動付与し、ターン表示・質問モーダルの宛先もこの名称を使う
- 人数・マス数は select ではなくトグルボタン（1クリック選択）
- テーマは折りたたまず常時表示（メンターが子どもの反応に応じて即調整できるように）
- 最低 2 テーマ必須。それ以外のバリデーションは最小限

※ この方針は roomK 共通の「ニックネーム必須」ルールの例外にあたる。理由は「対面（オンライン通話）前提・共有端末・対話のきっかけツール」という性質上、参加者識別は通話側で済んでおり、アプリ側の名前入力が冗長なため。

## データ構造（クライアントサイドのみ）

```js
state = {
  players: [{ name: 'プレイヤー1', pos: 0 }, ...],  // name は自動生成
  currentIndex: 0,
  totalSquares: 10 | 15 | 20,
  themes: ['suki', 'yatte', ...],
  pools: { [theme]: [質問配列（shuffle済）] },
  history: [{ theme, question }],
  rolling, ended, currentQ,
  diceTimer, moveTimer,  // 設定に戻る時にクリア
};
```

質問データは `string | { q, choices }` のハイブリッド。選択肢ありの場合、モーダルに「自由に話す」ボタンが自動で追加される。

## テーマ & 質問データ
`app.js` 内の `QUESTIONS` を直接編集する。テーマは6種類:

| キー | ラベル | アイコン |
|------|--------|---------|
| suki | 好きなもの | favorite |
| yatte | やってみたい | rocket_launch |
| moshimo | もしも… | auto_awesome |
| jibun | 自分のこと | person |
| saikin | 最近のこと | today |
| tokui | 得意・チャレンジ | star |

### 質問作成ガイドライン（AGENTS.md コンテンツガイドラインに準拠）
- 学校・勉強・宿題・テスト・成績を連想させる表現を使わない
- 恋愛・暴力・ダークな話題を避ける
- 正解のない開かれた質問にする
- 「答えたくない」と感じにくい軽いトーン

## 共通モジュールの使用箇所
| モジュール | 使用箇所 |
|-----------|----------|
| M-3 shuffle | テーマごとの質問プールの初期シャッフル |
| M-5 popIn | 質問モーダル / ゴールモーダルの出現 |
| M-6 ボタン | `.btn-primary` / `.btn-secondary` / `.btn-ghost` |

## 特有のルール・制約
- **質問の重複回避**: テーマごとにプールを保持し、使い切ったら再シャッフル
- **テーマの連続回避**: 直前と同じテーマが他にあれば再抽選
- **コマ色**: 4色固定（`.ks-pawn--0` 〜 `--3`）。design-system.css の雰囲気に合わせた落ち着いたトーン
- **プレイヤー名**: 入力なし。`プレイヤー1` 〜 `プレイヤー4` を自動付与
- **最低人数**: 1人から遊べる（自分だけの対話用途を想定）
- **ゴール**: サイコロの出目は最終マスで止まる（オーバーしない）
- **ボード**: 5列グリッドの蛇行（偶数段は左→右、奇数段は右→左）
- **設定に戻る**: アニメーション中（`diceTimer` / `moveTimer`）は `clearTimers()` で明示的に停止し、モーダルも閉じる
