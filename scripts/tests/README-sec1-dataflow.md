# A-11 の限定データフロー検査

実行:

```sh
python3 scripts/tests/test-sec1-dataflow.py
python3 scripts/sec1-dataflow.py --json
bash scripts/lint.sh
```

`sec1-dataflow.py` は SEC-1 の追加チェック(3)。既存の単行grepとA-9の複数行連結式検査(1)/(2)は変更しない。既存検査の関数名による広い免除などの限界を、この追加チェックで解消したとは扱わない。標準ライブラリだけを使い、解析対象のコード・ネットワーク・ブラウザ・Firebaseを実行しない。

## 検出する部分集合

- 対象は従来と同じ `apps/*/index.html` のインラインscriptと `apps/*/app.js`。直接の `.innerHTML =` / `+=` に渡す複数行テンプレート内の `${var}` / `${obj.field}` のみ。
- セミコロンで区切られた同じ直線ブロック内の単純代入・別名・プロパティ代入を追う。DOM取得直後のvalue／textContent／innerHTML、取得DOMのdataset、locationのhash／search、storageのgetItemという潜在的外部入力を裸補間まで追えれば `raw` / ERROR。
- 数値リテラル、固定文字列、明示的な `esc` / `escapeHtml` / `RoomkRTDB.esc` 全体呼出し、これらだけの限定テンプレート構築は局所的な根拠になる。変数名にsafe／escaped／HTMLがあるだけでは信用しない。ヘルパーは既存のエスケープ契約を前提とし、その関数の実装正当性を証明しない。
- ヘルパーや入力元グローバルの宣言・引数・再代入を検知したscriptでは、その名前を保守的に信用しない。`obj`置換は追跡済みの`obj.field`を失効させる。未知の呼出し・副作用候補は以前の根拠を破棄する。
- 値がescaped／固定HTMLでも、属性、script／style等が一度現れた前置部、先行補間でHTML文脈が変わり得る位置は `unknown`。引用符内の `>` をタグ終端と誤認しない。前置部にバックスラッシュがある場合も、実行時のJS文字列復号は未対応として `unknown` にする。

`safe` / `html` は以上の部分集合における値・文脈の分類であり、アプリ全体のXSS安全性を意味しない。`raw`も悪用可能性や入力権限まで確定した脆弱性数ではない。対象コードを人間が確認するための検査エラーである。

## 未対応と未判定の扱い

完全なJavaScript／HTMLパーサや関数間解析ではない。ブロック・関数・条件分岐・ループの境界で根拠を保持しない。コールバック、分割代入、任意の関数、計算プロパティ、オブジェクト別名、import先のデータ、暗黙の型、ASI等は確定解析しない。直接テンプレート以外のsink、代入変数だけをinnerHTMLへ渡す形、map/join経由等はこの追加検査の対象外。

未解決は `unknown` として安全認定しない。既存の検査対象外範囲を可視化するもので、通常lintは `INFO: UNKNOWN (unverified, not safe)` の件数を出す。行ごとの詳細は `--json`。新規WARNを許容する規約変更は行わず、明確なraw経路と検査器の失敗はERRORにする。失敗exit 1に診断がない場合も黙って通さない。

作成時の実ファイル走査は71ファイル・裸参照48箇所・ERROR 0・unknown 48。これは現行appsで誤ERRORがないという回帰条件だけを満たし、48箇所の安全確認完了ではない。A-11は部分実装で未完了のままとする。閉じるには、未判定の各パターンについてスコープ・再代入・入力元・出力文脈を含む根拠を追加し、対応する危険／安全の負例を恒久化するか、保証対象を限定する方針を別途決定する必要がある。単に無視リストへ移して完了にしない。

## 回帰テストと分量

恒久fixturesは危険な別名・プロパティ・再代入、明示エスケープ保持、名前だけの誤認、影・将来定義・分岐、部分エスケープ、HTML文脈、コメント／文字列／regex／エスケープ済み補間記号、HTML抽出、解析失敗を含む。同じCLIを一時ディレクトリの入力で実行する。さらに実際のlint SEC-1部分を切り出して8ケース（従来2方式と追加方式・未判定INFO・失敗経路）を検証し、現行appsも再走査する。一時入力はテスト終了時に削除する。

200行を超える理由は、字句境界・根拠失効・安全文脈の条件と、それを壊す負例・既存チェック回帰・失敗時配線を、依存追加なしの1関心事として不可分に保持するため。簡易検査である限界は行数を増やしても解消されない。コミット・公開はこのスクリプトでは行わない。
